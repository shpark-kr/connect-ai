## ✨ Defect ID 기반 MiniFunnel 유도형 릴스 주간 스케줄 V7 (2주 분량)

### **📅 Week 1: 만성 염증 및 혈당 시스템 오류 집중**

#### **📌 콘텐츠 1: S-I001 - 염증 폭발 경고 (Inflammation Escalation)**
*   **핵심 주제:** 단순 노화가 아닌, 신체 전반의 '만성 과부하' 상태를 공학적 결함으로 규정. (최초 위기감 조성)
*   **목표:** 높은 Pain Point로 인해 콘텐츠 시청 완료율을 높이고, 자가진단(MiniFunnel) 유도.

| 요소 | 상세 내용 및 스크립트/가이드라인 |
| :--- | :--- |
| **⏱️ 추천 게시 시간** | 평일 저녁 7:30 (퇴근 후 가장 높은 불안감과 정보 탐색 욕구 발생 시점) |
| **🎬 Hook Script (0~3초)** | (화면 암전, 경고음과 함께 붉은 글씨로 등장): "경고. 당신의 만성 통증은 '노화'가 아닙니다." / (나레이션, 단호하게): "몸속 염증 시스템에 오류 코드가 감지되었습니다." |
| **📺 비주얼 가이드라인** | 1. **초반:** 심장 박동 그래프와 함께 'S-I001' 코드 노출. 2. **중반 (보고서 UI 활용):** 인체 장기별 염증 수치(CRP, ESR 등)를 *시스템 실패 보고서* 형식의 차트로 보여주며, 정상 범위를 벗어난 구간을 Crisis Red로 강조. 3. **후반:** '결함 해소 프로토콜'이라는 타이틀과 함께 자가진단 페이지 UI를 배치. |
| **📜 캡션 초안 (문제 제기 - 해결책 제시 - CTA)** | [🚨 시스템 진단 결과 보고] 혹시 아침에 일어날 때마다 이유 없는 뻐근함이나, 만성적인 피로감 때문에 고생하고 계신가요? 대부분 이걸 '나이 탓'으로 돌리지만, 사실은 몸속 염증 스위치(S-I001)가 과부하 상태라는 신호입니다. 단순히 운동만으로는 해결할 수 없는 근본적인 시스템 오류입니다. ✅ 저희는 이 만성 염증의 원인을 과학적으로 역추적했습니다. 더 이상 증상을 억누르지 마세요. 지금 바로 [프로필 링크]에서 '염증 시스템 자가 진단'을 시작하고, 당신 몸의 결함 코드를 정확히 확인하세요! |
| **#️⃣ 필수 해시태그 세트** | `#만성염증 #염증관리 #S_I001 #40대건강 #50대건강 #체형교정 #혈관건강 #건강정보 #DefectID` |
| **💡 후속 스토리 아이디어 (다음 날)** | "🚨 3초 진단 체크리스트" : '아침에 몸이 찌뿌둥한가요?' 등 간단한 질문을 던지며, 답변자가 손뼉을 치거나 스와이프할 때마다 '염증 지수 상승' 경고 이미지를 보여주며 자가진단 페이지로 연결 유도. |

#### **📌 콘텐츠 2: S-B11D - 혈당 롤러코스터의 비밀 (Glycemic Variability Index)**
*   **핵심 주제:** 단순 당뇨보다 무서운, 예측 불가능한 급격한 혈당 변동성(GVI)을 핵심 위험으로 제시.
*   **목표:** 공포감과 전문성을 결합하여 '내 몸의 시스템 안정화'라는 해결책에 집중 유도.

| 요소 | 상세 내용 및 스크립트/가이드라인 |
| :--- | :--- |
| **⏱️ 추천 게시 시간** | 평일 점심시간 12:00~13:00 (식사 직후 혈당 변화를 체감하는 시점 공략) |
| **🎬 Hook Script (0~3초)** | (화면: 롤러코스터가 급강하/급상승하는 애니메이션과 함께): "🚨 잠깐! 이 식습관이 당신의 몸을 망가뜨립니다." / (나레이션, 불안감 고조): "혈당이 매번 롤러코스터를 타는 이유. 그것은 '시스템 과부하'입니다." |
| **📺 비주얼 가이드라인** | 1. **초반:** 식사 장면과 함께 혈당 그래프가 급격히 오르내리는 시각화 자료 제시 (S-B11D 코드 노출). 2. **중반 (보고서 UI 활용):** '이상적인 인슐린 반응 곡선' vs '실제 측정된 불안정한 곡선'을 비교하는 차트를 통해 Defect ID의 심각성을 부각. 3. **후반:** "시스템 안정화 프로토콜"이라는 해결책 제시와 함께, 전문 상담 CTA 배치. |
| **📜 캡션 초안 (문제 제기 - 해결책 제시 - CTA)** | [📉 혈당이 불안정한 분 필독] 식사 후 '괜찮다'고 생각하시나요? 하지만 급격하게 치솟았다가 떨어지는 혈당(GVI)는 이미 당신의 인슐린 시스템에 경보를 울리고 있다는 뜻입니다. 이는 단순한 피로감을 넘어, 심혈관과 뇌 건강까지 위협하는 가장 위험한 '시스템 불안정' 신호입니다. 저희가 수많은 데이터를 분석하여 찾은 해결책은 단순히 식단 조절이 아닙니다. 체계적인 시스템 재설정이 필요합니다. 지금 [프로필 링크]를 통해 혈당 변동성 자가 진단을 받아보세요. |
| **#️⃣ 필수 해시태그 세트** | `#혈당관리 #GVI #혈관건강 #인슐린저항성 #40대남자 #50대여자 #만성피로 #DefectID #미니퍼널` |
| **💡 후속 스토리 아이디어 (다음 날)** | "식사 시간 꿀팁 테스트" : 간단한 설문 ("점심 식사 후 가장 먼저 느끼는 증상은?")을 통해 사용자의 고통점을 다시 상기시키고, 자가 진단 페이지로 연결하는 스와이프 기능을 활용. |

### **📅 Week 2: 수면 및 혈관 기능 시스템 오류 집중**

#### **📌 콘텐츠 3: S-C12A - 뒤틀린 생체 리듬 (Circadian Rhythm Disruption)**
*   **핵심 주제:** 단순히 잠을 적게 자는 것이 아니라, 수면 '질'과 '주기' 자체가 결함 상태임을 전문적으로 지적.
*   **목표:** 심층적인 과학적 접근으로 콘텐츠의 권위를 높이고, 복합적인 건강 관리가 필요함을 인지시키기.

| 요소 | 상세 내용 및 스크립트/가이드라인 |
| :--- | :--- |
| **⏱️ 추천 게시 시간** | 주말 오전 10:00 (휴식과 회복에 대한 니즈가 최고조에 달하는 시간) |
| **🎬 Hook Script (0~3초)** | (화면: 시계 바늘이 뒤틀리거나 깨지는 효과와 함께 경고음): "아무리 자도 피곤한 이유? 당신의 생체시계가 고장 났습니다." / (나레이션, 의문을 던지듯): "수면 시간이 문제가 아닙니다. 수면 '패턴'에 오류 코드가 있습니다." |
| **📺 비주얼 가이드라인** | 1. **초반:** 일반적인 수면 패턴 그래프와 비교하여, 결함이 있는(S-C12A) 주기를 시각적으로 대비 제시. 2. **중반 (보고서 UI 활용):** REM/Deep Sleep 비율을 보여주는 전문적인 생체 리듬 차트(파형 분석기 느낌)를 사용하고, 어느 구간의 Defect가 심각한지 Crisis Red로 표시. 3. **후반:** '생체 리듬 재설정 프로그램' CTA 배치. |
| **📜 캡션 초안 (문제 제기 - 해결책 제시 - CTA)** | [🌙 숙면을 해도 피곤하다고요? 체크하세요.] 수면 시간을 늘리는 것만으로는 근본적인 회복이 불가능합니다. 우리 몸의 생체 리듬(S-C12A)은 밤낮 주기에 맞춰 정교하게 설계된 '시스템'입니다. 이 시스템에 결함이 생기면, 깊은 잠을 자도 뇌와 신체는 제대로 휴식하지 못해요. 단순한 수면 보조제가 아닌, 당신의 *생체 주기*를 전문적으로 재설정해야 합니다. 다음 주 무료 [전문 상담 예약]을 통해 나의 수면 시스템 오류 코드를 진단받아 보세요! |
| **#️⃣ 필수 해시태그 세트** | `#수면개선 #생체리듬 #CircadianRhythm #숙면팁 #40대필수템 #50대건강관리 #만성피로탈출 #DefectID` |
| **💡 후속 스토리 아이디어 (다음 날)** | "오늘의 수면 점검" : 사용자가 직접 오늘 수면 시간과 컨디션을 체크하는 폼을 제공하고, 답변에 따라 '수면 시스템 점수가 낮음' 등의 경고 문구를 보여주며 전문 상담 페이지로 유도. |
