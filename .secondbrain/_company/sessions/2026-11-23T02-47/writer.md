## 📑 랜딩 페이지 카피라이팅 초안 (Defect ID 기반)

### 📌 섹션 1: 공감 유발 (Empathy & Connection)
*   **목표:** 사용자에게 "당신의 노력이 부족해서가 아니라, 시스템 자체가 지치고 있다"는 안도감과 동시에 '무언가 잘못되고 있음'을 은연중에 인지시킵니다. 감성적 접근으로 시작합니다.

| 요소 | 초안 카피 (Tone: 공감, 전문적) |
| :--- | :--- |
| **헤드라인 (H1)** | "혹시... 몸이 보내는 '경고음'을 무시하고 계신가요? 40대 이후, 노화는 감(感)이 아닌 수치입니다." |
| **본문 카피** | 지난 몇 년간의 치열했던 삶. 가족과 커리어를 위해 자신에게 가장 많은 에너지를 소모하셨을 겁니다. 하지만 우리 몸은 기계와 같습니다. 아무리 열심히 달려도, 시스템에 누적된 부하(Load)가 임계점을 넘으면 반드시 '결함'이 발생합니다. 단순히 피곤하다는 느낌만으로는 설명할 수 없는, 관절의 미세한 틀어짐, 아침마다 느껴지는 근육의 경직, 거울 속 피부 탄력의 급격한 감소... 이는 타고난 노화가 아니라, **지금 당장 측정하고 개선해야 할 시스템적 결함(Defect)**일 수 있습니다. |
| **CTA (Call to Action) 버튼** | 💡 [나의 몸 상태, 객관적인 수치로 확인하기] |

<br>

### 📌 섹션 2: 위협 증폭 / 진단 필요성 제기 (Threat Amplification & Diagnosis Necessity)
*   **목표:** 공감에서 '공포/위험'으로 심리적 전환을 유도합니다. Defect ID 그래프 컴포넌트가 삽입될 가장 중요한 섹션입니다. "막연한 불안"을 "**구체적인 수치적 위협**"으로 치환시켜야 합니다.

| 요소 | 초안 카피 (Tone: 긴장감, 임상적, 경고) |
| :--- | :--- |
| **헤드라인 (H2)** | "당신의 몸은 지금 몇 %의 '결함(Defect ID)' 상태인가요? 육안으로 확인할 수 없는 진짜 위험 지표를 측정하세요." |
| **본문 카피** | 많은 분들이 만성 피로, 관절 통증 등으로 자신을 자가 진단합니다. 하지만 겉으로 드러나는 증상만으로는 근본적인 문제를 알 수 없습니다. 온현은 수많은 데이터를 분석하여, 나이가 들면서 필연적으로 생기는 신체 시스템의 **'핵심 결함 지표(Critical Defect ID)'**를 과학적으로 측정할 수 있는 방법을 제시했습니다. 이 그래프는 단순한 점수가 아닙니다. 당신이 지금 느끼는 모든 불편함을 뒷받침하는 **측정 가능한 '위험 수치'**입니다. *그래프 컴포넌트가 여기에 배치되며, 사용자가 진단 과정을 거칠수록 위험 수치가 상승하고 경고 애니메이션이 발동해야 합니다.* |
| **CTA (Call to Action) 버튼** | 🚨 [무료 Defect ID 자가진단 시작하기] *(최대 위협감을 주는 문구)* |

<br>

### 📌 섹션 3: 해결책 제시 (Solution & Transformation)
*   **목표:** 공포를 '희망'과 '통제력'으로 전환합니다. 문제가 측정되었으니, 이제는 그 Gap을 채울 수 있다는 자신감을 심어주며 다음 단계(구매/상담)로 유도합니다.

| 요소 | 초안 카피 (Tone: 확신, 솔루션 중심, 희망적) |
| :--- | :--- |
| **헤드라인 (H2)** | "측정된 결함 지표, 이제 계획적으로 채워나가세요. 온현의 [솔루션명]이 당신의 시스템을 재부팅합니다." |
| **본문 카피** | 위험 수치가 높은 것은 곧 개선할 기회가 있다는 뜻입니다. 저희는 단순한 영양제나 운동법을 제시하지 않습니다. 사용자의 Defect ID 측정 결과, 즉 '구체적인 Gap'만을 채우기 위해 최적화된 라이프케어 솔루션만을 엄선했습니다. 시스템의 부족했던 특정 부위(예: 인슐린 저항성 개선, 관절 연골 지지력 강화)를 과학적 근거와 수치로 메워나가는 과정이 필요합니다. **더 이상 '막연히 좋아지는' 것이 아닌, '수치적으로 나아지고 있다'는 확신을 경험하세요.** |
| **CTA (Call to Action) 버튼** | ✅ [내 Defect ID Gap에 맞는 맞춤 솔루션 받기] |
