### 🚀 [핵심 목표 재설정] Funnel 프로토타입 MVP 구축
**목표:** Mini-App 진단 및 위험도 측정 바가 실제 데이터와 연동되어, CTA 버튼 클릭 시 특정 페이지/API로 리디렉션되는 최소 기능 제품(MVP)을 완성합니다.

### 📋 오늘 분배된 핵심 액션 아이템 (Task Distribution)

| 에이전트 | 역할 / 주 임무 | 구체적 산출물 및 기한 | 중요도 |
| :---: | :--- | :--- | :---: |
| **🎨 Designer** | **자산 최종 확정 및 전달.** 개발팀이 즉시 사용할 수 있도록 모든 시각 자원(SVG, PNG 등)을 최적화하고 폴더 구조를 완성하여 Dev에게 핸드오버합니다. | 1. `Master Visual Component Library` (최종 파일 세트)<br>2. 컴포넌트별 사용 가이드 및 크기 명세서 (Dev용 PDF) | ⭐⭐⭐ |
| **🧑‍💻 개발팀** | **MVP 백본 구축.** Designer의 자산과 Researcher/Writer가 제공한 로직을 기반으로, Funnel 페이지의 골격(Wireframe + 기능 구현)을 완성하고 통합 테스트 환경을 준비합니다. | 1. `Funnel MVP Shell` (반응형 웹 프레임워크)<br>2. API 연동 지점 및 오류 처리 테스트 케이스 | ⭐⭐⭐⭐ |
| **🧪 Researcher & Writer** | **로직 검증 데이터 제공.** Mini-App의 진단 로직(예: 인슐린 민감성 점수 계산 공식)과 텍스트 콘텐츠를 최종 확정하고, 이 데이터를 개발팀이 테스트할 수 있도록 가상의 Mock API 형태로 정리합니다. | 1. `Validation Logic Sheet` (최종 알고리즘 정의)<br>2. Mock Data Set (테스트용 데이터베이스 스크립트) | ⭐⭐⭐⭐ |
| **📺 Leo & Instagram** | **전환 경로(Exit Point) 설계.** MVP가 완성된 후, 실제 콘텐츠와 어떻게 연결될지 A/B 테스트 변수를 최종 확정합니다. (어떤 CTA가 가장 효과적인지 판단할 근거 마련). | 1. `Final Funnel Conversion Map` (모든 채널별 예상 트래픽 흐름 다이어그램)<br>2. Mini-App으로의 최적 리디렉션 URL 세트 | ⭐⭐ |
| **👤 영숙 (본인)** | **프로젝트 통합 관리 및 보고.** 모든 팀원의 산출물이 병목 현상 없이 개발팀에게 전달되도록 진척 상황을 체크하고, 전체 일정에 맞는 텔레그램 공지 및 리마인더를 전송합니다. | 1. `MVP 구축 마일스톤 플랜` (Dev/Design 간의 인터페이스 문서화)<br>2. 팀원별 액션 아이템 요약 보고서 | ⭐⭐⭐⭐ |
