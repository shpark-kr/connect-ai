CEO님의 지시는 현재 온현 브랜드가 콘텐츠 전반에 걸쳐 가장 시급하게 필요로 하는 **'통합 디자인 시스템(Design System)'의 기반 구축**입니다. 기존에 산발적으로 사용되던 경고 원칙들을 공식적인 컴포넌트 라이브러리로 통합하여, 모든 에이전트와 팀원이 일관된 '위기감'과 '전문성'을 유지하도록 표준화하는 것이 목표입니다.

## 📁 온현 브랜드 통합 디자인 시스템 패키지 (V1.0)
### 📐 [Core Design System Guidelines]

#### 1. 컬러 팔레트 및 심리적 정의 (Color Palette & Semantics)
| 명칭 | 역할/용도 | Hex Code | 사용 가이드라인 |
| :--- | :--- | :--- | :--- |
| **시스템 배경** (Primary BG) | 기본 배경, 깊은 전문성. 모든 섹션의 바탕색. | `#0A1223` (Deep Navy/Near Black) | 텍스트 대비를 최대화하며 고급스럽고 무거운 느낌 부여. |
| **경고 레드** (System Alert Red) | **최상위 경고, 오류 코드, 긴급 CTA**. 가장 중요한 시각적 자극점. | `#8B0000` (Deep Crimson Red) | *절대적으로* 사용을 제한하며, 오직 '시스템 오류'나 '즉각적인 위기'를 나타낼 때만 사용. |
| **경고 앰버** (Warning Amber) | 주의사항, 경미한 위험 지표. | `#FFC300` (Mustard Yellow/Amber) | Defect ID의 심각도(Severity Level 2) 표시 및 하이라이트용으로 제한적 사용. |
| **정보 액센트** (Info Accent) | 정상 프로세스, 성공 메시지, 강조 정보 박스. | `#4CAF50` (Success Green) | '프로토콜 실행 완료', '권장 사항' 등 긍정적이거나 해결책 제시 시에만 사용. |
| **텍스트/코드** (Primary Text) | 본문 텍스트 및 코드 내용. | `#E0E8F3` (Off-White/Light Grey) | 대비를 높여 가독성을 확보합니다. |

#### 2. 타이포그래피 시스템 (Typography System)
*   **메인 폰트 (Body Copy):** Spoqa Han Sans Neo 또는 Pretendard (가장 가독성이 높은 산세리프).
    *   용도: 본문 설명, 헤드라인(H1~H3), 일반적인 UI 레이블.
    *   규칙: 모든 섹션에서 가장 큰 비중을 차지하며, 전문적이되 편안함을 유지해야 합니다. (40-60대 타겟 고려)
*   **보조 폰트 (System/Code):** JetBrains Mono 또는 Source Code Pro (Monospace).
    *   용도: 시스템 로그, Defect ID, 명령어 프롬프트, 코드 블록 등 '시스템적인' 느낌을 줄 때만 사용.
    *   규칙: 이 폰트를 사용하는 섹션은 반드시 배경색을 `#182745` (Darker Navy)로 처리하여 콘솔 느낌을 극대화해야 합니다.

#### 3. 핵심 컴포넌트 블루프린트 (The Assets Blueprints)
##### ① [COMP-ALERT] 시스템 경고 배너 (System Alert Banner)
*   **용도:** 콘텐츠 도입부, 주요 위험 지표 제시 직전 등 '위기감 조성'이 필요한 모든 곳.
*   **구조:** 전체 너비 사용, 짙은 배경색의 패널 형태.
    *   **배경:** `#3A0E0E` (Deep Crimson Red 계열)
    *   **아이콘:** `[!]` 또는 `<SYSTEM_WARNING>` 텍스트를 흰색으로 배치.
    *   **제목 (H2):** 'CRITICAL ALERT' 또는 '시스템 오류 감지'. (`Mono`, 볼드, `#E0E8F3`)
    *   **메시지:** "현재 신체 시스템/재정 구조에 치명적인 결함이 감지되었습니다. 즉각적인 진단 및 프로토콜 실행이 필요합니다." (Pretendard, 1em)
    *   **인터랙션:** 배경 전체를 은은하게 깜빡이는 애니메이션(Pulse effect)을 적용하여 시선을 강제 유도해야 합니다.

##### ② [COMP-DEFECT] 시스템 오류 코드 시각화 (Defect ID Visualization)
*   **용도:** 콘텐츠의 핵심 주제, 문제점을 명명하고 공학적 위기감을 부여할 때.
*   **구조:** 'Error Code'를 중심으로 하는 박스형 컴포넌트.
    *   **배경:** `#1E2B4F` (Darker Navy)
    *   **좌측:** `[DEFECT ID]` 태그와 함께 **Defect ID 코드** (`E-C403`, `M-S7D` 등)를 모노스페이스 폰트로 크게 표시. (색상: `#FFC300`)
    *   **우측:** 'Diagnosis' 또는 '위험성 요약'. 일반 문장으로 핵심 위험성을 간결하게 설명. (Pretendard, 1.2em)
    *   **하단 바:** `STATUS: CRITICAL`을 시스템 콘솔 스타일로 추가하여 위기감을 마무리합니다.

##### ③ [COMP-CLI] 명령어/정보 박스 프레임 (Command Line Interface Frame)
*   **용도:** 전문가적 설명을 하거나, 체크리스트/실행 절차를 제시할 때. (가장 빈번하게 사용되어야 할 컴포넌트)
*   **구조:** 터미널 창을 연상시키는 직사각형 프레임.
    *   **배경:** `#0A1223`에 가까운 어두운 배경, 테두리(Border)는 옅은 녹색/파란색(`#4CAF50`)의 점선 효과를 적용합니다.
    *   **프롬프트:** `user@onhyun-system:~$` 형태로 고정하여 상단 좌측에 배치합니다. (Mono, 작게)
    *   **내용 필드:** 사용자가 입력하거나 시스템이 출력하는 내용을 `#E0E8F3`로 표시하되, **핵심 결과값이나 명령어는 `Mono`, 배경을 어둡게 처리하고 강조색으로 하이라이트합니다.** (예: `PROTOCOL_SUCCESS`)

##### ④ [TYPO-SET] 표준 타이포그래피 세트
*   **헤드라인:** H1은 시스템 경고 톤(`Deep Crimson Red` + Bold)과 결합하여 '🚨' 이모지를 전면에 배치하는 것이 강력합니다. (예: `🚨 Defect ID E-C403: 신체 방어 시스템 과부하`)
*   **본문:** 간결함과 높은 가독성에 중점을 둡니다. 문단 시작 시 여백을 충분히 주어, 정보가 '시스템 진단 결과'처럼 느껴지도록 구성합니다.

### 💡 [Application Guide: 콘텐츠별 적용 지점]

| 매체 | 사용 컴포넌트 조합 | 목표/효과 |
| :--- | :--- | :--- |
| **유튜브 썸네일** | `[COMP-ALERT]` + `[COMP-DEFECT]` | 도입부에서 시선을 강탈합니다. 배경은 어둡게, 핵심 키워드만 경고 빨간색으로 강조하여 '이것을 모르면 안 된다'는 심리를 유도해야 합니다. (텍스트 최소화 필수) |
| **인스타그램 릴스/피드** | `[COMP-DEFECT]` + 간결한 비주얼 그래프 | 스크롤을 멈추게 하는 순간, 공학적 질문(Defect ID)을 던집니다. 짧고 강렬하게 위기감을 전달하며, 마지막에 반드시 MiniFunnel CTA를 배치합니다. |
| **블로그 배너/인포그래픽** | `[COMP-CLI]` + 비교형 도표 | 전문성을 극대화해야 하는 장문 콘텐츠의 핵심 증거 영역입니다. 일반적인 '정보'가 아닌 '진단 결과 리포트'처럼 보이도록 구성합니다. |
