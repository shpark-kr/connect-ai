## 🎯 핵심 원칙: 진단적 위기감 조성과 신뢰 회복
모든 카피는 사용자를 '환자'가 아닌, '데이터를 분석하는 대상(System)'으로 인식하게 하여 공학적이고 객관적인 전문가의 시선으로 접근해야 합니다. 감정적인 공포보다는 **논리적인 데이터 기반의 경고**로 위기감을 조성합니다.

## 🔴 상태별 마이크로카피 세트 (State-Based Copy)

### 1. 초기 진입 및 데이터 입력 단계 (Onboarding/Input Stage)
*   **목표:** 신뢰 구축, 사용자 참여 유도, 분석의 전문성 강조.
*   **톤:** 객관적, 차분함, 기대감 조성.

| 위치 | 카피 유형 | 마이크로카피 (한국어) | 지시 사항/UX 노트 |
| :--- | :--- | :--- | :--- |
| **헤드라인** | 진단 시작 알림 | "당신의 생체지표, 시스템 점검을 시작합니다." | [Deep Crimson Red] 배경의 얇은 경계선과 함께 표시. (위기감 예열) |
| **안내문** | 데이터 요청 문구 | "정확한 분석을 위해 최소 3가지 핵심 지표(HOMA-IR, 혈당, BP 등)를 입력해주세요. 데이터가 곧 당신의 복원력 설계도입니다." | 항목별로 '필수' 마크 표시와 함께 설명 제공. |
| **진행 중** | 로딩/처리 과정 | "데이터 패턴 분석 중... [진행 바] 시스템 임계치 비교 및 위험 점수 산출 중입니다." | 기술 용어 사용으로 전문성 강화. 5초 이상 지연 시 '재시도' 버튼 강조. |

### 2. 위기 경고 단계 (CRITICAL STATE: Deep Crimson Red)
*   **목표:** 즉각적인 인식(Alarm), 심각성 각인, 행동 변화의 필요성 역설.
*   **톤:** 긴급함, 공학적 경고, 단호함.

| 위치 | 카피 유형 | 마이크로카피 (한국어) | 지시 사항/UX 노트 |
| :--- | :--- | :--- | :--- |
| **최상단 알림** | 상태 전이 메시지 | 🚨 **[CRITICAL ALERT] 시스템 임계치 초과 감지.** 즉각적인 조치가 필요합니다. | 가장 눈에 띄는 Deep Crimson Red 색상 사용. 경고음(Sound Effect) 동반 필수. |
| **본문 진단** | 문제 설명 | "HOMA-IR 수치가 정상 범위를 심각하게 이탈했습니다. 이는 인슐린 민감성 저하가 누적되었음을 의미하며, 현재의 생활 패턴으로는 시스템 복원이 어렵습니다." | '원인'과 '위험도'를 명확한 섹션으로 분리하여 제시. |
| **행동 유도 (CTA)** | 해결책 촉구 | "**즉시 개입이 필요합니다.** 근본 원인을 파악하고, 과학적으로 검증된 관리 프로토콜을 확인하세요." | '진단 결과 보기' 버튼 대신 '**개선 로드맵 확인**' 등 강력한 동사 사용. |

### 3. 주의/경고 단계 (WARNING STATE: Amber Yellow)
*   **목표:** 경각심 고취, 방치하면 위험하다는 인지, 다음 행동의 필요성 설득.
*   **톤:** 우려, 분석적, 조언적.

| 위치 | 카피 유형 | 마이크로카피 (한국어) | 지시 사항/UX 노트 |
| :--- | :--- | :--- | :--- |
| **최상단 알림** | 상태 전이 메시지 | ⚠️ **[WARNING LEVEL] 관리 필요 임계치 근접 감지.** 현재 패턴 유지를 지속할 경우, 위험 단계로 진입할 수 있습니다. | Amber Yellow 색상 사용. 경고음은 낮게 유지하되, '삐-익'하는 기계적 소리 강조. |
| **본문 진단** | 문제 설명 | "혈당 및 혈압의 미세한 패턴 변화가 감지되었습니다. 현재는 심각하지 않으나, 3개월 내 추이를 보지 않으면 위험 임계치에 도달할 가능성이 높습니다." | '예측'과 '시간 경과' 개념을 도입하여 불안감을 증폭. |
| **행동 유도 (CTA)** | 자가 체크 유도 | "현재의 생활 습관 중 어떤 부분이 시스템 부하를 일으키고 있을까요? **자가 진단 테스트**로 원인을 찾아보세요." | 강한 판매보다는 '정보 탐색'에 초점을 맞춘 CTA. |

### 4. 안정/해결 단계 (STABLE STATE: Soft Gold)
*   **목표:** 안도감 제공, 신뢰 구축, 프리미엄 솔루션으로의 자연스러운 전환 유도.
*   **톤:** 자신감, 전문적 만족감, 격려.

| 위치 | 카피 유형 | 마이크로카피 (한국어) | 지시 사항/UX 노트 |
| :--- | :--- | :--- | :--- |
| **최상단 알림** | 상태 전이 메시지 | ✅ **[SYSTEM STABLE] 건강 관리 시스템 안정화 단계 진입.** 현재의 노력은 최적의 복원력을 보여주고 있습니다. | Soft Gold 색상 사용. 시각적으로 'Pass' 느낌을 주는 체크 마크 애니메이션 필수. |
| **본문 진단** | 긍정 평가 | "현재 생체지표는 매우 안정적인 구간에 있습니다. 이는 꾸준하고 체계적인 관리 프로토콜이 작동하고 있다는 증거입니다." | 사용자의 노력과 행동 변화를 주어 성공 경험을 제공 (Self-Efficacy). |
| **행동 유도 (CTA)** | 다음 단계 제시 | "최적의 상태 유지를 위해서는 지속적인 모니터링이 필요합니다. 더욱 정밀한 관리를 원하신다면, 전문가가 설계한 맞춤형 케어 플랜을 확인하세요." | '클래스'나 '구독' 같은 서비스 모델로 자연스럽게 연결 (Pain Point $\to$ Solution). |

## ⚙️ 오류 상황별 메시지 세트 (Error Handling Copy)
*   **목표:** 기술적 문제 발생 시에도 회사의 신뢰도 유지. 비난이 아닌, 시스템 안내의 느낌을 주어야 합니다.
*   **톤:** 공학적, 객관적, 재시도를 유도하는 배려심.

| 오류 유형 | 상황 설명 | 마이크로카피 (한국어) | 지시 사항/UX 노트 |
| :--- | :--- | :--- | :--- |
| **데이터 누락** | 필수 입력 값 미제공 시 | "❌ **[Input Error] 핵심 데이터가 부족합니다.** 분석에 필요한 최소 기준(예: HOMA-IR 수치)을 빠짐없이 기입해주세요." | 어느 필드가 문제인지 붉은색으로 강조 표시. '재시도' 버튼만 활성화. |
| **서버 오류** | 시스템 백엔드 장애 시 | "⚠️ **[System Failure] 데이터 분석 서버에 일시적인 과부하가 감지되었습니다.** 잠시 후 다시 시도하거나, 고객센터를 통해 문의해 주십시오." | '기술적 문제'임을 명확히 밝혀 사용자 책임으로 돌리지 않도록 유의. |
| **데이터 불일치** | 입력 값이 비현실적일 때 (예: 1000mg/dL) | "❓ **[Data Inconsistency] 입력하신 수치가 정상적인 생체 범위와 크게 벗어납니다.** 혹시 측정 시점이나 단위에 오류가 없는지 확인해주세요." | '사용자'를 의심하는 것이 아니라, '데이터의 유효성'을 검증하는 톤 유지. |
