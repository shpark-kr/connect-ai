# 📋 작업 브리프

**원 명령:** 지금 블로그 결과물에서 아래의 내용을 수정해서 반영해줘.
1. 텍스트로만 되어있는 글은 이탈율을 방지할 수 없어. 직관적으로 눈에 띄는 이미지가 필수이고 수치화 한 그래프 이미지도 필요해.  글의 제목 아래 텍스트 시작하기 전 대표 이미지가 하나 있어야 하고 글 중간에 그래프, 도표 같은것이 나오고 제일 마지막에는 슬로건 같은걸 이미지로 표현하면 좋을꺼 같아. 하나의 글에는 평균 4개 이상의 이미지를 사용해서 글을 작성해.
2. 제목 끝에  (문제 제기),  (가장 큰 위협), (근거 제시) 같은 요약 첨언 내용은 삭제해줘.  그냥 제목만 있는게 더 좋은거 같아.

## 요약
기존 블로그 콘텐츠의 가독성과 전문성을 극대화하기 위한 전반적인 형식 수정 작업입니다. 텍스트 위주의 글을 시각 자료 중심으로 재구성하고, 제목에 붙어 있는 부가 설명 태그를 제거하는 것이 핵심입니다.

## 분배
- **✍️ Writer**: 1. 모든 블로그 콘텐츠의 제목에서 (문제 제기), (가장 큰 위협), (근거 제시)와 같은 내용 요약 첨언 태그를 완전히 삭제하고, 순수한 핵심 주제명만 남겨주십시오.
2. 텍스트 내용을 구조화하여 각 단락별로 '어떤 종류의 데이터(예: 그래프, 비교표, 통계 수치)'가 필요하며, 해당 시각 자료가 블로그 내 어느 위치에 삽입되어야 가장 효과적인지 상세한 배치 가이드라인을 작성해 주십시오.
- **🎨 Designer**: 1. 새로운 콘텐츠 구조 원칙(대표 이미지 $\rightarrow$ 본문 그래프/도표 2~3개 $\rightarrow$ 슬로건 이미지)에 맞춰 블로그 포맷의 디자인 시스템을 재정립하십시오. (다크 네이비/골드톤 유지)
2. Writer가 제공한 배치 가이드라인과 데이터 유형(수치화된 그래프, 비교 도표)을 기반으로, 각 콘텐츠마다 평균 4개 이상의 고해상도 이미지 에셋(대표 이미지용 배너, 본문 삽입 그래프/차트, 최종 슬로건/CTA 이미지)의 디자인 브리프와 초안을 제작하십시오.
