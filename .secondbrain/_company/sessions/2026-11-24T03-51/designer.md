## 🔴 A/B 테스트 CTA 버튼 시스템 디자인 브리프 (3종 세트)

### 🎨 공통 컬러 및 타이포그래피 정의
| 요소 | 코드 | 역할 | 비고 |
| :--- | :--- | :--- | :--- |
| **Deep Navy** (Primary Background) | `#0A1931` | 기본 배경, 신뢰성 기반 문구. 전문성을 유지하는 바탕색. | 전체 UI의 메인 컬러. |
| **Alarm Red** (Accent/Danger) | `#CC3333` | 경고, 긴급성, 위험 임계점. 시선을 강하게 잡아끄는 색상. | 버튼 활성화 및 강조에 사용. |
| **Secondary Gold** (Callout) | `#D4AF37` | 희망/기회 비용 강조. 긍정적 전환을 유도하는 포인트 컬러. | 보조적인 안내 문구에 활용. |
| **Typography** | Noto Sans KR Bold / SemiBold | 가독성 최우선. 'Bold'는 긴급성을, 'SemiBold'는 정보를 전달할 때 사용. |

### 🟢 Version 1: 궁금증 유발형 CTA (Low-Friction Conversion)
*   **심리적 단계:** 초기 탐색, 낮은 위협감. 정보 제공에 초점을 맞춘 사용자에게 적합합니다.
*   **목표:** 진입 장벽을 낮춰 '정보 수집' 자체를 목표로 합니다. (낮은 마찰력)
*   **디자인 컨셉:** **'호기심 유도형 버튼'**. 빨간색의 과한 사용을 지양하고, 네이비 배경에 부드럽게 포인트를 주어 접근성을 높입니다. 마치 궁금증을 해결해 줄 안내문 같은 느낌을 줍니다.

| 스펙 | 내용 |
| :--- | :--- |
| **추천 문구** | "나의 위험 점수, 간단히 확인해 보세요." / "5분짜리 무료 진단 받기" |
| **시각적 요소** | 네이비 배경에 은은한 `Secondary Gold` 그라디언트 테두리를 적용. 텍스트는 Navy White로 처리하여 가독성을 극대화합니다. |
| **CSS/Tailwind 지향** | `bg-[#0A1931] border-2 border-[#D4AF37] text-white hover:border-[#CC3333] transition duration-300` |
| **UX 가이드** | 클릭 시, 즉각적인 '실패' 메시지 대신 "진단 과정이 필요합니다" 같은 긍정적 안내 페이지로 연결되어야 합니다. |

### 🟡 Version 2: 즉각적 경고형 CTA (Mid-Friction Conversion)
*   **심리적 단계:** 불안감 고조, 개인화된 위협 인지. "당신에게 문제가 있다"는 직접적인 경고를 전달합니다.
*   **목표:** '무료 진단'이라는 구체적이고 가치 있는 행동을 요구합니다. (중간 마찰력)
*   **디자인 컨셉:** **'경계 임박형 버튼'**. 네이비 배경에서 Alarm Red의 비중이 높아지기 시작하며, 긴급성이 느껴지는 텍스처를 부여합니다. 시각적으로 '주의'를 주고 있습니다.

| 스펙 | 내용 |
| :--- | :--- |
| **추천 문구** | "지금 바로 [비용] 무료 진단 받아보기" / "손실 막기, 전문가 상담 예약하기" |
| **시각적 요소** | 버튼 배경을 `Alarm Red` 계열의 채도 높은 색상으로 변경하고, 네이비 텍스트를 사용해 경고 메시지 자체에 무게감을 부여합니다. (Red Button, Navy Text) |
| **CSS/Tailwind 지향** | `bg-[#CC3333] text-white border-2 border-[#992222] hover:scale-[1.02] shadow-lg` |
| **UX 가이드** | 클릭 시, 명확한 '진단 예약 폼'으로 연결되어야 하며, 이 과정에서 시간적 흐름(카운트다운)이 함께 작동하는 것이 가장 효과적입니다. |

### 🔴 Version 3: 강제 선택 유도형 CTA (High-Commitment Conversion)
*   **심리적 단계:** 패닉 상태, 손실 회피 본능 자극. "지금 행동하지 않으면 더 큰 위험에 빠진다"는 느낌을 극대화합니다.
*   **목표:** '유료 상담/컨설팅 예약'이라는 가장 높은 수준의 전환(High-Commitment)을 유도합니다. (높은 마찰력, 강제성)
*   **디자인 컨셉:** **'비상 경고형 버튼'**. Alarm Red가 지배적인 색상을 가지며, 시각적으로 '멈춤', '위험'의 이미지를 극대화합니다. 애니메이션 효과(플래시/진동)를 반드시 적용해야 합니다.

| 스펙 | 내용 |
| :--- | :--- |
| **추천 문구** | "🚨 추가 손실 방지, 필수 컨설팅 예약하기" / "늦기 전에 지금 바로 대책 마련하세요." |
| **시각적 요소** | 배경과 텍스트 모두 Alarm Red를 사용하며, 버튼 주변에 미세한 플래시 효과(Animation)와 그림자 효과(Shadow)를 넣어 '🚨 경고'의 느낌을 극대화합니다. (Red Button, White Text) |
| **CSS/Tailwind 지향** | `bg-gradient-to-r from-[#CC3333] to-[#992222] text-white animate-pulse shadow-[0_0_15px_rgba(204,51,51,0.8)]` |
| **UX 가이드** | 이 단계에서는 단순 문의가 아닌, '필수 비용 안내'와 함께 예약 시스템으로 연결되어야 하며, 행동을 미루면 발생하는 금전적/신체적 손실 예측 그래프를 재차 노출시켜야 합니다. |
