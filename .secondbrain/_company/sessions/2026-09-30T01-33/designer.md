# 🚨 [디자인 시스템] 위기감 조성 비주얼 에셋 (V2.0)

## 🎨 공통 디자인 가이드라인 및 원칙
*   **콘셉트:** CLI(Command Line Interface) 기반의 서버 콘솔 대시보드 / 진단 장비 UI.
*   **핵심 색상 팔레트:**
    *   `#1A1A2E` (Dark Navy/Charcoal): 메인 배경색 (깊은 밤, 시스템 모드).
    *   `#A80000` (Deep Crimson Red): **경고(ALERT)** 메시지, 실패 지점 하이라이트.
    *   `#38FF9B` (Electric Green/Cyan): 정상 작동/성공 프로토콜 (참조용).
    *   `#FFFFFF`: 본문 텍스트.
*   **타이포그래피:** Monospace Font 필수 (예: Fira Code, Source Code Pro 등). 가독성을 위해 제목과 경고 메시지에는 대문자 사용을 원칙화합니다.
*   **필수 그래픽 요소:** 그리드 패턴 오버레이(Grid Overlay), 노이즈/스캔라인 효과(Scanline Effect), 깜빡이는 커서 블록(`█`), 시스템 접속 오류 아이콘(⚠️).

| 영역 | 요소 | 내용 및 스타일링 지침 | 목적 |
| :--- | :--- | :--- | :--- |
| **배경 (Background)** | 그리드/콘솔 배경 | `#1A1A2E` 색상의 어두운 공간에 미세한 회로 기판(Circuitry) 패턴을 오버레이. 전체적으로 노이즈가 있는 듯한 필터 적용. | 전문성 및 하이테크 위기감 조성. |
| **① 메인 제목 (Headline)** | Defect ID 명시 | 가장 크고 강력하게 배치. `#A80000`로 텍스트를 강조하고, 좌우에 `[ALERT]` 태그 추가. (예: `🚨 [DEFECT-ID: M-DISFUNC]`) | 시청자의 주의 집중 및 전문 용어 제시. |
| **② 서브 타이틀 (Problem)** | 핵심 Pain Point 요약 | Defect ID를 풀어쓴, 일반인이 공감할 만한 문구. `#FFFFFF` 폰트. (예: *“단순 피로는 아닙니다.”*) | 시청자의 공감을 얻어 콘텐츠로 유입시키기 위함. |
| **③ 증거/근거 (Proof)** | 진단 결과 패널 | 화면 하단에 가상의 '진단 시스템 결과' 박스 배치. 배경은 어두운 네이비, 테두리만 빨간색(`A80000`)으로 빛나게 처리. 여기에 "시스템 전력 효율: ⚠️ CRITICAL FAILURE (21%)"와 같은 수치를 넣어 공포감 극대화. | 정보의 권위성을 부여하고, 문제의 심각도를 시각적으로 증명. |
| **④ CTA/후킹** | 해결책 제시 (미스터리) | 우측 하단 또는 좌측 상단에 작은 박스로 "진짜 문제는...?" 같은 질문형 문구와 함께 MiniFunnel 진단 페이지로 연결되는 듯한 미니멀한 UI 요소를 배치. | 영상 시청을 유도하고, 다음 행동(MiniFunnel)의 필요성을 심기 위함. |
