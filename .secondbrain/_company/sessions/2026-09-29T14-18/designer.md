# 🎨 Designer — writer가 제공할 최종 릴스 스크립트 5개를 바탕으로, 각 콘텐츠의 핵심 주제를 압축한 '썸네일/커버 이미지 세트' 5종을 디자인해 주세요. 이 이미지는 Deep Crimson Red 테마와 공학적 오류 코드(예: ERROR CODE: PENS-404)를 활용하여 시각적인 권위감과 위기감을 동시에 전달할 수 있도록 제작해야 합니다.

🎨 Designer: 작업 시작합니다.

요청하신 대로, Writer가 제공한 '공학적 위기감' 콘셉트를 극대화하여, 릴스 스크립트 5개에 사용할 **통일된 비주얼 시스템(Visual System)**을 적용한 썸네일/커버 이미지 세트 디자인 브리프를 작성합니다.

모든 이미지는 단순히 '붉다'가 아니라, 마치 시스템이 실제로 경고창을 띄우는 듯한 **기술적 권위감**을 최우선 목표로 합니다.

### ⚙️ [공통 비주얼 가이드라인]

*   **테마:** Deep Crimson Alert (깊은 진홍색 경고)
*   **메인 컬러 팔레트:**
    *   Primary Background: `#121212` (Deep Black/Dark Gray - 기술적 배경)
    *   Alert Color 1 (주요 경고): `#8B0000` (Deep Crimson Red - 위기감 조성)
    *   Alert Color 2 (강조점/코드): `#FFD700` (Gold Yellow - 중요 정보/진단 결과)
    *   Text Color: `#EAEAEA` (Off-White - 가독성 확보)
*   **타이포그래피:**
    *   Headings/Titles: `Roboto Mono` 또는 시스템 기본 코딩 폰트 느낌의 Monospaced 폰트 사용. (권위감 증대)
    *   Body Text: `Noto Sans KR` (가독성 최우선).
*   **레이아웃:** 모든 썸네일은 9:16 비율(릴스/숏폼 표준)을 유지합니다. 핵심 정보는 중앙에 배치하고, 배경에는 미세한 회로 기판 패턴(`Grid Pattern`)을 오버레이하여 기술적 느낌을 강화합니다.

### 🔴 [핵심 디자인 컴포넌트 정의]

모든 썸네일에 공통으로 포함되어야 할 요소입니다.

1.  **시스템 경고 바 (System Alert Bar):**
    *   위치: 이미지 최상단 또는 하단에 가로 스트라이프 형태로 배치.
    *   색상: Deep Crimson Red (`#8B0000`).
    *   내용: `[SYSTEM ALERT] | CRITICAL DIAGNOSIS REQUIRED` (작은 폰트로 반복 배치).
2.  **오류 코드 블록 (Error Code Block):**
    *   위치: 우측 상단 또는 좌측 하단의 별도 박스 처리.
    *   스타일: 검은색 배경에 Gold Yellow 글씨로 `ERROR CODE: [코드]` 포맷 사용.
3.  **후크 문구 (Headline):**
    *   크기: 가장 크고 굵게 배치. Deep Crimson Red와 Off-White를 교차 사용하여 강렬하게 대비시킵니다.

### ✨ [5가지 콘텐츠별 썸네일 디자인 브리프]

다음은 스크립트의 주제에 맞춰 전문성과 위기감을 극대화한 3가지 변형 시각화 브리프입니다. (A/B 테스트용)

#### **1. 관절 시스템 오류 (JSE-404)**
*   **핵심 메시지:** 단순 통증이 아닌, 구조적 고장이다.
*   **시각 요소:** 뼈/관절의 X-ray 혹은 공학적 단면도 이미지 활용.

| 버전 | 제목 및 코드 | 컨셉 설명 | 강조 포인트 (A/B 테스트) |
| :--- | :--- | :--- | :--- |
| **A (구조 분석형)** | **CRITICAL ERROR: JSE-404**<br>관절 연골, 임계점 도달. | 무릎 관절의 공학적 단면도(Cross-Section)를 메인 이미지로 사용. 마모된 부분에 Deep Crimson Red 하이라이트를 적용하고, 주변부에는 깨진 회로 패턴을 오버레이합니다. | **'구조적 손실'**이라는 전문 용어를 전면에 배치하여 권위를 확보합니다. (전문가 시청자 유도) |
| **B (위협 경고형)** | **[SYSTEM ALERT] 무릎 관절, 기능 부전 진입.**<br>지금 당장 멈춰야 합니다. | 화면 절반을 Deep Crimson Red 경고창으로 가득 채우고, 나머지 절반에 건강한/손상된 연골 이미지를 극명하게 대비시킵니다. 중앙에 비포-애프터 화살표를 배치합니다. | **'즉각적인 행동 촉구'**와 '경계심 조성'에 집중합니다. (클릭 유도력 강화) |
| **C (질문 제기형)** | 연골 마모, 자연 현상이 아닙니다.<br>진단받지 않은 위험 신호 3가지. | 질문 형태의 제목을 전면에 배치하고, 배경으로 인체 시스템 다이어그램(Joint System Model)을 은은하게 깔아 전문적인 느낌만 유지합니다. | **'Pain Point 자극'**에 초점을 맞추어 호기심을 유발합니다. (탐색적 시청자 유도) |

#### **2. 에너지 효율성 저하 (PD-50)**
*   **핵심 메시지:** 나잇살은 단순 체중 문제가 아니다. 시스템 출력이 떨어진 것이다.
*   **시각 요소:** 배터리 잔량 게이지, 전력 흐름 다이어그램 활용.

| 버전 | 제목 및 코드 | 컨셉 설명 | 강조 포인트 (A/B 테스트) |
| :--- | :--- | :--- | :--- |
| **A (배터리 방전형)** | **POWER DRAIN ALERT: PD-50**<br>기초대사량, 비상 전력 상태. | 화면 중앙에 거대한 배터리 게이지를 배치하고, 잔량이 20% 미만인 Deep Crimson Red로 표시합니다. 아래쪽에 '활동성 감소율 그래프' 같은 공학적 데이터를 삽입합니다. | **가장 직관적인 위기감**을 조성하여 즉각적인 문제 인식을 유도합니다. (대중 시청자 적합) |
| **B (시스템 로직형)** | 근육은 엔진입니다. 지금, 출력이 급격히 떨어지고 있습니다. | 사람이 에너지를 사용하는 과정(Activity Cycle)을 나타내는 공학적 흐름도를 배경에 배치하고, '근력 감소 곡선'이 가파르게 하락하는 그래프를 중심으로 보여줍니다. | **'시스템 작동 원리'**에 대한 설명을 통해 높은 수준의 전문성을 전달합니다. (지식 탐구형 시청자 적합) |
| **C (대비 증폭형)** | 10년 전 VS 오늘: 당신의 엔진 효율은? | 왼쪽(과거/이상적 상태): 밝고 강력한 녹색 계열로, 오른쪽(현재/실제 상태): Deep Crimson Red 경고 패턴으로 명확히 분할하여 대비시킵니다. 중앙에 'Δ Efficiency' 코드를 삽입합니다. | **극적인 비교**를 통해 시청자 스스로의 변화를 체감하게 합니다. (공감대 형성 최적화) |

#### **3. 혈관 순환/혈류 저하 (CV-XXX)**
*   **(가정 주제: 심혈관계 건강)**
*   **핵심 메시지:** 몸 안의 흐름(Flow)이 막히고 있다.
*   **시각 요소:** 파이프, 튜브, 유체 역학 다이어그램 활용.

| 버전 | 제목 및 코드 | 컨셉 설명 | 강조 포인트 (A/B 테스트) |
| :--- | :--- | :--- | :--- |
| **A (막힘 지점 시각화)** | **BLOOD FLOW WARNING: CV-XXX**<br>미세혈관, 협착 위험 감지. | 인체 내부의 혈관을 튜브처럼 표현하고, 특정 지점에서 Deep Crimson Red로 막히거나 좁아진(Stenosis) 부분을 확대하여 보여줍니다. 마치 파이프가 녹슬고 막힌 모습입니다. | **'구체적인 문제 부위'**를 시각화하여 공포와 전문성을 동시에 전달합니다. (명확한 경고 메시지) |
| **B (압력 게이지형)** | 혈관 압력, 안전 범위를 초과했습니다.<br>순환 시스템 점검 필요. | 거대한 아날로그/디지털 스타일의 '혈압/혈류 측정 게이지'를 메인으로 배치하고, 바늘이 Deep Crimson Red 위험 구역에 걸쳐 있도록 만듭니다. | **측정값 기반**의 위기감을 조성하여 객관적 데이터로 접근하게 합니다. (신뢰도 극대화) |

#### **4. 인지 기능 저하/뇌 시스템 오류 (COG-XXX)**
*   **(가정 주제: 기억력, 집중력)**
*   **핵심 메시지:** 뇌의 처리 능력이 느려지고 있다.
*   **시각 요소:** 회로 기판, 데이터 전송 플로우 차트 활용.

| 버전 | 제목 및 코드 | 컨셉 설명 | 강조 포인트 (A/B 테스트) |
| :--- | :--- | :--- | :--- |
| **A (오류 메시지 시뮬레이션)** | **PROCESSING ERROR: COG-XXX**<br>기억 회로, 연결 불안정. | 복잡한 뇌의 신경망(Neural Network) 이미지를 배경으로 깔고, 일부 연결된 노드(Node)가 Deep Crimson Red 점멸과 함께 끊어지는 애니메이션 효과를 부여합니다. (애니메이션 필수) | **'기술적 고장'**을 시각화하여 비과학적인 불안감을 공학적으로 치환시킵니다. (최강의 위기감 조성) |
| **B (데이터 과부하형)** | 뇌 정보 처리 속도, 임계점 도달.<br>지금부터 '디버깅'이 필요합니다. | 수많은 데이터가 너무 빠르게 지나치며 뇌를 압도하는 듯한 시각적 혼잡도를 연출하고, 중앙에 느려지거나 오류가 발생하는 지점을 Gold Yellow로 강조 처리합니다. | **정보 과부하**라는 현대인의 공통된 고충을 공학적 언어로 승화시킵니다. (공감대와 전문성 결합) |

#### **5. 피부 탄력/콜라겐 합성 저하 (DERM-XXX)**
*   **(가정 주제: 노화, 콜라겐 부족)**
*   **핵심 메시지:** 구조적 지지대가 무너지고 있다.
*   **시각 요소:** 섬유질, 그물망(Mesh), 건축 공학 다이어그램 활용.

| 버전 | 제목 및 코드 | 컨셉 설명 | 강조 포인트 (A/B 테스트) |
| :--- | :--- | :--- | :--- |
| **A (네트워크 붕괴형)** | **STRUCTURAL FAIL: DERM-XXX**<br>콜라겐 지지망, 파열 임박. | 피부의 단면을 미세한 그물(Mesh) 구조로 표현하고, 시간이 지나면서 이 그물이 Deep Crimson Red로 끊어지고 늘어나는 과정을 보여줍니다. (섬유질 공학 모델링) | **'구조적 실패'**라는 건축/공학 용어를 사용하여 단순 미용 문제를 학문적으로 접근합니다. (최고의 권위감) |
| **B (팽창력 저하형)** | 탄성계수(Elasticity Constant) 감소 경고.<br>피부는 더 이상 버티지 못합니다. | 고무줄이나 스프링처럼 늘어나는 물질의 공학적 모델을 배경에 배치하고, 시간이 지남에 따라 복원력이 약해지는 그래프와 함께 Deep Crimson Red 경고를 표시합니다. | **물리학/공학 용어**를 사용하여 학술적인 느낌을 강화하며 신뢰도를 높입니다. (지식 전달 목적) |
