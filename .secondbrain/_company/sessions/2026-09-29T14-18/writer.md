## 🚨 [Reels Script #1] 관절 시스템 오류 (Joint System Error: JSE-404)

**예상 길이:** 35~40초
**핵심 목표:** '만성 통증은 자연스러운 현상이 아니다'라는 인식을 심어주고 진단 유도.

| 시간대 | 비주얼 지시 (Visual Direction) | 스크립트/내레이션 (Voice Over Tone: 긴박하고 권위적) |
| :--- | :--- | :--- |
| **[0~3초] 후킹** | 화면 전체에 Deep Crimson Red 경고 애니메이션. 'SYSTEM FAILURE' 코드와 함께 `JSE-404` 표시. (강렬한 톤앤매너) | **(긴급 알림음 + 웅장한 나레이션)** "경고. 관절 시스템 안정성, 임계점 도달. 즉각적인 점검이 필요합니다." |
| **[3~15초] 문제 제기** | 일반인이 무릎을 아파하며 일상생활에 어려움을 겪는 슬로우모션 영상 클립 (통증 시각화). 그래프나 공학적 다이어그램 삽입. | "무릎이 아프면 당연한 거라고 생각하셨죠? 아닙니다. 이는 **관절 연골의 구조적 손실**을 의미합니다. 단순 통증이 아니라, 시스템 자체가 효율적으로 작동하지 못한다는 경고 신호입니다." |
| **[15~28초] 공학적 근거 제시** | '연골 마모도 그래프' 또는 '혈관 순환 저하 모델링' 등 전문적인 시각 자료가 빠르게 지나감. (전문성을 강조) | "문제는 단순히 뼈와 관절 사이의 간극이 벌어지는 데 그치지 않습니다. 연골은 자가 복구 능력이 극히 낮습니다. 시간이 지날수록 **미세한 염증 반응**과 **만성적인 영양 결핍**이 누적되어, 기능 부전 상태로 진입하는 겁니다." |
| **[28~35초] CTA & 해결책 제시** | 화면 배경이 안정된 파란색/녹색 계열로 전환. 전문 상담사가 신뢰감 있게 등장. '진단 프로토콜 실행' 버튼 강조. | "억지로 참지 마세요. 이 상태를 방치하면 걷는 것 자체가 고장 납니다. **가장 중요한 것은, 현재 시스템의 정확한 진단부터 받는 겁니다.** 지금 바로 [프로필 링크]에서 무료 진단 프로토콜을 실행하세요." |

## 🔥 [Reels Script #2] 에너지 효율성 저하 (Power Drain Alert: PD-50)
**주제:** 나잇살, 근력 감소와 기초대사량 저하 (효율성 위기감 자극형)
**예상 길이:** 30~35초
**핵심 목표:** '나이가 들어서'가 아닌 '시스템이 효율적이지 않아서' 문제가 생겼다는 인식을 주어 해결책을 판매.

| 시간대 | 비주얼 지시 (Visual Direction) | 스크립트/내레이션 |
| :--- | :--- | :--- |
| **[0~3초] 후킹** | 'WARNING: Metabolic Efficiency Low' 문구와 함께 배터리가 급격히 방전되는 애니메이션. Deep Crimson Red 경고음. | **(경고 알림음)** "비상! 현재 대사 시스템, 효율성 50% 이하로 떨어졌습니다." |
| **[3~12초] 문제 제기** | 젊은 사람과 나이든 사람이 비슷한 활동을 하지만, 에너지 소모와 회복 속도에서 극명하게 차이가 나는 비교 영상. (A/B 비교 구조) | "예전 같지 않다? 그게 전부가 아닙니다. 단순히 몸무게가 늘어난 게 아니라, 우리 몸의 **에너지 생산 공장(미토콘드리아)** 가 고장나고 있다는 신호입니다." |
| **[12~25초] 전문 지식 강조** | '근육은 에너지 저장소'라는 메시지를 중심으로, 근섬유와 지방 세포가 대비되는 다이어그램 제시. 과학적인 용어(ATP, 대사율) 언급 시 자막 처리. | "나이가 들면 가장 먼저 잃는 건 무엇일까요? 바로 **제2의 호르몬**을 만드는 근육입니다. 이 근육이 부족하면, 아무리 좋은 식단도 에너지로 전환되지 못하고 지방으로 저장되는 악순환에 빠집니다." |
| **[25~35초] CTA & 해결책 제시** | 상담사 등장. '시스템 재부팅' 같은 비주얼 효과와 함께 권위적인 톤 유지. | "이 낮은 효율성은 방치하면 만성 질환으로 이어지는 치명적 결함입니다. 근본적인 원인 진단부터 해야 합니다. **지금 바로 프로필 링크를 통해 개인화된 신체 시스템 점검을 받아보세요.**" |

## 🧠 [Reels Script #3] 인지 기능 데이터 손상 (Memory Data Corruption: MDC-50)

**예상 길이:** 30~38초
**핵심 목표:** '기억력 저하'를 단순히 스트레스 때문이 아닌 '뇌 시스템의 데이터 손상'으로 규정하여 전문 진단 필요성 강조.

| 시간대 | 비주얼 지시 (Visual Direction) | 스크립트/내레이션 |
| :--- | :--- | :--- |
| **[0~3초] 후킹** | 'WARNING: Memory Data Corruption' 문구와 함께 데이터가 깨지거나 오류 코드(`MDC-50`)로 변하는 애니메이션. Deep Crimson Red. | **(데이터 오류음)** "주의! 핵심 정보 저장소, 메모리 코어에서 심각한 데이터 손상이 감지되었습니다." |
| **[3~15초] 문제 제기** | '내가 뭘 하려 했더라?' 같은 상황을 연출하거나, 일상 속에서 사물을 잊는 모습을 공감하게 보여줌. (공감대 형성) | "가끔 깜빡하는 건 자연스러운 현상이라 생각하셨죠? 하지만, 뇌과학은 다르게 말합니다. 이는 **신경 전달 물질의 불균형**과 **기억 회로 자체의 물리적 손실**이 진행되고 있다는 치명적인 경고입니다." |
| **[15~28초] 공학적/의학적 설명** | 뇌 사진에 '위험 구역'을 표시하는 듯한 그래픽 사용. 아세틸콜린, 신경 가소성 같은 전문 용어 등장 시 자막 처리. | "노화로 인한 건망증과 초기 치매 증상의 경계는 모호합니다. 핵심은 **손상 속도와 패턴**입니다. 방치된 기억력 문제는 단순히 약 먹고 해결되는 문제가 아니며, 전반적인 시스템의 재점검이 필수적입니다." |
| **[28~38초] CTA & 해결책 제시** | 상담사 등장. '뇌 기능 최적화 프로토콜 실행' 같은 문구를 강조. | "자가진단으로는 절대 모릅니다. 현재 뇌 시스템의 어떤 부분이, 어느 정도까지 손상되었는지 객관적인 데이터가 필요합니다. **지금 바로 [프로필 링크]를 통해 정밀한 인지 진단을 예약하세요.**" |
