### 📝 Expert Widget Component Library Specification v1.0

본 문서는 '전문가 진단' 섹션에 사용될 모든 컴포넌트의 디자인, 인터랙션 로직, 데이터 구조를 정의합니다. 최종 목표는 모바일 환경에서 높은 가독성과 CTA 전환율을 달성하는 것입니다.

#### 🎯 1. 핵심 가정 및 목적
*   **목적:** 사용자에게 리스크 수치(Gap)와 공적인 해결책의 필요성을 직관적으로 전달하고, 다음 단계 행동(CTA 클릭)을 유도한다.
*   **톤앤매너:** 전문적 경고 (Professional Warning). Dark Navy 배경에 Critical Red 강조색 사용.
*   **디바이스 최우선 순위:** 모바일 (Mobile First). 모든 컴포넌트는 375px 너비를 기준으로 디자인된다.

#### 💾 2. 데이터 구조 정의 (Codari 전달용)
이 위젯은 최소한 다음의 데이터 필드를 API 호출을 통해 받아야 합니다. 이는 `pydantic` 모델에 반영되어야 할 핵심 요구사항입니다.

| Field Name | Data Type | Description | 예시 값 | 사용처 컴포넌트 | 비고 (Validation) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `risk_area` | String | 진단된 리스크의 핵심 영역 (예: 노후 대비, 간병비, 연금 사각지대) | "노인장기요양보험" | 제목/섹션 헤더 | 필수 값. |
| `gap_value_percent` | Float | 현재 제도와 필요한 지원금 사이의 격차 비율 (%) | 43.2 | 게이지 위젯, 핵심 수치 표시 | 소수점 첫째 자리까지 표기. |
| `severity_level` | Enum (Low/Medium/High) | 리스크의 심각도 레벨 | High | 경고 배지, 색상 결정 요소 | 'High'일 경우 Critical Red 강제 적용. |
| `suggested_action` | String | 사용자가 취해야 할 다음 행동 요약 (1줄) | "정부 지원금 3종 검토 필수" | Callout Box 내부 문구 | 가이드라인 제시. |

#### ✨ 3. 컴포넌트별 디자인 및 인터랙션 정의 (UI/UX 브리프)

##### A. [핵심 게이지 위젯] - The Gap Visualizer
*   **기능:** 사용자가 인식하는 '현실'과 '필요'의 격차를 시각적으로 보여줍니다.
*   **디자인:** 0%부터 100%까지 채워지는 막대형(Gauge Bar) 형태가 가장 직관적입니다.
    *   **배경 (Need):** Dark Navy 배경에 희미한 골드 그라디언트로 '필요 영역'을 표시합니다.
    *   **채움 (Gap):** 게이지의 특정 구간이 Critical Red(`#EF4444`)로 채워지며, 이 빨간색 부분이 **"현재 놓치고 있는 공백(The Gap)"**임을 강조해야 합니다.
    *   **인터랙션:** 마우스 오버 시, `gap_value_percent` 수치가 Tooltip으로 부드럽게 표시되어야 합니다 (애니메이션 필수).

##### B. [전문가 경고 배지] - Severity Alert Tag
*   **기능:** 리스크의 심각도를 즉시 알립니다.
*   **디자인:** 모서리가 둥근 직사각형 태그 형태입니다.
    *   **High:** Critical Red 배경, 흰색 굵은 글씨 (`HIGH RISK`). (가장 중요)
    *   **Medium:** 노란색/주황색 계열의 경고 배지.
    *   **Low:** Dark Navy 배경에 연한 회색 텍스트.

##### C. [CTA 버튼 라이브러리] - The Funnel Trigger
*   **기능:** 모든 진단 후 최종적으로 사용자를 유도하는 버튼입니다.
*   **디자인 원칙:** 모바일에서 손가락으로 가장 잘 눌리는 크기(최소 48px 높이)를 유지하며, 대비 효과가 극대화되어야 합니다.
*   **버전 A (Primary CTA):** Critical Red 배경, 흰색 굵은 글씨. (`전문가 진단 보고서 다운로드`) - 가장 중요한 액션에 사용.
*   **버전 B (Secondary CTA):** Dark Navy 배경, 골드/밝은 회색 테두리 및 글씨. (`관련 정보 블로그 보기`) - 다음 단계 유도용.

#### 🚀 4. 통합 시뮬레이션 흐름 (Codari와 함께 검증할 영역)
1.  **데이터 입력:** API를 통해 `gap_value_percent` (예: 43%) 및 `severity_level` (High) 데이터가 도착한다.
2.  **위젯 렌더링:** 배경이 어둡게 설정되고, 게이지 위젯의 빨간색 부분이 43% 지점에 도달하며 애니메이션으로 채워진다. 경고 배지가 Critical Red로 활성화된다.
3.  **정보 제공:** Callout Box가 `suggested_action` (예: "정부 지원금 3종 검토 필수")을 사용자에게 명확하게 전달한다.
4.  **전환 유도:** 사용자는 충격적인 시각적 경험과 구체적인 행동 지침에 자극되어, 가장 대비가 강한 **버전 A CTA (Critical Red)** 버튼을 클릭하여 Funnel의 다음 단계(랜딩페이지)로 이동하게 된다.
