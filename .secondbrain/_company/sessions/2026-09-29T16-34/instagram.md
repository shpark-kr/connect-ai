## 🗓️ MiniFunnel 유입 극대화 릴스 주간 콘텐츠 캘린더 (3주차)

### ✨ Week 1: [재정적 불안] - 사각지대 오류 감지
*   **Pain Point:** 공적 연금 및 노후 자산 관리의 사각지대 (경제적 취약성 공포).
*   **테마:** 시스템 재무 상태 진단 실패.
*   **핵심 목표:** 시청자에게 '내 돈이 사라지고 있다'는 경고를 주고, MiniFunnel을 통해 Gap 분석을 유도한다.

| 요소 | 내용 및 실행 지침 (A-Z 가이드) | 비주얼/사운드 연출 디테일 |
| :--- | :--- | :--- |
| **① 주제** | 🚨 [경고] 놓치기 쉬운 노후 재무 시스템의 3가지 오류 코드. (국민연금 외 공백 지점) | 화면 전체에 Deep Crimson Red 경고창 오버레이. 'SYSTEM ALERT' 자막 필수. |
| **② 핵심 후크** | "이거 모르면, 은퇴 후에 월 N백만원 손해 봅니다." (충격적인 수치 제시) | 첫 2초: 타이핑되는 빨간 글씨의 오류 코드 `CODE_PENSION_GAP`와 함께 급박한 비트 사운드. |
| **③ 스크립트 요약** | 1. 노후 자산 구조도를 보여주며, 'Gap'이 발생하는 지점을 시각적으로 강조 (예: 경력단절 기간). 2. 이 Gap을 메우는 것이 중요하며, 단순 저축만으로는 해결 불가함을 공학적 언어로 설명. 3. **(CTA 전환)** "지금 당신의 재무 시스템 진단을 받아야 합니다." | 스크립트 중 'Gap' 언급 시, 화면 전체가 떨리는 듯한 글리치 효과와 경고음을 삽입. |
| **④ CTA 배치** | **[12초 지점]** 스크립트가 가장 위기감을 최고조로 끌어올린 직후, 잠시 멈춤(Freeze Frame). "진단이 필요하다면? 프로필 링크에서 [MiniFunnel 진단 테스트]" 텍스트와 함께 CTA 버튼 애니메이션. |
| **⑤ 해시태그 세트** | `#노후준비 #은퇴자금 #재무상담 #공적연금 #경제위기코드` (전문성/긴급성 강조) |

### ✨ Week 2: [건강 기능] - 자율 시스템 성능 저하 경고
*   **Pain Point:** 독립 생활 능력의 점진적 저하 및 낙상 위험 (자율성 상실 공포).
*   **테마:** 신체 활동 기능 데이터 이상 감지.
*   **핵심 목표:** 건강 관리를 '시스템 유지보수'로 인식하게 만들고, 체계적인 진단(MiniFunnel)을 유도한다.

| 요소 | 내용 및 실행 지침 (A-Z 가이드) | 비주얼/사운드 연출 디테일 |
| :--- | :--- | :--- |
| **① 주제** | ⚠️ [경고] 당신의 관절과 근력, 지금 몇 %가 망가지고 있나요? (낙상 위험도 자가진단) | 의학 장비나 복잡한 그래프 같은 UI를 배경에 깔아 공학적 권위를 부여. |
| **② 핵심 후크** | "계단을 오르는 이 동작, 데이터 상으로 이미 오류입니다." (일상 활동을 기술적으로 분석하며 시작). | 첫 2초: 카메라가 사람의 관절 움직임을 슬로우 모션으로 잡아내며 '데이터 로딩 실패' 같은 시스템 경고음 삽입. |
| **③ 스크립트 요약** | 1. 간단한 동작(예: 의자에서 일어서기)을 수행하는 과정을 보여주되, 일반적인 설명 대신 '관절 가동 범위 측정', '근육 안정화 계수'와 같은 전문 용어로 대체하여 경고. 2. 기능 저하가 단순히 나이가 아니라 '관리 실패' 때문임을 지적. 3. **(CTA 전환)** "정확한 성능 분석이 필요합니다." | 근력이나 관절 움직임이 미달할 때마다, 화면에 `ERROR_FUNCTION_LOW`와 같은 빨간 오류 코드를 오버레이한다. |
| **④ CTA 배치** | **[15초 지점]** 시청자에게 자가 진단을 하도록 유도한 후, "일반적인 테스트로는 부족합니다. [MiniFunnel 전문 시스템진단]" 텍스트와 함께 링크를 노출하며 마무리. |
| **⑤ 해시태그 세트** | `#관절건강 #근력운동 #웰에이징 #낙상예방 #신체시스템점검` (기능/의학적 키워드) |

### ✨ Week 3: [디지털 소외] - 디지털 인프라 활용 오류
*   **Pain Point:** 복잡한 디지털 시스템 활용 능력 격차 및 소외감 (고립 공포).
*   **테마:** 필수 생활 인프라 접속 실패.
*   **핵심 목표:** '나만 뒤처지는 것 같다'는 감정을 건드려, 기술적 도움(MiniFunnel)이 필요함을 느끼게 한다.

| 요소 | 내용 및 실행 지침 (A-Z 가이드) | 비주얼/사운드 연출 디테일 |
| :--- | :--- | :--- |
| **① 주제** | ⛔️ [시스템 오류] 병원 예약부터 금융까지, 이 버튼을 못 누르면 생활이 마비됩니다. (디지털 문해력 점검) | 복잡하고 빠른 속도의 UI 변화(병원 앱, 은행 앱 화면 등)를 배경에 깔아 압도감을 준다. |
| **② 핵심 후크** | "요즘 세상은 이걸 모르면 살아남기 힘듭니다." (구체적인 일상 시나리오 제시: '진료 기록 열람' 등). | 첫 2초: 화면이 깜빡이는(Flicker) 불안정한 느낌을 주며, `WARNING_DIGITAL_GAP` 코드를 크게 표시. |
| **③ 스크립트 요약** | 1. 병원이나 금융 서비스의 필수적인 디지털 과정(예: 인증서 사용법, 앱 업데이트 등)을 빠르게 나열하며 어려움을 조성. 2. 문제는 기술 자체가 아니라 '어디서부터 시작해야 할지 모르는 시스템 전체'임을 지적. 3. **(CTA 전환)** "당신의 디지털 역량을 종합 진단받으세요." | 설명 중 사용자가 당황하는 표정이나, 복잡한 앱 화면 앞에서 막히는 듯한 연출을 넣어 공감대를 높인다. |
| **④ CTA 배치** | **[10초 지점]** 가장 많은 정보가 쏟아져 나와 시청자가 혼란스러움을 느낄 때, 화면이 갑자기 Deep Crimson Red로 바뀌며 "복잡하지 않은 단 하나의 가이드라인: [MiniFunnel 디지털 적응 프로토콜]"을 제시. |
| **⑤ 해시태그 세트** | `#디지털격차 #스마트라이프 #액티브시니어 #생활정보 #시스템적응` (사회/기술 공포 자극) |
