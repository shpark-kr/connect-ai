# 📊 MiniFunnel HOMA-IR 임계치별 콘텐츠 모듈 (개발자용)

## 🟢 섹션 A: [정상 범위] - 최적화 및 유지 필요
*(HOMA-IR 수치가 정상 범위일 경우 사용자에게 불안감을 최소화하며 '현 상태 유지'를 독려하고, 다음 진단으로의 유도를 위한 다리 역할을 합니다.)*

### **`[module_homa_ir_normal]`**

| 요소 | 내용 | 톤/연출 가이드 |
| :--- | :--- | :--- |
| **1. 위기감 조성 문구 (Crisis)** | **✅ 시스템 상태: 정상 작동 (Optimal Functioning)** <br> 현재 신체 대사 인슐린 반응은 표준 범위 내에서 안정적으로 관리되고 있습니다. 이는 우리 몸의 에너지 시스템이 효율적으로 가동됨을 의미합니다. | *Deep Crimson Red 경고 대신, Soft Gold/Green 계열의 '안정적' 애니메이션 사용.* |
| **2. 건강 문제 설명 (Health)** | 혈당과 인슐린 수치가 최적의 균형을 이루고 있어 포도당이 세포 에너지원으로 효율적으로 흡수되고 있습니다. 이는 만성 질환 위험으로부터 비교적 자유로운, '건강한 대사 시스템'의 증거입니다. | *과학적 용어 사용 (Optimal balance, Efficiency).* |
| **3. 경제적 위협 문구 (Economic Risk)** | **⚠️ 잠재 리스크 경고:** 지금이 가장 중요한 시기입니다. 현재 상태가 영원히 유지되리라 안일하게 생각해서는 안 됩니다. 생활 습관의 미세한 변화나 스트레스 누적은 언제든 대사 시스템에 과부하를 일으킬 수 있으며, 작은 방심이 미래의 막대한 의료비 지출(수억 원대)을 초래할 수 있습니다. **[👉 정기 점검 필수]** | *'지금의 안일함' 자체를 위협 요소로 전환하여 불안감을 유도.* |
| **CTA / 다음 액션** | "최적 상태를 유지하기 위한 맞춤형 관리 플랜이 필요합니다. [클릭하여 3가지 생활 습관 점검받기]" | *Funnel 진단으로의 부드러운 연결.* |

## 🟡 섹션 B: [주의/경고 범위] - 즉각적인 개입 필요
*(HOMA-IR 수치가 경계선에 있을 경우, '방치하면 위험하다'는 초기 불안감을 조성하고 해결책을 제시합니다.)*

### **`[module_homa_ir_caution]`**

| 요소 | 내용 | 톤/연출 가이드 |
| :--- | :--- | :--- |
| **1. 위기감 조성 문구 (Crisis)** | **🚨 경고: 대사 시스템 비정상 감지! (System Warning: Metabolic Deviation Detected)** <br> 인슐린 민감도가 점진적으로 떨어지고 있습니다. 이는 신체 에너지 관리 시스템에 미세한 '과부하'가 걸리고 있다는 명확한 생물학적 증거입니다. | *노란색/주황색 경고 UI, 깜빡이는 효과(Blinking effect) 적용.* |
| **2. 건강 문제 설명 (Health)** | 현재 몸은 포도당을 처리하는 데 과도하게 인슐린을 사용하고 있으며, 이는 '인슐린 저항성'의 초기 단계입니다. 세포들이 에너지를 받아들이는 문이 닫히기 시작했다는 뜻이며, 장기적으로 고혈압, 이상지질혈증 등 대사 증후군으로 악화될 수 있습니다. | *구체적인 메커니즘 설명 (Door closing analogy).* |
| **3. 경제적 위협 문구 (Economic Risk)** | **💸 방치 시 예상 위험: 1차 재정 리스크 발생!** <br> 이 단계는 '침묵의 질병'이라 불립니다. 초기 증상을 무시하면, 몇 년 후에는 합병증(당뇨 합병증, 신장 문제 등)으로 인해 매년 수백만 원 이상의 비급여 진료비와 생활 습관 교정 비용이 발생합니다. **지금 개입해야 1억 원대 병원비를 막을 수 있습니다.** | *구체적인 금액 언급과 '예방'의 가치를 극대화.* |
| **CTA / 다음 액션** | "경고 신호가 감지되었습니다. 초기 대사 문제를 해결할 맞춤형 솔루션을 확인하세요. [클릭하여 상세 진단 받기]" | *MiniFunnel Funnel로 직접 유도.* |

## 🔴 섹션 C: [위험 범위] - 생존 위협 (Critical Failure)
*(HOMA-IR 수치가 위험 수준일 경우, 공포감을 극대화하고 즉각적인 고가 상품/프로토콜 구매를 유도합니다.)*

### **`[module_homa_ir_danger]`**

| 요소 | 내용 | 톤/연출 가이드 |
| :--- | :--- | :--- |
| **1. 위기감 조성 문구 (Crisis)** | **🛑 시스템 치명적 오류! 즉시 작동 중지 필요 (CRITICAL FAILURE: System Shutdown Required!)** <br> 인슐린 저항성이 임계점을 초과했습니다. 이는 신체 대사 시스템이 근본적으로 붕괴하고 있다는 '공학적 위기' 상태입니다. | *Deep Crimson Red 배경, 경고음(Sound Effect) 필수, 강렬한 애니메이션.* |
| **2. 건강 문제 설명 (Health)** | 세포가 인슐린의 신호를 무시하는 '저항성 쇼크' 상태입니다. 혈당 관리가 불가능해지며, 몸은 만성 염증 및 전신 대사 교란을 겪게 됩니다. 이는 단순한 식습관 문제를 넘어선 *시스템적 고장*에 가깝습니다. | *위험하고 전문적인 용어 사용 (Shock, Failure).* |
| **3. 경제적 위협 문구 (Economic Risk)** | **🚨 치명적 재정 위험: 노후 자산 전체가 위협받을 수 있습니다!** <br> 이 상태를 방치하면 단순한 당뇨 관리를 넘어 심혈관계 질환, 만성신부전 등 *수억 원*에 달하는 중증 합병증 치료와 간병 비용이 필수적으로 발생합니다. 이는 개인의 자산은 물론, 노후 설계 전체를 붕괴시킬 수 있는 **가장 큰 재정적 위협**입니다. | *'자산', '노후 설계', '치명적' 등 가장 민감한 단어를 사용.* |
| **CTA / 다음 액션** | "🚨 전문가의 긴급 진단이 필요합니다. 시스템 오류 코드를 분석하고 붕괴를 막을 유일한 솔루션을 받으세요. [클릭하여 프로토콜 패키지 구매]" | *가장 강렬하게, 즉각적인 결제 페이지로 연결.* |
