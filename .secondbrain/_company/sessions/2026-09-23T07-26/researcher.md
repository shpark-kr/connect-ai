## 💡 1. Gap 모델 강화를 위한 설문 기반 데이터 구조 설계 (CEO 지시 이행)

Gap 계산 모델이 '공식 정책 대비 개인의 손실액'이라는 공신력 있는 틀을 유지하는 동시에, 실제 사용자 경험을 반영하기 위해 **'숨겨진 경제 행동 패턴 변수(Behavioral Gap Variables)'**를 도입해야 합니다. 이는 단순 설문조사가 아닌, 사용자의 심리를 자극하고 결제까지 유도할 수 있는 정량적 데이터 포인트여야 합니다.

### 📈 A. 핵심 목표: Behavioral Gap Model의 구축
*   **목표:** 공공 지원금 (Macro Policy) + 개인 행동 패턴 (Micro Behavior) $\rightarrow$ **총 손실액 (Gap)** 계산.
*   **방식:** 설문 문항을 통해 사용자의 *인지된 리스크(Perceived Risk)*와 *재정적 부족함(Financial Deficiency)*을 측정하고, 이를 점수화하여 Gap 모델에 반영합니다.

### 🔢 B. 구체적인 변수 목록 및 정의 (Variables & Definitions)

| 카테고리 | 변수명 (Variable Name) | 변수 유형 | 데이터 수집 방법 (Survey/Input) | Gap 통합 방식 (Quantitative Integration) |
| :--- | :--- | :--- | :--- | :--- |
| **1. 은폐된 자산/부채** | `V_HiddenDebt` (숨겨진 부채 인식 점수) | Likert Scale (1~5점) | "혹시 생각보다 높은 생활비 때문에 공적 지원을 포기한 경험이 있으신가요?" 와 같은 간접 질문으로 측정. | **손실 가산치:** Debt 수준에 비례하여 '추가 필요 자금' 항목 점수 부여. ($Gap_{total} = Gap_{policy} + (V\_HiddenDebt \times C_1)$) |
| | `V_UndervaluedAsset` (저평가된 자산 유형) | Multi-select/Open End | "퇴직금 외에 활용 가능한 비상 자금이나 지인 간의 금전 거래 경험이 있으신가요?"를 통해 묻고, 전문가 검토로 정량화. | **잠재 자원 점수:** 사용자가 인식하는 자산과 실제 최적 관리 가능액의 차이를 Gap으로 정의. |
| **2. 공백 지원 항목** | `V_MissedService` (놓치는 비공식 지원 서비스) | Checkbox/Scenario Test | "A 상황에서 B 제도를 이용하면 혜택이 더 큰데, 그것을 모르셨나요?"와 같은 시나리오 기반 질문 설계. | **Missing Benefit 가산:** 놓친 지원 항목의 예상 금액을 Gap 모델에 직접 합산. (가장 높은 전환율 유도 지점). |
| | `V_NonOfficialIncome` (비공식 소득원 인식) | Numerical Input / Slider | "월 평균으로 포기하고 있는 부수입이나 활용 가능한 재능 수입은 어느 정도라고 생각하십니까?" | **소득 공백 Gap:** 예상 생활비와 현실적인 최적 소득 간의 격차를 계산. |
| **3. 디지털/건강 리스크** | `V_DigitalLiteracyGap` (디지털 역량 Gap) | Difficulty Scale (1~5점) | "정부 사이트에서 필요한 서류를 온라인으로 처리하는 데 얼마나 어려움을 느끼시나요?" 등 사용 난이도 측정. | **행동적 비용 가산:** 이 항목의 Gap은 '정보 탐색 및 행정처리 시간/비용'이라는 무형의 재정적 손실로 환산하여 추가 점수화. |

### 🛠️ C. 통합 모델 작동 원리 (Model Flow)
1.  **입력 데이터 수집:** 사용자가 웹상에서 체크리스트(설문)에 응답 $\rightarrow$ **[V_HiddenDebt, V_MissedService 등]** 점수/값을 얻음.
2.  **Gap 계산:** 기존 공공 정책 Gap ($Gap_{policy}$) + 행동 패턴 Gap (새로 정의된 변수들 $\times$ 가중치)를 합산하여 최종 '손실액'을 산출합니다.
3.  **결과 제시:** 단순 금액 제시가 아닌, **"이 손실은 귀하의 현재 노후 계획에서 발생하는 심각한 위험입니다 (Critical Red Alert)"**와 같이 경고 메시지와 함께 Gap 금액을 시각화하여 공포감(FOMO)을 극대화합니다.
