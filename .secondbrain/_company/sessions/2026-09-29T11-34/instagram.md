## 📅 온현 MiniFunnel 유도 주간 릴스 콘텐츠 캘린더 (4주차 분량)

**🚀 목표:** '공학적 위기감(Failure Injection)' 콘셉트를 활용하여 전문성 기반의 신뢰도를 쌓고, 시청자의 불안감을 최고조로 끌어올려 MiniFunnel 진입을 유도한다.
**💡 핵심 원칙:** 모든 콘텐츠는 **[Pain Point 제시 (위기 감지)] $\rightarrow$ [권위적 경고 및 문제 심화] $\rightarrow$ [해결책 제시/CTA (MiniFunnel)]** 구조를 따른다.

### 🗓️ Week 1: 근력 약화 위협 (The Structural Failure)
| 요소 | 내용 | 상세 지침 / 시간대 |
| :--- | :--- | :--- |
| **주제** | 나잇살로 인한 '근육 시스템 오류' 경고 | 운동 부족을 단순한 게으름이 아닌, 신체 시스템의 기능 부전(Failure)으로 프레이밍. |
| **🚨 공학 코드** | `MUS-FAIL-403` (Muscle Function Failure) | 모든 자막과 화면에 이 코드를 Deep Crimson Red로 노출. |
| **영상 길이/포맷** | 12초 클립 (세로형, 빠른 편집) | 도입부: 질문(훅) $\rightarrow$ 전개: 근육 손실 수치 제시 $\rightarrow$ 결론: 해결책 언급 및 CTA. |
| **① 핵심 후크 문구 (3가지)** | 1. "혹시 우리 몸에 [ERROR CODE: MUS-FAIL-403]가 발생했나요?" (질문형) 2. "30대와 비교했을 때, 당신의 근육은 이미 30% 감소했습니다." (수치 충격형) 3. "이 증상을 '나이가 들어서'라고 무시하면 안 되는 이유." (경고/불안감 조성) |
| **② CTA 배치 시간** | **8초 ~ 12초 구간:** 근육 손실 수치가 가장 크게 제시된 직후, 화면 전환과 함께 Deep Crimson Red의 경고 박스를 넣고 "시스템 점검이 필요합니다"라는 문구와 MiniFunnel 버튼을 노출. |
| **③ 권장 CTA** | [MiniFunnel 링크] '근력 시스템 자가진단 체크리스트 다운로드' (Lead Magnet) |

### 🗓️ Week 2: 관절/연골 마모 위협 (The Joint Degradation Failure)
| 요소 | 내용 | 상세 지침 / 시간대 |
| :--- | :--- | :--- |
| **주제** | 퇴행성 관절염을 '시스템 과부하'로 인식시키기 | 무릎 통증 등을 단순한 노화가 아닌, 연골의 기계적 마모(Mechanical Wear) 문제로 진단. |
| **🚨 공학 코드** | `JOINT-OVERLOAD-500` (Overload Warning) | 뼈와 관절 부위를 스캔하는 듯한 그래픽 효과를 사용하여 전문성을 높임. |
| **영상 길이/포맷** | 15초 클립 (세로형, 시각화 강조) | 도입부: 아픈 순간의 공감 $\rightarrow$ 전개: X-ray 이미지와 같은 CG로 연골 마모 시뮬레이션 $\rightarrow$ 결론: 전문가 진단 필요성. |
| **① 핵심 후크 문구 (3가지)** | 1. "관절 통증, '나이 때문'이라고 합리화하고 계신가요? (오류 코드 경고)" (반박/도전) 2. "X-ray로 절대 볼 수 없는 연골의 진짜 마모 상태를 아십니까?" (궁금증 유발) 3. "퇴행성 관절은 '느린 시스템 고장'입니다." (비유적 표현 강화) |
| **② CTA 배치 시간** | **12초 ~ 15초 구간:** 연골 마모 시뮬레이션이 끝남과 동시에, 비주얼적으로 가장 심각한 경고(Deep Crimson Red 깜빡임)를 넣고 "전문가진단 시스템 점검 필수" 문구와 MiniFunnel 버튼 노출. |
| **③ 권장 CTA** | [MiniFunnel 링크] '관절 건강 3단계 위험도 자가 진단 가이드' (Lead Magnet) |

### 🗓️ Week 3: 피부 탄력 저하 위협 (The Bio-Chemical Failure)
| 요소 | 내용 | 상세 지침 / 시간대 |
| :--- | :--- | :--- |
| **주제** | 콜라겐/엘라스틴 감소를 '생체 화학적 오류'로 진단 | 피부 노화를 단순한 관리가 아닌, 신체의 필수 생화학 물질 부족(Deficiency) 문제로 접근. |
| **🚨 공학 코드** | `BIO-CRIT-999` (Critical Bio-Marker Alert) | 혈액 검사 결과지나 미세한 세포 구조를 확대하는 듯한 전문적인 그래픽을 사용. |
| **영상 길이/포맷** | 10초 클립 (매우 빠르고 임팩트 있게) | 도입부: 거울 앞에서 자신을 바라보는 모습(공감) $\rightarrow$ 전개: 콜라겐 감소 그래프 제시 $\rightarrow$ 결론: 외부 관리만으로는 불가능, 내부 시스템 재정비 필요. |
| **① 핵심 후크 문구 (3가지)** | 1. "피부 탄력 저하의 진짜 원인은 '나이'가 아닙니다." (논파/반전) 2. "당신의 콜라겐 수치는 지금 몇 %로 추락했습니까?" (직접적 질문) 3. "만성적인 피부 오류 코드(BIO-CRIT-999), 방치하면 안 됩니다." (위기감 강조) |
| **② CTA 배치 시간** | **7초 ~ 10초 구간:** 콜라겐 감소 그래프가 급격히 하락하는 지점 직후, 마치 경고등이 깜빡이는 것처럼 연출하며 "근본적인 시스템 보강이 필요합니다" 메시지와 MiniFunnel 버튼 노출. |
| **③ 권장 CTA** | [MiniFunnel 링크] '피부 생체 활력도 자가 측정 테스트' (Lead Magnet) |

### 🗓️ Week 4: 영양 결핍 및 전반적 시스템 취약성 (The Comprehensive Failure)
| 요소 | 내용 | 상세 지침 / 시간대 |
| :--- | :--- | :--- |
| **주제** | 특정 영양소 부족이 가져오는 신체 다중 오류 발생 예측 | 종합적인 건강 관리의 필요성을 강조하며, 가장 광범위하고 심각한 위기감을 조성. (가장 높은 트래픽 유도 목표) |
| **🚨 공학 코드** | `PENS-404` (Potential Error State Alert) | 모든 신체 기능(에너지, 면역, 순환)이 동시에 위험 경고음을 내는 듯한 오디오 디자인 필수. |
| **영상 길이/포맷** | 18초 클립 (가장 긴 분량, 스토리텔링 집중) | 도입부: 아침의 무기력함(일상적 불편함) $\rightarrow$ 전개: 여러 시스템이 동시에 오류를 일으키는 다이어그램 제시 $\rightarrow$ 결론: 전문가의 통합적인 진단이 유일한 해결책. |
| **① 핵심 후크 문구 (3가지)** | 1. "여러 증상을 개별적으로 치료하려 하시나요? 지금은 '시스템 전체' 점검이 필요합니다." (통합적 시야 제시) 2. "만성 피로는 단순 수면 부족 문제가 아닙니다. [PENS-404] 경고입니다." (오류 코드 활용 극대화) 3. "몸의 모든 기능이 동시에 '취약 상태'에 놓여있다면?" (최상위 위기감 조성) |
| **② CTA 배치 시간** | **15초 ~ 18초 구간:** 여러 시스템 경고음과 함께, 최종적으로 가장 크고 빨간색인 `PENS-404` 코드가 화면을 가득 채우며 진동하는 순간. "전문가의 종합적인 진단이 최후의 안전장치입니다"와 MiniFunnel 버튼 노출. |
| **③ 권장 CTA** | [MiniFunnel 링크] '종합 건강 시스템 리스크 예측 상담 신청' (최상위 컨버전스 목표) |
