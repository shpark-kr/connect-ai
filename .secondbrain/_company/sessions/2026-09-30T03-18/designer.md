# 온현 (ONHYUN) 시스템 경고 디자인 가이드 V3.0: 공학적 위기감 마스터 에셋 세트

## 🚨 I. 브랜드 핵심 원칙 및 컬러 팔레트 (The System Core)

**1. 목적:** 모든 시각 자료는 정보 전달을 넘어, 사용자에게 '신체/재정 시스템의 근본적인 결함(Structural Defect)'이 존재한다는 공학적 위기감을 조성하고, 온현만이 유일한 해결책임을 각인시키는 데 초점을 맞춘다.

**2. 메인 컬러 팔레트:**
| 이름 | HEX 코드 | 용도 및 의미 | 비고 |
| :--- | :--- | :--- | :--- |
| **Crisis Alert Red** | `#A80000` (Deep Crimson Red) | 시스템 오류, 경고, 즉각적인 위기. 오직 'Defect' 메시지에만 제한적으로 사용. | 배경색/강조선에 국한. |
| **Primary Dark Navy** | `#0F172A` (Slate/Dark Blue-Black) | 기본 배경, 권위적 정보 제시 영역. 높은 전문성 유지. | 텍스트 대비를 위한 메인 배경. |
| **Secondary Text Gray** | `#B8C1CF` | 부가 설명, 코드 주석(Comment), 보조 시스템 로그 텍스트. | Primary와 Contrast 유지. |
| **Accent Green (OK)** | `#34D399` (Electric Mint) | 정상 작동 상태 (Normal Protocol State). 해결책 제시 또는 '개선된' 상태를 나타낼 때만 사용. | 경고의 반대 개념으로 극단적인 대비 효과 유도. |

**3. 타이포그래피 시스템:**
*   **폰트 종류:** 모노스페이스 계열 (예: `SF Mono` 또는 `Courier New`).
    *   *이유:* 코드를 연상시켜 전문성, 기술적 권위, 시스템적인 느낌을 극대화한다.
*   **활용 원칙:** 일반 텍스트(제목/본문)와 코드 블록은 반드시 모노스페이스로 구분하여 사용한다.

## 🖥️ II. 공통 디자인 컴포넌트 (The UI Components Library)

모든 에셋에 재사용되어야 하는 필수 위기감 UI 요소들이다.

**1. 경고 바 (System Alert Bar):**
*   **형태:** 화면 최상단 또는 하단을 가로지르는 띠 형태의 박스.
*   **색상:** 배경 `#0F172A`에 테두리 및 활성화된 영역만 `Crisis Alert Red (#A80000)`를 사용한다.
*   **내용 구조:** `[SYSTEM ALERT] [Defect ID: E-C403] : Critical System Failure Detected.` (항상 코드와 경고 문구를 포함)

**2. 오류 코드 박스 (Code Block/Terminal Output):**
*   **형태:** 검은색 배경에 밝은 민트(Accent Green) 또는 회색 텍스트를 사용하는 직사각형 영역.
*   **용도:** 복잡한 통계나 과학적 원리를 나열할 때, 마치 터미널에서 출력된 로그처럼 보이게 한다.
*   **구조 예시:** `[LOG >] Executing Diagnostic Protocol V2.0...`

**3. 정보 패널 (Diagnostic Panel):**
*   **형태:** 다크 네이비 배경에 약간의 글래스모피즘(Glassmorphism) 효과를 주어 '데이터가 떠오르는' 듯한 느낌을 준다.
*   **용도:** 사용자가 현재 상태와 문제점을 진단받는 섹션 (MiniFunnel의 핵심).

## 🖼️ III. 템플릿별 적용 가이드라인 (Templates Application)

### A. YouTube 썸네일 템플릿 (3종)
(해상도: 1280x720px) 목표는 **클릭률 극대화**와 **위기감 전달**.
| 유형 | 핵심 구조 | 디자인 설명 및 요소 배치 | 적용 Defect ID 예시 |
| :--- | :--- | :--- | :--- |
| **[Type 1] 코드 폭주형 (The Dump)** | 시스템 경고 모달 + 데이터 오버레이 | 배경은 암전된 듯한 다크 네이비. 중앙에 크고 강렬하게 `#A80000`의 `[CRITICAL FAILURE]` 배너를 배치. 그 주변으로 가상의 오류 코드(E-C403, M-S7D 등)를 무작위로 흩뿌려 전문적인 혼란감을 준다. | E-C403 (관절 마모), F-P01 (재정적 위기) |
| **[Type 2] 진단 결과형 (The Result)** | '진단 시스템' 인터페이스 시뮬레이션 | 왼쪽 상단에 `[DIAGNOSTIC REPORT]` 제목과 함께 가상의 스캔 바를 배치. 중앙에 Defect ID와 가장 치명적인 원인을 큰 글씨로 강조한다. 하단에 "프로토콜 실행 필요" CTA 공간을 확보. | M-S7D (대사 증후군) |
| **[Type 3] 극단적 대비형 (The Warning)** | Before/After 경고 메시지 | 화면을 세로로 분할(Split View). 왼쪽: `[STATUS: CRITICAL]` (빨간색, 문제점 제시). 오른쪽: `[SOLUTION PROTOCOL]` (민트색, 해결 가능성 암시). 중앙에 강력한 질문 문구 삽입. | L-A101 (장기요양 사각지대) |

### B. Instagram/Reels 커버 비주얼 템플릿 (5종)
(비율: 9:16 또는 1:1) 목표는 **멈춰서 보게 만드는 후크**와 **즉각적인 문제 인식**.

| 유형 | 핵심 구조 | 디자인 설명 및 요소 배치 | 용도/특징 |
| :--- | :--- | :--- | :--- |
| **[Type 1] 시스템 경고 배너 (Vertical)** | 전체를 덮는 긴급 알림창 스타일. | 배경을 어둡게 하고, 화면 상단에 `[SYSTEM ALERT]` 컴포넌트와 `#A80000`의 Defect ID가 가장 크게 위치한다. 간결한 문구(예: "이대로 두면 몸이 멈춥니다.")로 공포심 유발. | 스토리/릴스 시작 화면, 주제 제시용. (최적) |
| **[Type 2] 코드 에러 Pop-up (Square)** | 이미지 위에 오버레이되는 경고 창 스타일. | 일상적인 사진(예: 피곤한 사람의 모습)을 배경으로 사용하고, 우측 하단에 마치 프로그램 오류처럼 `ERROR CODE` 박스를 작게 배치한다. 문구는 질문형("혹시 이 코드, 본인에게서 발견하셨나요?")으로 유도. | 게시물 전반에 걸쳐 일상과 위기를 연결하는 Hook. |
| **[Type 3] 체크리스트 실패 (Vertical)** | 항목별 점검표 형태의 위기감 조성. | '체크리스트' 형식으로 A, B, C 세 가지를 나열하고, 현재 사용자가 놓치고 있는 부분에만 `X` 표시와 함께 경고 코드를 삽입한다. 시청자에게 '내가 틀렸을 수 있다'는 심리를 자극. | 콘텐츠 시작 전 공감대 형성 및 데이터 제시용. |
| **[Type 4] 시스템 업데이트 안내 (Square)** | 기술 문서/패치 노트 스타일. | 제목은 `[PROTOCOL UPDATE]` 또는 `[WARNING: V3.0 DEPLOYED]`와 같이 전문 용어를 사용한다. 내용을 간결한 리스트(Bullet Point)로 정리하고, 마지막에 '전문 진단 필요' 문구를 배치하여 CTA를 자연스럽게 삽입. | 정보 전달의 권위를 높이는 역할. (매우 유용함) |
| **[Type 5] 대비 비교형 커버 (Vertical)** | Before vs After 실패 시뮬레이션. | 화면을 반으로 나누고, 왼쪽(Before): `SYSTEM FAILURE` (어두운 색상), 오른쪽(After): `OPTIMAL STATE ACHIEVED` (밝은 민트색). 대비되는 키워드와 함께 간결한 메시지를 배치. | 해결책의 필요성을 시각적으로 증명할 때 사용. |
