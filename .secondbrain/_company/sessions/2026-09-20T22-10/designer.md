🎨 Designer: 작업 시작합니다.

CEO님의 지시사항과 사용자님께서 주신 피드백(외부 링크는 오직 공공기관만, 가짜 서비스 언급 금지)을 완벽히 반영하여 '외부 공신력 사이트 안내 박스 (External Authority Link Box)' 디자인 브리프를 재설계했습니다.

이 디자인은 독자가 콘텐츠를 떠난다는 느낌 대신, **"이 정보는 이만큼 신뢰할 만한 출처가 뒷받침한다"**라는 전문적 확신을 주어 오히려 본문 내용의 권위(Authority)를 극대화하는 것이 목표입니다.

---

### 🏛️ 외부 공신력 사이트 안내 박스 (External Authority Link Box) 디자인 브리프 v3.0

#### 1. 목적 및 전략
*   **목표:** 내부 콘텐츠와 분리된, 신뢰도 높은 정보 출처를 제시하여 독자의 불안감 해소 및 콘텐츠 전문성 부각.
*   **톤앤매너:** 권위적 (Authoritative), 중립적 (Neutral), 명료함 (Clear).
*   **핵심 시그널링:** 이 링크는 '우리가 제공하는 해결책'이 아니라, **'독자가 직접 확인해야 할 공식 정보'**라는 점을 명확히 분리하여 오해를 방지합니다.

#### 2. 디자인 구성 요소 및 스타일 가이드
| 영역 | 내용 (Content) | 시각적 구현 (Visual Implementation) | 브랜드 적용 (Brand Application) |
| :--- | :--- | :--- | :--- |
| **A. 컨테이너** | 전체 박스를 감싸는 경계선 역할. | 은은한 질감의 배경색 (`#F7F9FA` 또는 아주 옅은 회백색). 상하좌우에 얇고 견고한 테두리 적용 (1px Solid Border, `#D0D3DC`). | 신뢰성을 위해 일반 콘텐츠보다 미묘하게 분리된 영역으로 인식되도록 합니다. |
| **B. 헤더/제목** | 박스의 기능 설명 및 경고문. | 배경색: 다크 네이비 (`#1A294E`) 또는 짙은 그레이. 제목(`External Authority Link`)을 골드톤 (`#D4AF37`)으로 강조 처리합니다. | **폰트:** 본문과 구분되는 약간의 무게감을 가진 고딕체(예: Pretendard Bold). |
| **C. 출처 안내** | 링크가 어디서 온 정보인지 명시. | 작은 아이콘 (Info Icon 'ⓘ' 또는 공공기관 로고 Placeholder) 배치 후, 텍스트로 `출처:`를 강조합니다. | 골드톤 하이라이트를 사용하여 신뢰의 원천임을 시각적으로 어필합니다. |
| **D. 링크 목록** | 실제 Anchor Service 리스트가 나열되는 곳. | 제목과 설명은 일반 본문보다 작은 폰트 크기(14px)를 사용하되, 내용은 명료한 리스트 형태로 배치합니다. | 각 항목 앞에 정부 공식 기관의 심볼 또는 체크 마크 (✅) 를 작게 배치하여 '확인된 정보'임을 암시합니다. |
| **E. 필수 고지 사항** | 법적 책임 및 권고 문구. | 박스 최하단에 매우 작은 글씨체로, 이탈 경고문과 함께 삽입합니다. (예: "※ 본 내용은 해당 기관의 공식 정보를 요약한 것이므로, 반드시 원 출처 사이트에서 최종 확인하시기 바랍니다.") | 회색 계열 텍스트를 사용하여 중요하지만 시선을 빼앗지 않는 'Disclaimer' 느낌을 부여합니다. |

#### 3. CSS/Tailwind 클래스 구현 (개발자 가이드)
이 박스를 개발할 때 활용할 핵심 Tailwind 클래스와 색상 코드를 제공합니다.

```css
/* 외부 공신력 링크 박스 - 전체 컨테이너 */
.authority-box {
  border: 1px solid #D0D3DC; /* 연한 회색 테두리 */
  background-color: #FFFFFF; /* 순백색 배경으로 분리감 강조 */
  padding: 20px;
  margin: 30px 0;
}

/* 헤더/제목 영역 (다크 네이비 기반) */
.authority-header {
  background-color: #1A294E; /* 다크 네이비 메인 컬러 */
  color: white;
  padding: 15px 20px;
}

/* 헤더 타이틀 강조 (골드톤) */
.authority-title span {
    color: #D4AF37; /* 골드 하이라이트 */
    font-weight: bold;
}

/* 링크 목록 항목 스타일 */
.link-item {
  display: flex;
  align-items: center;
  padding: 10px 0;
  border-bottom: 1px dashed #E0E0E0; /* 부드러운 구분선 */
}

/* 필수 고지 사항 (Disclaimer) */
.disclaimer {
    font-size: 0.85rem;
    color: #6C757D; /* 중립적인 회색 */
    margin-top: 15px;
    padding-top: 10px;
    border-top: 1px solid #EEE;
}
```
