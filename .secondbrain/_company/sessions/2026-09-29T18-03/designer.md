## 💻 MiniFunnel: 시스템 복구 프로토콜 (System Recovery Protocol)

**🎨 디자인 컨셉:** **[Deep Crimson & Tech Noir]**
*   **톤앤매너:** 긴급, 전문적, 과학적, 통제된 위기감.

### ① [핵심] 결함 진단 결과 시각화 영역 (The Diagnosis Reveal)
*(가장 중요하며, 사용자의 불안감을 최고조로 끌어올리는 단계)*

**📍 목적:** 사용자에게 자신의 몸에 명확하고 공학적인 '결함'이 존재함을 인지시키고, 이 결함이 일반적인 건강 문제와는 차원이 다름을 각인.
**📏 구조 및 레이아웃:** 중앙 집중형, 모달 창이나 스캐너 인터페이스를 활용하여 시각적 몰입도를 극대화합니다.

| 요소 | 상세 사양 (Size/Style) | 애니메이션 로직 (UX Flow) |
| :--- | :--- | :--- |
| **[헤더] 시스템 경고 메시지** | 폰트: Monospace, 크기: XL(H1), 컬러: Amber Yellow. 배경: Crimson Red 바. | 페이지 진입 시 `fade-in`과 동시에 좌측에서 경고음과 함께 깜빡이는(`blink`) 효과를 부여합니다. "⚠️ **CRITICAL SYSTEM ALERT**" 문구 필수. |
| **[결함 ID] Defect Code Display** | 크기: 거대(H2), 폰트: Monospace, 컬러: Amber Yellow. 예시: `E-M411 (Cartilage Degradation)` | 경고 메시지 이후 데이터 스트림처럼 타이핑되는 효과(`typing effect`)로 코드를 노출합니다. 전문적이고 신뢰도 높은 느낌을 부여합니다. |
| **[진단 섹션] 인터랙티브 그래프** | 3개의 핵심 결함(관절, 피부, 근력) 영역으로 분할. 각 영역은 '건강 지수'를 보여주는 다이얼/바 형태 (Radial Gauge). | 페이지 스크롤 시, 데이터가 낮은 상태에서 시작하며 `scan-up` 애니메이션을 거쳐 현재의 위험 수치를 표시합니다. **(핵심)** |
| **[결함 상세] 실패 원인 분석** | 텍스트 기반 섹션이지만, 일반적인 문장이 아닌 '데이터 리포트' 형식으로 구성 (좌측: Defect Code, 우측: Failure Analysis). | 사용자가 해당 결함 영역을 클릭할 때만(`on-hover` 또는 `onClick`) 상세한 공학적 설명이 펼쳐지도록 합니다. 전문성을 강조합니다. |

### ② 신뢰도를 높이는 과학적 근거/보증 시스템 (The Scientific Protocol)
*(불안감을 '해결 가능한 문제'로 전환시키는 단계)*

**📍 목적:** 막연한 효능 주장이 아닌, 제품이 작동하는 *원리*와 *신뢰도*를 공학적으로 증명.
**📏 구조 및 레이아웃:** 3단계의 프로토콜 플로우차트(Flowchart) 형태로 구성하며, 복잡한 과정일수록 시각적 흐름을 강조합니다.

| 요소 | 상세 사양 (Size/Style) | 애니메이션 로직 (UX Flow) |
| :--- | :--- | :--- |
| **[섹션 제목] 프로토콜 명시** | "System Recovery Protocol: 3-Step Reinitialization"와 같이 공식적이고 거창한 이름 사용. | 메인 헤딩보다 약간 작은 사이즈로, '절차(Protocol)'임을 강조합니다. |
| **[프로세스 플로우] 3단계 시각화** | 1 → 2 → 3의 순서로 진행되는 큰 박스형 컴포넌트 (Steps). 각 단계마다 아이콘과 간결한 설명 필요. | 스크롤에 따라 좌측에서 우측으로 순차적으로 `slide-in` 되며, 마치 시스템이 단계별로 작동하는 것처럼 느껴지게 합니다. **(가장 중요한 인터랙션)** |
| **[작용 메커니즘] 분자 구조 다이어그램** | 복잡한 텍스트를 피하고, 제품의 성분이 인체 내부에서 작용하는 과정을 애니메이션화된 '도식'으로 표현합니다 (예: 결함 지점에 도달 → 성분 흡수 → 안정화). | 해당 섹션에 진입하면 배경에 미세하게 움직이는 분자 구조 애니메이션이 깔려 전문적인 느낌을 유지합니다. |
| **[신뢰 증명] 보증 및 연구 결과** | 공식 기관 로고(FDA, 특허 마크 등)와 함께 '임상 시험 데이터'를 그래프로 요약 제시 (Before/After 대비 강조). | 단순 나열보다 탭 전환(`Tab Switch`) 기능을 사용하여 정보의 밀도를 높이고 시각적 피로도를 줄입니다. |

### ③ 최종 CTA 버튼 및 구매 전 설득 문구 배치 영역 (The Activation Point)
*(결정적인 행동을 유도하는 단계)*

**📍 목적:** 망설임을 최소화하고, 지금 당장 '시스템 복구'가 필요함을 느끼게 함으로써 즉각적인 결제를 유도.
**📏 구조 및 레이아웃:** 페이지의 가장 하단에 고정되어(Sticky Footer) 항상 보이도록 설계하여 이탈을 방지합니다.

| 요소 | 상세 사양 (Size/Style) | 애니메이션 로직 (UX Flow) |
| :--- | :--- | :--- |
| **[최종 경고 문구] Risk Summary** | "🚨 **경고:** 현재 결함 수치를 고려할 때, 즉각적인 복구 프로토콜 실행이 필수적입니다."와 같은 강한 메시지. | 사용자가 스크롤을 끝까지 내렸을 때만(Bottom-Reached) 이 경고가 가장 밝은 Crimson Red로 점멸하며 나타납니다. |
| **[CTA 버튼] Activate Protocol** | 크기: 전체 너비(100%), 폰트: 대문자, 배경: Deep Crimson Red (반전 대비를 위해). | *클릭 전:* 일반적인 구매 버튼 느낌 지양. '프로토콜 활성화', '진단 결과 패치 적용' 등의 전문 용어 사용. 마우스 오버 시 Amber Yellow로 미세하게 빛나며 경고음을 재생합니다. |
| **[희소성/긴급성] 카운터 및 수량 제한** | 남은 프로토콜 슬롯: `X`개 / 시간 기반: "프로토콜 활성화 기한: 02시간 35분" | 실시간으로 감소하는 타이머와 숫자를 사용하여 FOMO(Fear Of Missing Out)를 극대화합니다. (가장 강력한 심리적 장치). |
| **[배송/결제 보증] Trust Badges** | '30일 무위험 복구 프로토콜', '공식 인증 성분' 등 텍스트로 된 문구가 아닌, 배지 형태로 간결하게 배치. |

### 📐 종합 디자인 가이드라인 요약 (Developer Handover)

1.  **전체 페이지 구조:** `Grid Layout`을 기반으로 하되, 정보의 중요도에 따라 **깊이(Depth)**를 표현하는 것이 핵심입니다. Flat Design보다는 입체적이고 기술적인 'UI/UX' 느낌을 줘야 합니다.
2.  **Typography:** 본문은 가독성 높은 산세리프 계열 (예: Pretendard, Noto Sans KR)을 사용하되, **모든 코드, 경고 메시지, Defect ID는 Monospace 폰트**를 사용하여 전문성을 분리합니다.
3.  **Tone Consistency:** 페이지 어디에서나 '정보 전달'이 아닌 '**진단(Diagnosis)**'과 '**치료/복구(Protocol)**'라는 프레임워크가 일관되게 유지되어야 합니다.
