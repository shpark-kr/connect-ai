## 📊 Defect ID 그래프 컴포넌트 최종 명세서 (V1.0)

### 1. 목표 및 감정적 전달 가치
*   **목표:** 시청자가 자신의 현재 상태가 '정상'이 아님을, 그리고 그 차이가 얼마나 심각한지(Gap Size)를 수치적으로 인지하게 만든다.
*   **핵심 감정:** **긴급성 (Urgency)** $\rightarrow$ **충격/공포 (Shock)** $\rightarrow$ **전문적 안도감 (Expert Relief)**
*   **톤앤매너:** 다크, 전문적, 경고(Warning), 과학 보고서.

### 3. 애니메이션 흐름 설계 (The State Change)

이 컴포넌트는 세 단계의 애니메이션 시퀀스를 통해 공포감을 극대화해야 합니다.

#### **Phase 1: Baseline Establishment (기준점 제시)**
*   **표시 내용:** '20년 전 정상 수치' 데이터 그래프만 먼저 나타난다.
*   **애니메이션:** 화면 중앙에 축(Y축, X축)이 선형적으로 그려지며 준비된다. `정상 데이터 곡선` (Muted Blue/Gray)이 부드럽게 상승하며 그립니다. 마치 '원래의 건강한 상태'를 시청자에게 각인시키는 과정입니다.
*   **사운드 연출:** 낮은 톤의 안정적인 앰비언트 사운드 (Ambient Hum).

#### **Phase 2: Defect ID Visualization (시스템 오류 포착)**
*   **표시 내용:** 현재 수치 데이터(Current)가 `정상 대비 Gap`을 가지는 순간, 이 차이가 **Defect ID**로 정의되며 그래프에 오버레이된다.
*   **애니메이션:**
    1.  '현재 데이터 곡선'이 Phase 1의 정상 데이터를 가리키며 등장합니다 (Muted Blue/Gray와 대비).
    2.  두 곡선 사이의 수직적 **Gap 부분 전체가 순식간에 섬광처럼 빨갛게(Coral Red)** '점멸'하며 나타납니다. 이 깜빡임이 공포감을 극대화하는 핵심입니다.
    3.  강조된 Gap 영역 위에, 마치 시스템 경고창처럼 **"DEFECT ID: [인슐린 저항성] - Critical Failure"**라는 텍스트가 빨간색으로 크게 오버레이됩니다. (진동/팝업 효과 필수)
*   **사운드 연출:** 낮은 안정음이 갑자기 끊기며, 날카롭고 불규칙한 '경고음(Alarm Tone)'과 함께 전기적 잡음(Static Buzz)이 발생합니다.

#### **Phase 3: Callout & Solution Focus (솔루션 제시)**
*   **표시 내용:** Gap을 분석하고, 이로 인해 발생하는 신체 시스템의 문제점(예: 만성 염증).
*   **애니메이션:** Defect ID 그래프가 배경으로 약간 축소되며, 화면 전면에 **"Gap이 의미하는 것: 낮은 수준의 만성적 시스템 오류"**라는 핵심 요약 박스(Callout Box)가 깔끔하게 나타납니다. 이 때만 전문적인 느낌의 골드/화이트 톤을 사용하여 신뢰도를 회복합니다.
*   **사운드 연출:** 긴장감이 풀리며, 차분하고 희망적인 BGM이 다시 부상합니다.

### 4. [실행 예시] 인슐린 저항성 Gap 시각화 스펙 (20년 전 vs 현재)

| 요소 | 데이터/값 | 시퀀스 타이밍 | 애니메이션 지시 |
| :--- | :--- | :--- | :--- |
| **X축** | 시간 경과 (식사 후 1시간, 2시간 등) | 전체 | 일반적인 축 그리기. |
| **Y축** | 수치 측정값 (mg/dL 또는 Index Point) | 전체 | 정상 범위(Range: `[45-60]`)를 그리드 라인으로 표시. |
| **정상 곡선 (20년 전)** | 부드럽고 가파르게 하강하는 형태의 파형 데이터 | Phase 1 | `#457B9D` 색상의 선이 부드러운 애니메이션으로 그려짐. |
| **현재 곡선** | 정상 대비 지나치게 높은 수치를 유지하며, 하락 속도가 느린 형태 | Phase 2 (도입) | `#0A192F` 배경 위에서 `현재 데이터`가 점진적으로 나타나며 불안감을 조성함. |
| **Defect ID Gap 영역** | 정상 곡선과 현재 곡선 사이의 수직적/시간적 차이 | Phase 2 (클라이맥스) | **순간적인 섬광(Flash)** 효과와 함께 `#E76F51` 색상으로 채워지며, 배경 전체에 미세한 노이즈 패턴을 입힌다. |
| **핵심 문구** | "Gap Size: 30% 증가" 등 구체적 수치 | Phase 2 (최대 강조) | 가장 크고 두꺼운 타이포로 빨간색 경고문으로 표시. |
