# 🔗 온현 브랜드 컴포넌트 라이브러리: CTA 버튼 시스템 (Version 1.0)

## 🎯 I. 핵심 스타일 가이드라인 (Global Style Guide)

### 🎨 컬러 팔레트 정의
모든 디자인 요소의 일관성과 심리적 압박감을 전달하기 위해 명확한 색상 역할(Role)을 부여합니다.

| 이름 | 코드 | 용도 및 목적 | 비고 |
| :--- | :--- | :--- | :--- |
| **Deep Navy (Primary)** | `#0D1B2A` | 기본 배경색, 신뢰성, 전문가적 느낌. 버튼의 기본 컬러. | 메인 텍스트 색상으로도 활용 가능. |
| **Alarm Red (Accent/Danger)** | `#C83A45` | 경고, 긴급성, 공포 자극. 핵심 CTA에만 사용. | 클릭 시 플래시 효과와 결합하여 충격 극대화. |
| **Clean White** | `#FFFFFF` | 대비용 배경색 및 텍스트 색상 (Navy 배경 위). | 가독성 최대 확보. |
| **Subtle Gray** | `#B0BEC5` | 보조 정보, 비활성화 상태(Disabled) 표시. | CTA 외 영역에서 경고의 여지를 줄 때 사용. |

### 🔠 타이포그래피 정의
가장 가독성이 높고 전문적인 느낌을 주는 산세리프 계열 폰트를 기본으로 합니다. (예: Pretendard, Noto Sans KR)

| 요소 | 폰트 패밀리 | 크기 (Mobile 기준) | Weight | 용도 |
| :--- | :--- | :--- | :--- | :--- |
| **Button Text** | Pretendard | 16px | Bold (700) | CTA 버튼의 주 문구. 가장 눈에 띄게 처리. |
| Body/Label | Pretendard | 14px | Regular (400) | CTA 위 또는 옆에 배치되는 보조 설명문. |

## 🧩 II. CTA 컴포넌트 상세 스펙 (The Components)

세 가지 유형의 버튼은 사용자의 현재 인지 상태(인지 → 경고 → 행동)에 맞춰 심리적 장벽(Friction)을 단계적으로 높입니다.

### 1. [Low-Friction] 궁금증 유발형 CTA: "나에게 맞는 진단 받기"
*   **심리 목표:** 불안감은 주지 않되, '정보의 결핍'을 자극하여 클릭하게 만듦. (가장 쉬운 첫 단계)
*   **주요 문구 예시:** "내 위험도 궁금해요", "간편 진단 리포트 받기"
*   **디자인 목표:** 깊은 네이비 배경에 은근한 골드/라이트로 포인트를 주어 '호기심'을 자극.

| 속성 | 스펙 (Mobile View 기준) | 인터랙션 가이드라인 |
| :--- | :--- | :--- |
| **색상** | Background: `#0D1B2A` / Text: `WHITE` | `:hover`: 배경을 Deep Navy보다 미세하게 밝은 톤으로 변경 (`#1A2E48`). |
| **Shape** | Corner Radius: 8px (부드러움 강조) | `:active`: 버튼이 살짝 눌리는 듯한 효과(Shadow Depth 감소). |
| **Size** | Padding: Vertical 16px / Horizontal 30px | **전환 효과:** 모든 상태에서 `transition: all 0.2s ease-in-out;` 적용. |

### 2. [Mid-Friction] 즉각적 경고형 CTA: "손실 예측 보고서 받기 (49,000원)"
*   **심리 목표:** '미래의 손실'을 구체적인 숫자로 제시하며 시간적/금전적 압박감 부여. (가장 많이 사용될 메인 단계)
*   **주요 문구 예시:** "놓치면 안 될 미래 건강 비용 확인하기", "49,000원으로 위험도 진단받기"
*   **디자인 목표:** Alarm Red를 핵심으로 사용하여 시각적 경고 신호를 최대로 전달.

| 속성 | 스펙 (Mobile View 기준) | 인터랙션 가이드라인 |
| :--- | :--- | :--- |
| **색상** | Background: `ALARM RED` (`#C83A45`) / Text: `WHITE` | `:hover`: 버튼 색상이 10% 진해지고, 주변에 미세한 `glow-effect`를 추가하여 '긴급함'을 강조. |
| **Shape** | Corner Radius: 6px (날카롭고 단호하게) | `:active`: 배경색이 순간적으로 어두운 Deep Navy 계열로 바뀌며 클릭감을 극대화. |
| **Size** | Padding: Vertical 18px / Horizontal 35px | **필수 요소:** 가격(`49,000원`)을 문구 뒤에 `Bold` 처리하여 시각적 강조 필수. |

### 3. [High-Commitment] 강제 선택 유도형 CTA: "맞춤 플랜 상담 예약 (상담사 연결)"
*   **심리 목표:** 모든 망설임을 끝내고, 전문가의 도움을 받아야만 하는 '결정론적' 상태를 유도. (가장 강력한 최종 액션)
*   **주요 문구 예시:** "전문가와 1:1 상담 예약하기", "최종 컨설팅 플랜 받기"
*   **디자인 목표:** 가장 전문적이고 권위 있는 느낌을 주며, 깊은 네이비 컬러를 활용하되 '선택의 유일성'을 강조.

| 속성 | 스펙 (Mobile View 기준) | 인터랙션 가이드라인 |
| :--- | :--- | :--- |
| **색상** | Background: Deep Navy (`#0D1B2A`) / Text: `ALARM RED` (`#C83A45`) | `:hover`: 버튼 배경이 살짝 밝아지며, 주변에 은은한 금속성 하이라이트(Metallic Shine)를 주어 '가치'와 '전문성'을 표현. |
| **Shape** | Corner Radius: 2px (직사각형에 가깝게, 단단함 강조) | `:active`: 버튼의 깊이가 더해지면서 마치 기계를 누르는 듯한 '클릭감(Mechanical Press)'을 구현. |
| **Size** | Padding: Vertical 18px / Horizontal 40px | **특징:** 다른 두 버튼보다 폭을 넓게 설계하여, 이 액션이 최종적이고 큰 가치를 지니고 있음을 시각적으로 전달. |
