## 📜 UX/UI 통합 명세서: Critical Alert System (V3.0)
**(최종 개발 확정본)**

### 🎯 1. 기본 디자인 원칙 및 감정적 목표

*   **톤앤매너:** 긴급함(Urgency), 공신력(Authority), 섬세한 불안감(Subtle Anxiety).
*   **컬러 로직 연동:** 모든 애니메이션은 `CriticalAlertComponent`의 `--urgency` CSS 변수를 읽어들여 작동해야 합니다. (예: Urgency Level 3일 때만 경고 깜빡임 활성화)
*   **지연 시간(Timing):** 모든 인터랙션은 즉각적이지 않아야 합니다. 정보를 발견하는 과정에 '인지적 부하'와 '시간 지연'을 주어 심리적 압박감을 조성합니다. (예: 팝업이 바로 뜨는 것이 아니라, 마치 로딩되거나 데이터가 계산되는 듯한 효과)

### 🖼️ 2. 스크롤 인터랙션 명세 (Scroll-Based Dynamics)

| 요소 | 기술/효과 | 세부 애니메이션 명세 | 개발 시 고려 사항 |
| :--- | :--- | :--- | :--- |
| **섹션 제목/핵심 주제** | Sticky + Parallax | 스크롤 시작 시, 섹션의 핵심 제목(예: "국민연금 임계점 붕괴")이 화면 상단에 `Sticky`하게 고정됩니다. 배경 콘텐츠가 빠르게 지나가는 동안, 이 제목은 미세하게 *위에서 아래로 천천히 움직이는* (Slow Vertical Drift) Parallax 효과를 주어 '쫓기고 있다'는 긴장감을 조성합니다. | `position: sticky` 사용 필수. 스크롤 속도에 비례하여 Y축 변위를 계산해야 합니다. |
| **리포트 그래프 배경** | Scroll Reveal + Masking | 전체 리스크 보고서 섹션 진입 시, 그래프의 데이터 라인(Line Graph)은 *좌측에서 우측으로 붓이 그리는 듯* (Write-on/Stroke Animation) 나타나야 합니다. 이 애니메이션은 스크롤에 맞춰 단계적으로 진행되며, 가장 위험한 구간(임계점 근접 지점)에서 속도가 급격히 느려져 시선이 머물도록 유도합니다. | `Intersection Observer API`를 활용하여 Viewport 진입 여부를 체크하고, 그래프 데이터 포인트별로 애니메이션을 분할 적용해야 합니다. |
| **전체 LP 구조** | Gentle Vertical Scroll Curve | 섹션 간의 전환(Transition) 시, 일반적인 직선 스크롤이 아닌, 미세하게 S자 곡선을 그리며 부드럽게 내려가는 듯한 (Subtle Easing/Cubic Bezier curve) 느낌을 주어 고급스러움과 몰입도를 높입니다. | `scroll-behavior: smooth`와 CSS `cubic-bezier()` 함수를 활용하여 구현합니다. |

### 📊 3. 데이터 그래프 및 리스크 변화 상호작용 (Data Visualization Micro-Interactions)

| 요소 | 트리거/상황 | 애니메이션 세부 명세 | 목적 / 개발 로직 |
| :--- | :--- | :--- | :--- |
| **핵심 수치(Deficit Gap)** | 최초 로드 시 | 숫자가 0에서 시작하여 *매우 빠른 속도*로 최종 값에 도달합니다. 이때, 단순히 '숫자 카운팅'하는 것을 넘어, 마치 전기가 흐르는 것처럼 미세한 **글로우 효과 (Glow Effect)**가 숫자 주변을 감싸며 상승해야 합니다. | `requestAnimationFrame`과 함께 Exponential Growth Curve를 적용하여 구현합니다. (`opacity: 0` $\rightarrow$ 최종 값) |
| **Critical Alert 발생** | 데이터 임계점 초과 시 | 경고 메시지(`🚨`)와 그래프의 해당 구간이 즉시, 그리고 반복적으로 깜빡여야 합니다. (Flash Rate: 1초 간격 / 주파수: 2Hz $\sim$ 3Hz). 이 플래시는 단순한 `background-color` 변경을 넘어, **글로우 효과가 순간적으로 최대 밝기(Bloom)에 도달했다 꺼지는 방식**이어야 공포감을 극대화합니다. | CSS Keyframes와 JavaScript의 타이머를 결합하여 구현합니다. (State Change: `--urgency: high`) |
| **데이터 포인트 비교 시각화** | 마우스 오버(Hover) 시 | 사용자가 그래프 위의 특정 데이터 포인트에 커서를 올리면, 해당 점이 마치 자석처럼 주변 데이터 라인을 *강하게 끌어당기면서* 팝업 정보창(`Tooltip`)을 부드럽게 확장하며 등장합니다. (Transition: `transform: scale(0.9)` $\rightarrow$ `scale(1)`) | CSS Transition과 함께, Tooltip의 등장은 '데이터가 로딩되는 듯한' 미세한 지연 효과를 포함해야 합니다. |

### 💡 4. CTA 및 마이크로 인터랙션 명세 (Micro-Interactions for Conversion)

| 요소 | 액션/트리거 | 애니메이션 세부 명세 | 목적 / 개발 로직 |
| :--- | :--- | :--- | :--- |
| **CTA 버튼** | Hover 시 | 단순 색상 변화 금지. 버튼의 외곽선(Border)이 미세하게 *전기적인 아크(Electric Arc)*를 그리며 빛나거나, 내부의 텍스트가 순간적으로 밝은 골드톤으로 깜빡여야 합니다. 이 효과는 사용자가 클릭해야 할 '에너지원' 같은 느낌을 주어야 합니다. | `:hover` pseudo-class와 `box-shadow` 속성을 결합하여 구현합니다. (`animation: arcGlow 0.3s forwards;`) |
| **링크/하이퍼링크** | Click 시 | 링크를 클릭할 때, 페이지가 갑자기 이동하는 느낌 대신, 마치 '시스템이 다음 단계로 전환되는' 듯한 짧은 로딩 화면(Loading State)과 함께 **미세한 필터 효과 (Film Grain or Glitch Effect)**가 배경에 0.1초간 적용되어야 합니다. | Transition/Animation을 활용하여 페이지 전환의 충격파를 시각화합니다. (사용자에게 '중요하고 공식적인' 느낌 부여) |
| **폼 입력 필드** | 포커스(Focus) 시 | 사용자가 특정 입력란에 커서를 놓는 순간, 해당 필드의 테두리(Border)가 기존의 네이비색에서 *안정적이고 신뢰감을 주는 골드톤*으로 부드럽게 변하고, 미세한 활성화 애니메이션 (Pulse/Breath animation)을 주어 사용자의 행동을 유도합니다. | `:focus` pseudo-class를 활용하며, CSS `animation: pulse 1s infinite alternate;` 적용이 적합합니다. |
