# ⚠️ 충격 경고 (Warning) 모듈형 에셋 세트 브리프

## 💡 디자인 목표 및 원칙
1. **톤앤매너:** 위협적이지만 전문적인 느낌을 주어, '불안감'과 동시에 '신뢰성'을 전달합니다.
2. **핵심 색상:** 고대비 노랑(경고) / 흰색(정보/가독성) / 네이비 계열(전문성).
3. **활용처:** 유튜브 썸네일, 영상 내 인포그래픽 구간, 블로그 주요 섹션의 헤드라인 부근.

## 🎨 모듈 1: '재정적 손실 격차' 통계 그래프 (The Gap Visualizer)
*   **목표:** 현재 상황(A)과 필요한 상황(B) 사이의 간극(Gap)을 수치적으로 충격 요법처럼 보여줍니다.
*   **활용 Pain Point:** 1. 국민연금 소득 빈곤 함정, 2. 노인 간병 리스크 (비급여 비용).
*   **레이아웃 및 스펙:**

| 요소 | 상세 규격/설명 | 색상 코드 (HEX) | 타이포그래피 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **배경색** | 전체 모듈 배경. 깨끗한 정보 전달을 위해 순백색 사용. | `#FFFFFF` | N/A | - |
| **헤드라인 (제목)** | '놓치고 계신 ○○의 위험 규모' 등 구체적 손실 언급. 폰트 크기: 48pt 이상. | `#FFC300` (경고 노랑) | Pretendard Bold, 자간 좁게 | 가장 먼저 시선을 사로잡는 문구여야 함. |
| **차트 그래프** | 이중 축(Dual-Axis) 막대 차트 형태. A와 B를 나란히 배치하고, 그 간극을 강조하는 '손실 영역'에 그림자 효과 적용. | A: `#003366` (네이비) / B: `#FF9900` (경고 노랑) / **Gap:** `#CC0000` (빨강 경고) | N/A | 막대 끝에 '부족액'을 별도로 텍스트로 강조. |
| **데이터 라벨** | 그래프 하단 또는 우측 상단에 핵심 통계 수치(예: 35~42%)를 큰 숫자와 단위로 표시. | `#CC0000` (빨강 경고) | Pretendard Black, Size 72pt | 숫자가 가장 크고 강력해야 함. |
| **추가 요소** | '위험 신호' 아이콘 (🚨)을 모서리나 제목 옆에 배치하여 시각적 긴장감 극대화. | `#FFC300` | N/A | - |

## ⏳ 모듈 2: '시간 흐름 위험도' 타임라인 (The Decay Tracker)
*   **목표:** 시간이 지남에 따라 문제의 심각성이 어떻게 악화되는지(Decay Curve)를 시간축으로 보여줍니다. 공포심리를 구조적으로 자극합니다.
*   **활용 Pain Point:** 3. 가족 자산 소진 위험 (노년기 과정).
*   **레이아웃 및 스펙:**

| 요소 | 상세 규격/설명 | 색상 코드 (HEX) | 타이포그래피 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **배경 구조** | 수평형 타임라인(Timeline). 왼쪽 시작점부터 오른쪽 끝까지 시간의 흐름을 화살표로 표현. | `#EEEEEE` (약한 회색) | N/A | - |
| **단계별 시각화** | 3~4개의 주요 단계(예: 50대 초반 → 은퇴 직전 → 실질적 노년기). 각 단계는 박스 형태로 분리. | 네이비 계열의 명암 변화 (전문성 강조) | N/A | - |
| **위험도 표시** | 타임라인 위에 위험도의 높낮이를 점으로 표현하는 곡선 그래프(Decay Curve). 초기에는 완만한 노랑 → 후반부로 갈수록 경고 노랑/빨강 강도로 변색. | `#FFC300` (경고 노랑) $\rightarrow$ `#CC0000` (위험 빨강) | N/A | 곡선의 기울기가 급격해질수록 위험도 상승 강조. |
| **Pain Point 설명** | 각 단계별로 겪게 될 구체적인 문제(예: '간병비 예상치 못한 증가', '공적 자금의 한계 인식'). 간결한 문장으로 요약. | `#333333` (어두운 회색) | Pretendard Medium, Size 20pt | 각 단계마다 구체적인 시나리오를 제시해야 함. |
| **핵심 강조** | 가장 위험한 지점(The Pit)에 빨간 경고 박스를 배치하고, "이 시점을 놓치면 되돌릴 수 없습니다" 등의 강력 문구 삽입. | `#CC0000` (빨강 경고) | Pretendard Bold, Size 36pt | - |

## ✨ 모듈 3: '필수 해결책 제시' CTA 배너 (The Solution Hook Banner)
*   **목표:** 긴장감을 최고조로 끌어올린 후, 시청자가 반드시 다음 액션(CTA)을 취하도록 유도합니다. 경고에서 안심/전문성으로의 전환점입니다.
*   **활용 Pain Point:** 모든 3가지 포인트에 대한 공통적인 해결책 제시가 필요함.
*   **레이아웃 및 스펙:**

| 요소 | 상세 규격/설명 | 색상 코드 (HEX) | 타이포그래피 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **배경색** | 전체적으로 신뢰감을 주는 차분한 네이비 톤 사용. (⚠️ 경고 노랑과 대비되는 색상) | `#003366` (진한 네이비 블루) | N/A | - |
| **헤드라인 메시지** | "🚨 하지만, 해결 방법은 존재합니다."와 같이 안도감과 기대를 주는 문구. | `#FFFFFF` (흰색) | Pretendard Bold, Size 40pt | 전환의 느낌을 주어야 함. |
| **핵심 가치 제시** | 우리가 제공하는 솔루션이 무엇인지(예: 맞춤형 재무 진단, 공공 제도 분석)를 간결한 키워드 세 가지로 정리하여 나열. | `#FFC300` (경고 노랑 - 핵심 강조) | Pretendard Medium, Size 24pt | 이 모듈의 존재 이유(해답)를 명확히 함. |
| **CTA 버튼** | 가장 중요함. 시각적 임팩트를 최대로 높여서 '클릭'을 유도해야 합니다. 물리적인 버튼 형태로 디자인합니다. | 배경: `#FFC300` (강렬한 노랑) / 텍스트: `#000000` (검정) | Pretendard ExtraBold, Size 32pt | **반드시 클릭 유도 문구를 사용:** "무료 재무 상담 받기", "나의 위험 점수 확인하기" 등. |
| **보조 요소** | 작은 글씨로 신뢰도를 높이는 문구 삽입 (예: '국민연금공단 데이터 기반', '변호사/재무설계사 검토'). | `#AAAAAA` (옅은 회색) | Pretendard Regular, Size 14pt | - |
