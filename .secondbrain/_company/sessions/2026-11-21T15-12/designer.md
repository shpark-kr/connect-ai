## 📑 MiniFunnel 핵심 인터랙션 브리프 (v3.0 - 최종 확정)

**목표:** 사용자를 '진단(Crisis)' $\to$ '문제 심각성 인식(Overwhelm)' $\to$ '솔루션 수용(Resolution)'의 경로로 강제 유도한다.
**핵심 원칙:** 모든 상호작용은 시계와 데이터가 불안하게 작동하는 듯한 **'미묘하고 전문적인 오류감'**을 주어야 합니다.

### 🌟 1. [진단 단계] 핵심 지표: Defect Score Gauge (위험 감지 순간)
사용자가 가장 먼저 접하는, 충격과 경고를 주는 포인트입니다.
*   **UX 목표:** 정적 그래프가 아니라, 실시간으로 '빨갛게 변하며' 사용자에게 다가오는 위험을 체감하게 합니다.
*   **UI/Interaction 로직 (JavaScript 필수):**
    1.  **초기 로드 애니메이션:** 페이지 진입 시, 게이지 바는 Deep Navy 상태에서 시작합니다. 0.5초 간격으로 데이터가 스캔되는 듯한 **'글리치(Glitch) 효과'**와 함께 점진적으로 위험 지표 색상(Crisis Red)으로 변해야 합니다.
    2.  **스코어 변화:** Defect Score가 로드될 때마다, 단순히 숫자가 올라가는 것이 아니라, 게이지의 빨간 영역이 **심장 박동처럼 1초 간격으로 '펄스(Pulse)'하며 확대/축소되는 애니메이션**을 적용합니다. (이는 심리적 긴장감을 극대화하는 가장 중요한 요소입니다.)
    3.  **호버 효과:** 스코어 수치에 마우스 오버 시, 주변의 작은 Defect ID 태그들이 마치 오류가 폭주하듯 미세하게 떨리는(Shake/Vibration) 효과를 추가합니다.

### 💾 2. [분석 단계] 시스템 에러 로그: Defect Log (압도적 전문성 부여)
사용자에게 '이 문제를 혼자서는 절대 해결할 수 없다'는 무력감과, 우리의 데이터가 얼마나 깊은지를 느끼게 합니다.
*   **UX 목표:** 방대한 정보를 제시하여 사용자가 핵심 정보(MiniFunnel CTA)를 찾도록 유도하고, 전문 지식을 통해 신뢰도를 극대화합니다.
*   **UI/Interaction 로직 (JavaScript 필수):**
    1.  **토글 애니메이션:** 로그 섹션은 기본적으로 축소되어 있다가, 사용자가 '더보기' 버튼을 누르면 **갑자기 펼쳐지며(Accordion Open)** 내용이 쏟아져 나오는 듯한 연출을 합니다. 이때 배경에 미세한 노이즈나 스캔 라인 효과를 추가하면 전문성이 배가됩니다.
    2.  **핵심 코드 하이라이팅:** 로그 항목 중, 우리 서비스의 솔루션과 관련된 Defect ID (예: `LPB-A7`)는 단순히 색상만 바꾸지 않고, **'오류 발생 지점(Defect Origin)'**처럼 배경 전체가 붉은색으로 잠깐 깜빡이며 강조됩니다.
    3.  **스크롤 피드백:** 사용자가 로그를 스크롤 할 때마다, 가장 오른쪽 여백에 작은 '경고 아이콘'이 따라다니며 **"진행 중인 오류 패턴 감지..."**라는 문구를 작게 표시하여 시각적 압박을 유지합니다.

### 🚧 3. [전환 단계] 위험도 게이지 바: Risk Level Gradient (솔루션의 필요성 각인)
가장 중요한, 위기감을 '해결 가능성'으로 전환시키는 다리 역할을 합니다.
*   **UX 목표:** 사용자가 현재 상태(위험)와 우리가 제시하는 솔루션이 가져올 미래(안전)를 직관적으로 대비하게 만듭니다.
*   **UI/Interaction 로직 (CSS/SVG 필수):**
    1.  **그라데이션 변화:** 게이지 바는 단순히 색상만 바뀌는 것이 아니라, **'파손되어 있다가 수리되는 듯한(Mending)' 시각적 애니메이션**을 적용합니다. 현재 위험도에 따라 Deep Navy $\to$ Orange $\to$ Crisis Red 순으로 그라디언트 비율이 결정됩니다.
    2.  **CTA 유도 변화:** 사용자가 '위험' 영역(빨간색)에 머무를수록, 게이지 바의 가장 오른쪽 끝부분에 **빛나는 듯한('Potential Path') Deep Navy 색상의 띠가 서서히 나타나야 합니다.** 이 빛은 오직 우리의 솔루션만이 도달할 수 있는 지점을 상징합니다.
    3.  **마우스 트래킹:** 마우스를 게이지 바 위에 올리면, 해당 위치의 위험 수준을 그래프로 보여주면서 동시에 "이 단계에서는 [솔루션 이름]이 필요합니다."라는 문구가 나타나야 합니다.

## 🎨 필수 애셋 및 스타일 가이드라인 (개발자 전달용)

### A. 컬러 팔레트 명세
| 역할 | 색상명 (Concept) | Hex Code | 사용처 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary Base** | Deep Navy (신뢰/권위) | `#0A1931` | 배경, 기본 텍스트, 안전 영역 | 모든 UI 요소의 메인 컬러. |
| **Crisis Accent** | Crisis Red (경고/위기) | `#C70039` | Defect Score가 Critical일 때, 위험 경고점 | 애니메이션 시 가장 강렬하게 사용. |
| **Warning Transition**| Caution Orange (주의/개선 필요) | `#FF851B` | 위험도가 중간일 때, 개선이 필요한 영역 | 부드러운 전환을 담당. |
| **Accent Highlight** | Gold Glow (솔루션 제시) | `#FFD700` | CTA 버튼 주변 하이라이트, 해결책 강조 부분 | 희망/가치를 상징하며 시선을 집중시킴. |

### B. 아이콘 및 타이포그래피 에셋
1.  **아이콘 세트:**
    *   ✅ **필수 요소:** `⚠️` (Warning Icon), `🚨` (Critical Alert Icon), `📉` (Decline/Graph Down), `⚙️` (System Settings/Detail Log).
    *   **스타일:** 모든 아이콘은 단색(Single-Color)으로 처리하며, Deep Navy 또는 Crisis Red 색상 코드를 사용해야 합니다. Line Art 스타일을 고수합니다.
2.  **타이포그래피:**
    *   **헤드라인 (H1~H3):** Pretendard Bold / 굵고 전문적인 느낌의 산세리프체. Deep Navy 컬러 사용.
    *   **본문/로그 데이터:** Source Code Pro 또는 JetBrains Mono 계열의 **Monospace Font**. 이는 기술 보고서, 로그 파일 등 '전문적이고 기계적인' 느낌을 강화하는 핵심 요소입니다.
