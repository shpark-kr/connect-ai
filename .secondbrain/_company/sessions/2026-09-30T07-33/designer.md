### 📦 [최종 산출물] MiniFunnel 진단 시스템 UI/UX Spec V1.0
**파일 이름:** `system_failure_report_kit_v1.0.md`
**목적:** 영상 제작팀 및 개발팀을 위한 통합 디자인 가이드라인 제공.

#### 📐 핵심 컬러 팔레트 정의 (Color Palette)
| 이름 | HEX Code | 용도 | 비고 |
| :--- | :--- | :--- | :--- |
| **Deep Navy** (메인 배경/텍스트) | `#0A1931` | 신뢰성, 전문성, 기본 UI 배경. | 깊은 밤하늘 같은 느낌으로 안정감 부여. |
| **Crisis Red** (경고/위기) | `#D62828` | Defect ID 표시, 심각한 오류 메시지, CTA 강조. | 가장 시선을 끄는 경고색. 위험을 즉시 인지시킴. |
| **Accent Gold** (하이라이트/성공) | `#FFC300` | 핵심 지표 하이라이트, 중요 정보 포인터. | 전문적인 '진단' 결과의 권위를 더함. |
| **Background Gray** | `#1A2B45` | 섹션 분리 또는 카드 배경. | Deep Navy와 대비되어 가독성을 높임. |

#### 📜 [Stage 1] Diagnosis Input: 시스템 진단 입력 (Diagnosis Input)
*   **목표:** 사용자에게 '진짜 테스트'를 받는 듯한 느낌을 주어 몰입도를 극대화한다.
*   **구성 요소:** 질문/체크박스, 실행 버튼.

| 컴포넌트 | 디자인 명세 | 애니메이션 가이드라인 (영상 적용) |
| :--- | :--- | :--- |
| **섹션 헤더** | 텍스트: `[SYSTEM DIAGNOSTIC PROTOCOL V1.0]` / 서브 텍스트: `본 진단은 전문 의료기관의 대체 불가한 참고 자료입니다.` (Deep Navy) | 화면에 나타날 때, 글자가 마치 전자기기 디스플레이에 출력되듯 **'글리치(Glitch)' 효과**와 함께 타이핑되는 느낌으로 등장. |
| **체크박스 항목** | 질문: "아침에 일어나기가 힘들다." / 체크박스: (⚪) 상태로 표시. 각 항목은 간결한 문장형 문제 제시. | 사용자가 마우스 오버(Hover)할 때, 항목의 배경이 미세하게 어두워지면서 **'시스템 감지됨'** 같은 느낌을 주는 은은한 빛 효과를 준다. |
| **실행 버튼 (CTA)** | 텍스트: `[RUN DEEP ANALYSIS]` / 색상: Deep Navy 바탕에 Crisis Red 테두리. | 클릭 직전, 버튼 주변으로 얇고 빠르게 깜빡이는 **'로딩 애니메이션(Pulse Effect)'**을 넣어 즉각적인 액션 유도. (영상에서는 이 순간 정지 화면 후 로딩 바를 보여줌) |

#### 🔴 [Stage 2] System Error Report Page: 시스템 오류 보고서
*   **목표:** 가장 강력한 공학적 위기감(Defect ID)을 시각적으로 폭발시키고, 문제의 심각성을 주입한다. (M-S7D 강조)
*   **구성 요소:** Defect ID 코드 블록, 상세 오류 메시지, 증거 데이터 그래프.

| 컴포넌트 | 디자인 명세 | 애니메이션 가이드라인 (영상 적용) |
| :--- | :--- | :--- |
| **Defect ID Code Block** | 중앙에 크게 배치. `[DEFECT ID: M-S7D]` / 폰트: 모노스페이스(Monospace) 계열의 강렬한 서체. 배경: 어두운 블랙/딥 네이비. 텍스트 색상: **Crisis Red**. | 화면 전체가 순간적으로 **'시스템 경고음과 함께 떨리는 듯한 필터 효과'**를 거친 후, Defect ID 코드가 마치 서버에서 폭발하듯 강렬하게 등장해야 함. (Impact!) |
| **오류 메시지** | 텍스트: "대사 및 순환계 시스템의 구조적 붕괴가 감지되었습니다." / 심각도 표시: `CRITICAL SEVERITY (95%)` (Crisis Red) | 오류 코드가 한 줄씩, 마치 해킹 화면처럼 빠르게 **'스크롤되면서 나타나는(Typewriter/Matrix)'** 효과를 적용하여 전문성을 극대화. |
| **데이터 그래프** | 3D 느낌의 미니멀한 라인 그래프 2개 배치. (예: 인슐린 저항성 추이, 혈관 플라그 밀도). 축과 데이터는 Accent Gold와 Crisis Red 조합 사용. | 그래프가 단순히 나타나는 것이 아니라, 시간이 흐르면서 **'데이터가 쌓여가는(Accumulating)'** 애니메이션으로 표현되어야 신뢰도를 높인다. |

#### 🟢 [Stage 3] Protocol Suggestion Screen: 프로토콜 제시 및 CTA
*   **목표:** 위기감을 해결책을 통해 '관리 가능한 문제'로 전환시키고, 다음 단계 구매(MiniFunnel)로 자연스럽게 유도한다.
*   **구성 요소:** 솔루션 개요, 작동 원리 요약, 강력한 CTA 버튼.

| 컴포넌트 | 디자인 명세 | 애니메이션 가이드라인 (영상 적용) |
| :--- | :--- | :--- |
| **프로토콜 헤더** | 제목: `[RECOMMENDED PROTOCOL: 온현 라이프케어 시스템]` / 서브 텍스트: "M-S7D 오류에 최적화된 단계별 교정 프로그램." (Deep Navy) | Stage 2의 위기감이 지나가면서, 마치 **'안정화(Stabilizing)'**되는 느낌으로 부드럽고 차분하게 등장. 색상 전환이 핵심. |
| **작동 원리 요약 박스** | 3개의 간결한 카드 구조 (예: ① 염증 감소, ② 순환 개선, ③ 에너지 재활성화). 각 카드는 Accent Gold의 아이콘과 함께 설명됨. | 카드가 마치 전기가 흐르듯(Flow) 한 장씩 **'팝업되어 나타나며'** 정보가 단계적으로 습득되도록 유도한다. |
| **최종 CTA 버튼** | 텍스트: `[M-S7D 진단 결과 상세 프로토콜 확인하기]` / 색상: Deep Navy 바탕에 Accent Gold 테두리 (Crisis Red는 사용 금지). | 이 버튼은 가장 크고, 영상의 결론 부분에서 화면 전체를 가득 채우며 **'클릭을 기다리는 듯한(Waiting)'** 효과와 함께 명확하게 보여야 함.
