# 📋 작업 브리프

**원 명령:** [자율 사이클 — 2026-09-21] 1인 기업 24시간 운영 중. 회사 목표·각 에이전트의 개인 목표(_agents/{id}/goal.md)·최근 의사결정·메모리를 검토해서 지금 가장 가치 있는 단일 작업 1개를 결정하고, 적절한 1~2명 에이전트에게 분배해서 실행하세요. 같은 산출물을 반복하지 마세요 — 메모리에 비슷한 항목이 24시간 내에 있으면 다른 각도로 진전시키세요.

## 요약
시스템의 자율성을 극대화하기 위해, 현재까지 기획된 구조적 모듈(Citation Box 등)을 실제 콘텐츠 파이프라인에 통합하는 것이 최우선 과제입니다. 새로운 공공데이터를 기반으로 리서치-기획-구현 사이클을 실행하여 시스템 검증에 집중합니다.

## 분배
- **🔍 Researcher**: 최근 트렌드 및 목표(50~60대 공적 지원금 사각지대)를 고려하여, 아직 다뤄지지 않은 새로운 공공 데이터 세트 1개를 선정하고, 이 데이터를 '위험 경고'의 근거로 활용할 수 있도록 구조화된 JSON 형태로 요약합니다. (예: 특정 건강보험 항목의 미지원 비용 비교 등)
- **✍️ Writer**: researcher가 제공한 새로운 데이터 세트를 핵심 근거 자료로 삼아, '위험 경고(Warning) → 데이터 증명(Data) → 해결책 제시' Funnel 구조를 가진 블로그 아티클 초안 (최소 2,000자 분량)과 이에 기반한 유튜브 롱폼 스크립트의 주요 전환점(Hook Point) 리스트를 작성합니다.
- **💻 코다리**: writer가 생성한 콘텐츠 초안을 바탕으로, designer가 정의한 'Citation Box' 및 기타 구조적 모듈들이 자동으로 삽입되고 로깅되는 통합 테스트 시나리오(E2E Test Case)를 설계하고, 실제 API 연동 환경에서 해당 기능을 검증하는 코드를 작성합니다.
