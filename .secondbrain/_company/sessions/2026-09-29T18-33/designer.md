## ⚙️ 시스템 오류 메시지 컴포넌트 (System Failure Alert Component) 스펙 확정

### 1. 핵심 디자인 원칙 및 전반 구조
*   **컨셉:** OS 레벨의 경고창(OS-Level Alert). 데이터와 코드를 최우선으로 배치하여 전문성을 극대화합니다.
*   **배치 가이드라인:** 모든 요소는 좌측 상단 또는 중앙에 고정된 패널 형태로 존재하며, 마치 화면을 '덮어씌운' 오버레이처럼 보이게 합니다.
*   **전체 배경 (Background):** `#0A1826` (Deep Navy/Black). 낮은 명도로 깊이감을 줍니다.

### 2. 컬러 팔레트 및 타이포그래피 가이드

| 요소 | 이름 | Hex Code | 용도 / 특징 |
| :--- | :--- | :--- | :--- |
| **BG** | Deep Background | `#0A1826` | 기본 배경색 (매우 어두운 네이비). |
| **WARN** | Alert Red | `#FF4B4B` | *위기/경고* 메시지, 결함 수치 하회 시. (글로우 효과 필수) |
| **DATA** | Primary Data Blue | `#00CCFF` | 시스템 정상 작동 영역의 기준선 및 주요 데이터 표시. (네온 블루 강조) |
| **ACCENT** | Authority Gold | `#D4AF37` | 해결책, 핵심 결론, CTA 버튼 등 '가치'와 '권위'를 부여하는 색상. |
| **TEXT** | Primary Text | `#FFFFFF` | 기본 본문 텍스트. (높은 가독성 확보) |
| **FONT** | Typography | `Space Mono`, `Courier New` | 전체 시스템 UI에 통일성을 주기 위한 Monospace 계열 폰트 사용을 필수화합니다. |

### 3. 컴포넌트별 상세 스펙 및 레이아웃 (Modular Design)

컴포넌트는 총 4개의 모듈로 구성되며, 크기 배분은 반응형(Responsive) 그리드를 따릅니다.

#### Module A: 경고 코드 표시 영역 (The Code Block)
*   **목적:** 시청자에게 '이것은 단순한 문제가 아니다'라는 인지적 충격과 권위를 부여합니다.
*   **위치:** 컴포넌트의 최상단, 좌측에 고정 배치.
*   **디자인 스펙:**
    *   **형태:** 얇고 긴 사각형 박스 (`border: 1px solid #00CCFF`). 배경은 반투명 `#0A2A3D`로 설정하여 깊이감을 줍니다.
    *   **텍스트:** `[SYSTEM_ALERT]`, `DEFECT ID: E-PENS75A`.
    *   **스타일:** **반드시 글로우 효과 (Box Shadow)**를 적용합니다. (`0 0 10px #FF4B4B`)
    *   **폰트 크기:** 코드 부분은 크게 (예: `2rem`), ID는 중간 크기로 (예: `1.5rem`).

#### Module B: 문제 요약 및 위기 메시지 (The Diagnosis)
*   **목적:** 전문 용어를 사용해 문제를 구조화하고, 시청자에게 구체적인 불안감을 심어줍니다.
*   **위치:** Code Block 아래에 배치되는 주 텍스트 영역.
*   **디자인 스펙:**
    *   **제목/헤딩 (H2):** `[DIAGNOSIS REPORT]`: Authority Gold 색상, 모노스페이스 폰트, 볼드 처리.
    *   **본문 텍스트:** 핵심 키워드는 **굵게 강조(Bold)**하고, 일반 문장은 Primary Text를 사용합니다.
    *   **불안감 조성 요소 (Critical Warning):** '결손 비율', '하락 추세' 등의 표현 앞에는 `<<<CRITICAL>>>` 같은 경고 텍스트를 작게 삽입하여 시각적 강도를 높입니다.

#### Module C: 결함 수치 그래프/시각화 (The Data Breach)
*   **목적:** 감정적인 주장을 데이터로 증명하는 핵심 단계.
*   **위치:** 컴포넌트 중앙부, 가장 큰 비중을 차지합니다.
*   **디자인 스펙:**
    *   **유형:** '게이지(Gauge)' 또는 '프로그레스 바(Progress Bar)' 형태의 변형 사용. (단순 막대 그래프 지양)
    *   **시각화 로직:**
        1.  **기준선 (Baseline):** Data Blue 색상의 수평선 (`Y축=100%`). 이 선은 '정상 상태'를 의미합니다.
        2.  **실제 측정값 (Defect Value):** Alert Red 색상의 바가 기준선보다 **확연히 낮은 위치에서 끊겨나간 모습**으로 표현되어야 합니다. (공학적 결함의 시각화)
        3.  **레이블:** 수치 옆에 `[MEASUREMENT: -20% to -35%]` 와 같이 공학적인 측정값 레이블을 괄호와 대문자로 표시합니다.

#### Module D: 해결책 유도 버튼 (The Protocol Activation)
*   **목적:** 위기감의 최고조에서 자연스럽게 '해결책'으로 시선을 돌리고 행동하게 만듭니다.
*   **위치:** 컴포넌트 하단, 가장 눈에 띄는 곳.
*   **디자인 스펙:**
    *   **버튼 형태:** 일반적인 버튼이 아닌, **터미널 명령어 입력창 스타일의 사각형 패드**처럼 디자인합니다. (테두리만 빛나게)
    *   **텍스트:** "시스템 복구 프로토콜 활성화(ACTIVATE PROTOCOL)"와 같은 명령형 문구를 사용합니다.
    *   **색상:** Authority Gold 색상을 배경에 은은하게 적용하고, 호버 시 더욱 강렬한 Glow 효과를 줍니다.
