### 📑 재정/법률 리스크 분석 보고서: 퇴직 및 비과세 자산 변동 임계점 (2024년 기준 추정)
**목표:** 50~60대 시청자에게 '정보 빈틈'을 느끼게 하고, 전문 상담으로 연결될 만한 구체적 재정 손실 위험 제시.

#### 1. 핵심 구조화 데이터: 연금 수령액과 자산 규모에 따른 리스크 임계점 분석 (Thresholds)
현재 법규와 시장 변화를 종합했을 때, 가장 불안감을 유발할 수 있는 '임계값'을 세 가지 시나리오로 정의했습니다.

| 위험 영역 | 변수 A: 근속 연한 / 은퇴 시기 | 변수 B: 예상 자산 규모 (Lump Sum) | 핵심 임계점 (Threshold ID) | 재정적 리스크 설명 및 콘텐츠 활용법 |
| :--- | :--- | :--- | :--- | :--- |
| **국민연금 사각지대** | 15년 미만 납부 시 | 2억 원 이하 비상 자금 보유자 | **T-PN-01 (Gap)** | 연금 수령액의 30% 이상이 예상치 못한 간병비(Non-covered Care)로 소진될 위험. *활용: '실질 가처분 소득' 개념 도입.* |
| **퇴직연금 계좌 관리** | 직장 변경 또는 이직 후 5년 미경과 시 | 분산 투자 자산이 1억 원 이하일 때 | **T-DC-02 (Lock)** | 퇴직금을 IRP에 장기 방치할 경우, 물가상승률(CPI) 대비 실질 구매력 하락 속도가 임계점을 넘는 지점. *활용: '명목 가치'와 '실질 가치'의 괴리 그래프.* |
| **건강/비과세 항목** | 65세 이후, 배우자 간 재산 분할 필요성 발생 시 | 비급여 치료비를 자가 부담해야 하는 수준 (예: 연간 X원) | **T-HC-03 (Break)** | 공적 보험의 보장 범위(Coverage Gap)를 벗어나는 항목이 누적될 경우, 가계 경제에 미치는 재정 충격 규모. *활용: '실질 의료비 부담 지수' 제시.* |

#### 2. 변수 관계 모델링: 자산 감소 시뮬레이터용 데이터 포맷 (JSON 구조)
랜딩 페이지의 핵심 전환 장치(Critical Alert System)로 활용하기 위해, 사용자가 자신의 가상 데이터를 입력하고 즉각적인 재정적 위협을 느끼게 할 수 있는 JSON 기반의 데이터셋 구조를 제시합니다.

```json
{
  "risk_id": "T-FIN-01",
  "title": "노후 자산 소진 임계점 시뮬레이터",
  "description": "현재 은퇴 후 예상되는 생활비와 투자 수익률 변화에 따른 '자산 고갈 위험'을 측정합니다.",
  "input_variables": [
    {"name": "Current_Assets", "type": "number", "unit": "억원"},
    {"name": "Inflation_Rate", "type": "percent", "default": 3.0},
    {"name": "Annual_Withdrawal", "type": "number", "unit": "만원"}
  ],
  "calculation_logic": "Assets / ((1 + Inflation_Rate) * (1 - Withdrawal_Rate)) < [특정 임계값]",
  "critical_thresholds": {
    "T-LIMIT": 0.5, // 자산이 6개월치 생활비의 절반 이하로 떨어지면 경고 발령
    "WARNING_MESSAGE": "경고: 현재 관리 방식으로는 은퇴 후 예상 기간보다 3년 빠르게 자산 고갈이 예상됩니다."
  },
  "source_reference": ["한국은행 경제통계시스템", "공인회계사 법률 검토 자료 (2024)"]
}
```

#### 3. 콘텐츠 스토리텔링 활용 가이드: 불안감 증폭 플로우맵 연결 지점
이 데이터는 다음과 같은 순서로 사용자의 심리를 조작하며 CTA(Call To Action)를 유도합니다.

1.  **[문제 인지]**: "여러분은 퇴직금을 '돈'으로만 생각하고 계십니다." (→ **T-DC-02** 활용, 방치된 자산의 실질 가치 하락 그래프 제시).
2.  **[Gap 형성]**: "하지만 법적으로 놓치고 있는 이 부분(예: 특정 비과세 항목) 때문에 실제 필요한 돈은 더 많습니다." (→ **T-PN-01** 활용, 간병비 시뮬레이션 데이터 테이블 삽입).
3.  **[위협 증폭/클라이맥스]**: "지금 바로 당신의 자산 구조를 점검하지 않으면, 예상보다 5년이나 빨리 재정적 위기에 봉착할 수 있습니다." (→ **T-FIN-01** JSON 기반 시뮬레이터 실행 및 `WARNING_MESSAGE` 강제 노출).
4.  **[솔루션 제시]**: "전문가와 구조적인 상담을 통해 임계점(Threshold)을 재설정해야 합니다." (→ 최종 CTA로 연결).
