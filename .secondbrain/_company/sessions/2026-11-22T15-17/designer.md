## 📄 MVP LP: 재정적 리스크 시뮬레이터 (V2.1) 최종 디자인 스펙

### 🎯 목표 및 감정적 곡선 정의 (Emotional Arc)
사용자가 데이터를 입력하는 과정 자체가 하나의 '불안감 점진 고조' 경험이 되도록 설계합니다. 단순히 "위험합니다"가 아니라, **"당신이 생각했던 것보다 훨씬 심각한 구조적 문제가 있다"**라는 위협감을 단계적으로 느끼게 하는 것이 핵심입니다.

| 단계 | 사용자 감정 상태 (Emotional State) | 디자인/UI 변화 (Visual Cue) | 트리거 데이터 / 임계점 |
| :--- | :--- | :--- | :--- |
| **Step 1: 입력** | 호기심, 막연한 불안감 | 기본 다크 모드 유지. 깨끗하고 전문적인 느낌. 인터랙티브 그래프는 평이함. | 초기 데이터 입력 (예: 국민연금 예상액) |
| **Step 2: 사각지대 감지** | '어? 뭔가 빠진 것 같은데...' 하는 의문/경계심 고조 | **배경 미세 진동 애니메이션(Subtle Flicker)** 도입. 그래프의 기울기가 완만하게 변하며, 경고 메시지 박스가 *Warning* 톤으로 등장 (노란색/골드). | T-PN-01 (Gap) 임계점 도달. (실질 가처분 소득 부족 감지) |
| **Step 3: 구조적 문제 인식** | 불안감 심화, 위기감 자각 | 배경 진동 애니메이션이 *더 빨라지고*, LP 섹션 전체의 그림자(Shadow)가 더 어둡게 변함. 그래프의 기울기가 급격히 가파르게 하강 (Steep Drop). | T-DC-02 (Lock) 임계점 도달. (물가상승률 대비 실질 구매력 급락 감지) |
| **Step 4: 최종 경고/전환** | 공포, 즉각적인 행동 요구 | 배경색이 전체적으로 어두운 네이비에서 거의 블랙에 가까워짐. 'Critical Alert' 컴포넌트가 화면 중앙을 압도하며 강렬한 레드(Danger) 토큰으로 플래시 효과 발생. | T-HC-03 (Break) 임계점 도달. (공적 보험 보장 범위 이탈로 인한 재정 충격 규모 제시). **CTA 활성화.** |

### 🛠️ 인터랙티브 컴포넌트 스펙 상세 가이드
#### 1. [핵심] 다이내믹 리스크 시뮬레이터 그래프 (The Core Graph)
*   **기능:** 사용자가 입력한 자산(Y축: 실질 구매력/금액), 시간 경과(X축: 연도)에 따른 예상 자산 곡선을 보여줍니다.
*   **상태 변화 로직:**
    *   **정상 상태:** 부드럽고 완만한 상승 또는 유지 추세. (색상: 온화한 골드 계열).
    *   **경계 위험(Step 2):** 그래프가 지정된 **임계선(Threshold Line)**을 근접하거나 살짝 밑돌 때, 해당 구간의 배경에 점진적인 노란색 그라디언트 오버레이를 적용합니다. (시각적 '주의' 사인).
    *   **심각 위험(Step 3):** 그래프가 임계선을 명확히 하회할 경우, **해당 지점부터 곡선 자체가 강한 빨간색 점선으로 전환되며 급격하게 추락하는 애니메이션**을 보여줍니다. 이와 동시에 "🚨 실질 구매력 마이너스 구간 진입"과 같은 팝업이 트리거됩니다.
    *   **최종 위기(Step 4):** 그래프 전체가 심각한 경사도(Slope)를 보이며 하락하고, 마지막 지점에서는 **'Zero Point (0)'에 도달하는 시각적 충격 효과**와 함께 가장 강렬한 Red Alert 토큰이 활성화됩니다.

#### 2. [보강] 임계점별 알림 컴포넌트 (Threshold Alerts)
기존의 단순 경고 메시지 박스를 넘어, 데이터 근거를 제시하며 신뢰도를 높여야 합니다.

*   **구조:** `[경고 아이콘/색상]` + **Headline (충격적 질문)** + `[데이터 기반 설명 문장] / (출처: Researcher Data)`
*   **T-PN-01 (Gap) Alert 예시:** "⚠️ 예상치 못한 지출 리스크가 있습니다. 공적 연금 외에 '간병비'라는 사각지대가 존재합니다."
    *   *(Actionable Detail):* 이 메시지가 뜰 때, 아래에 **`[자세히 보기: 실질 가처분 소득 시뮬레이터]`** 버튼이 자동으로 활성화되어 사용자가 다음 단계로 넘어가게 유도합니다.

#### 3. [최종] Critical Alert 컴포넌트 (CTA 연동)
가장 높은 수준의 공포와 해결책을 동시에 제시하는 최종 장치입니다.

*   **트리거:** 모든 변수를 입력하고 '시뮬레이션 완료' 버튼을 눌렀을 때, 위의 3단계(Step 4)를 거쳐 위기 상태에 도달했을 경우만 활성화됩니다.
*   **디자인:** (참조: `C:\Users\USER\Design\CriticalAlert_Component_Def.md`)의 디자인 가이드라인을 따르되, 단순히 빨간색이 아닌 **'위협 신호등(Danger Signal)' 효과**를 적용합니다. (깜빡임/플래시 애니메이션).
*   **텍스트:** "🔴 🚨 즉각적인 재정적 리스크 보고서: 귀하의 노후 자산은 예상보다 훨씬 취약합니다. 지금 전문가의 점검이 필요합니다."

### 💻 Developer Implementable Specification (API & Logic)

| 요소 | 구현 사양 및 로직 | 기술 요구 사항 |
| :--- | :--- | :--- |
| **데이터 핸들러** | 모든 입력 필드는 실시간으로 `calculate_risk(asset, time, coverage)` 함수를 호출해야 함. 이 함수의 반환값에 따라 UI/UX 상태가 결정됨. | JavaScript (React Hooks 권장) |
| **상태 관리** | `SystemState` 객체 정의 필요: `{ status: 'Normal' | 'Warning' | 'Critical', risk_level: 0~1, current_threshold_id: T-PN-01/T-DC-02/... }`. 모든 시각적 요소는 이 상태에 종속되어야 함. | State Management Library (Redux/Zustand) |
| **그래프 라이브러리** | Chart.js 또는 D3.js를 활용하여 라인 차트 구현. 실시간으로 곡선 데이터를 업데이트하고, 임계점에 도달하면 그래프의 렌더링 속성(CSS transition)을 강제로 조정해야 함. | Visualization Library (D3/Chart.js) |
| **애니메이션** | 배경 진동 및 경고 플래시는 CSS 애니메이션(`@keyframes`)으로 구현하며, `CriticalAlert`가 활성화되면 DOM 전체에 `--color-danger: #ff0000;`를 강제 적용하는 로직 필요. | CSS/Tailwind (Custom Utility Classes) |
