### 📐 Gap Area Chart Design System Specification V1.0

**[문서 목적]**
본 문서는 '미인지된 재정적 사각지대(The Financial Gap)'를 시각화하는 표준 인터랙티브 컴포넌트인 'Gap Area Chart'의 최종 디자인 및 개발 명세서를 제공합니다. 모든 콘텐츠(블로그, 롱폼, 숏폼)는 이 시스템을 따릅니다.

**[1. 핵심 브랜드 요소 정의]**
| 항목 | 상세 내용 | 규격/코드 | 비고 |
| :--- | :--- | :--- | :--- |
| **차트 배경 (Base)** | Deep Navy Blue (전문성, 신뢰감) | `#0A1931` | 모든 차트의 기본 배경색으로 사용. |
| **정상 범위 (Safe Zone)** | 짙은 회색 또는 어두운 청록색 | `#2D4E6F` | 데이터가 정상 범위에 있을 때의 색상 (기준선). |
| **Gap 범위 (Danger Zone)** | 경고 오렌지 (위험, 긴급성) | `#FF7B00` | Gap 발생 구간을 표시하는 핵심 액센트 컬러. 시선을 즉시 사로잡아야 함. |
| **데이터 라인** | 밝은 골드/옐로우 | `#FFC300` | 실제 데이터 추이를 나타내는 메인 라인 색상. |
| **폰트 (Axis Label)** | Noto Sans KR 또는 Pretendard | Primary Font | 가독성이 최우선이며, 흰색 텍스트를 기본으로 사용. |

**[2. 컴포넌트 구조 및 레이아웃 명세]**
*   **구조:** A vs B 비교형 (Comparison Chart)
    *   **A축 (X-Axis):** 시간 경과에 따른 항목/연도 (예: 2024년 $\rightarrow$ 2034년).
    *   **Y축 (Y-Axis):** 재정적 가치 또는 금액 단위.
    *   **데이터 레이어:**
        1.  **Baseline Layer (Safe Zone):** 정상적인 예상/기준선 값 ($\text{Value}_{\text{Ideal}}$)을 표시하는 넓은 Area Chart (`#2D4E6F`). 이 부분이 가장 큰 면적을 차지하여 '안정감'을 조성합니다.
        2.  **Actual Data Layer (A):** 현재 또는 측정된 데이터 값 ($\text{Value}_{\text{Current}}$)을 나타내는 라인 및 채움 영역 (`#FFC300`).
        3.  **Gap Area:** $\text{Value}_{\text{Ideal}} - \text{Value}_{\text{Current}}$의 차이를 계산하여, Safe Zone 위에 덮어씌우는 직사각형/그래프 형태의 면적. **이 Gap 영역은 `#FF7B00`로 강조되어야 합니다.**

**[3. 상호작용 로직 (Interaction Spec) 상세화]**
코다리가 구현할 때 필수적으로 고려해야 할 인터랙션 요소입니다.

| 동작 | 트리거 | 시각적 변화/효과 | 개발 요구사항 (Kodari) |
| :--- | :--- | :--- | :--- |
| **툴팁 활성화** | 마우스 커서가 Gap Area 내에 진입할 때 (`:hover`) | 1. `#FF7B00` 영역이 미세하게 밝아지거나, 테두리가 생김. 2. 차트 중앙 상단 또는 하단에 **팝업 형태의 요약 박스**가 나타남. | `Tooltip Component (SVG/React)` 구현 필수. 데이터 ID와 함께 'Gap 발생액: X원'을 명확히 표시해야 함. |
| **데이터 강조** | 마우스 커서가 특정 연도 지점에 머무를 때 | 1. 해당 연도의 모든 요소(라인, Gap 면적)의 투명도가 일시적으로 증가함 (Focus). 2. Y축과 X축에 수직/수평 가이드 라인이 나타나 데이터 포인트를 명확히 분리함. | 애니메이션 지연 시간(Delay): 150ms. 사용자 경험을 해치지 않는 부드러운 전환 효과 적용. |
| **데이터 출처 표시** | 차트의 우측 하단 (Footer) | 모든 차트가 사용한 데이터셋 ID 및 공신력 있는 출처(예: "출처: 국민연금공단 2024년 통계 기반")를 명확히 배치. | 별도의 `Authority Box Component`로 분리하여, 배경색을 연한 회색 계열로 처리하고 신뢰도를 높여야 함. |

## 🎯 목표: 미인지된 재정적 사각지대(The Financial Gap) 시각화 표준 확립

### 1. 기본 구조 및 색상 팔레트 (SVG/CSS 기반)
*   **배경:** Deep Navy Blue (`#0A1931`) - 신뢰, 전문성
*   **Gap Area (위험):** 경고 오렌지 (`#FF7B00`) - 긴급함, 주의 환기 (핵심 액센트)
*   **Safe Zone (기준선):** Dark Slate Blue (`#2D4E6F`) - 안정성, 대비 제공
*   **데이터 라인:** Gold/Yellow (`#FFC300`)

### 2. A vs B 비교형 레이어 구조
| 레이어 명칭 | 역할 | 색상 코드 (Hex) | 기능적 요구사항 |
| :--- | :--- | :--- | :--- |
| **Baseline Layer ($\text{Value}_{\text{Ideal}}$)** | 정상/예측 가치. 기준점 설정. | `#2D4E6F` | 넓은 면적으로 표현하며, Gap 대비를 위한 무대를 제공함. |
| **Actual Data Layer ($\text{Value}_{\text{Current}}$)** | 현재 측정된 값. 실제 데이터 포인트. | `#FFC300` | 라인과 채움 영역 모두 사용. 추이 변화가 명확해야 함. |
| **Gap Area** | $\text{Ideal} - \text{Current}$의 결손액. | `#FF7B00` | 이 컴포넌트의 핵심. 면적(Area)으로 표현되어 '결손'을 시각화함. 반드시 인터랙션 적용. |

### 3. 상호작용 및 개발 명세 (Kodari 필수 구현)
1.  **툴팁/팝업:** 마우스 오버 시, 해당 지점의 **Gap 금액과 연도**를 중앙에 표시하는 모달(Tooltip)이 즉시 떠야 함. (지연 시간 150ms).
2.  **애니메이션:** 로딩 시, Safe Zone $\rightarrow$ Actual Data $\rightarrow$ Gap Area 순으로 단계적으로 데이터가 쌓이는 듯한 애니메이션 효과를 적용하여 '발견'의 과정을 연출해야 함.

### 4. 활용 가이드라인 (CTA Funnel)
*   **차트 하단:** "이 Gap, 방치하시면 안 됩니다."라는 문구와 함께 **[무료 진단 받기]** 버튼을 배치합니다.
*   **색상 대비:** CTA 버튼은 차트의 Deep Navy Blue 배경 위에서 가장 눈에 띄는 색상(예: 밝은 흰색 또는 골드)으로 처리하여 이탈 없이 다음 액션으로 이어지도록 유도해야 합니다.
