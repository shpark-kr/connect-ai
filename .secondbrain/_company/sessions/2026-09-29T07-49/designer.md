## 📱 A. 모바일 UX/UI 개선 브리프 (Mobile Shock Value Maximization)

| 요소 | 기존 설계 의도 | **UX 개선 포인트 (Shock Factor)** | 기술적 사양 및 애니메이션 타이밍 |
| :--- | :--- | :--- | :--- |
| **1. 진입 시점** | 일반적인 결제 화면 전환 | **[시스템 강제 오류 발생]** 상태 변화를 통해 불안감을 즉시 주입합니다. 마치 '무언가 잘못된 것'을 사용자 스스로 느끼게 합니다. | - **트리거:** CTA 클릭 $\to$ 0.1초 로딩 스피너 (일반) $\to$ **(0.2초 지연)** 화면 전체에 깜빡이는 `[ERROR: SYSTEM FAILURE]` 오버레이 발생.<br>- **사운드:** 낮은 주파수의 불안정한 경고음 (Dissonant Tone). |
| **2. 오류 메시지** | 텍스트로 위기감 전달 | **[공학적 강제 인식]** 단순한 문구가 아닌, 시스템 자원 고갈의 시각화된 '코드'와 함께 제시합니다. | - **UI:** Deep Crimson Red (`#8B0000`) 배경에 `[ERROR CODE: HOMA-IR_L3]`가 깜빡이는 픽셀 효과 적용.<br>- **애니메이션:** 오류 메시지 등장 시, 좌우에서 경고선이 빠르게 스캔하듯 나타났다 사라짐 (Scanning Line Effect). |
| **3. 재정적 위협 제시** | 일반적인 리스크 설명 | **[손실 예측의 충격]** '지금 안 하면 잃는다'는 경제적 공포를 수치화하고, 이를 시각적으로 폭발시킵니다. | - **비주얼:** "미진단 시 예상 의료 비용: **₩103,450,000**" 문구에만 배경을 Deep Crimson Red로 채우고, 숫자 부분은 흰색으로 강조 (최대 대비).<br>- **타이밍:** 이 수치가 화면 중앙에서 *'팝업/폭발'* 하듯이 등장해야 합니다. |
| **4. CTA 유도** | 결제 버튼 배치 | **[유일한 탈출구]** 위기감과 경고 메시지 사이의 간극을 메우는 '필수 생존 장치'처럼 보이게 합니다. | - **버튼 디자인:** 일반적인 플랫 버튼이 아닌, 전력이 흐르는 듯한 미세한 LED 효과를 준 사각형 형태.<br>- **텍스트:** "지금 진단하고 위협 회피하기" (명령조).

## 🎨 B. 최종 Mockup 구조 및 컴포넌트 명세 (Figma/CSS 기반)

### 1. 레이아웃 구조 (Mobile First)
*   **Header:** 로고 + '진단 결과 분석 중...' (불안정한 느낌의 타이핑 효과).
*   **Body (The Shock):** 오류 코드 $\to$ 위협 메시지(Deep Crimson Red) $\to$ 재정적 손실 수치.
*   **Footer (Solution Funnel):** CTA 버튼과 미세한 안전 경고 문구 (`*전문가와 상담하지 않을 경우, 위험도는 기하급수적으로 증가할 수 있습니다.*`).

### 2. 색상 팔레트 및 대비 강도
| 용도 | 코드 (Hex) | 역할 | 비고 |
| :--- | :--- | :--- | :--- |
| **배경/기본** | `#1A1A2E` (Dark Navy) | 신뢰, 전문성 유지. | 전체 배경색. |
| **Deep Crimson Red** | `#8B0000` | 위협, 경고, 시스템 오류. | 주요 강조색 및 배경 오버레이에 사용. |
| **강조/하이라이트** | `#FFD700` (Gold) | 전문성, 핵심 솔루션 부각. | CTA의 텍스트나 중요 수치 일부에 제한적으로 사용. |
| **텍스트 기본** | `#FFFFFF` | 가독성 최우선. | 일반 텍스트 및 배경 대비를 극대화. |

### 3. 애니메이션 상세 스펙 (Keyframes)
*   **[Error Code 등장]**: `opacity: 0` $\to$ `opacity: 1` (Transition Duration: 0.2s, Timing Function: Cubic-Bezier(0.5, 0, 0.1, 1)). 동시에 화면에 전파되는 노이즈 필터 적용.
*   **[재정적 손실 수치]**: 숫자가 한 번에 나타나는 것이 아니라, '계산 중'이라는 느낌으로 초당 약 3자리씩 카운트업 되는 애니메이션 (`Number Animation`). 이 과정에서 빨간색 플래시가 깜빡여야 함.
