## 📐 핵심 디자인 시스템 변수 (Global Variables)

이 값들은 모든 컴포넌트의 기본 색상으로 사용되며, A/B 테스트 시 쉽게 변경 가능하도록 정의되었습니다.

```css
:root {
  /* 브랜드 컬러 */
  --color-primary-navy: #1A237E; /* 진한 네이비 (배경, 신뢰) */
  --color-accent-gold: #FFC107;  /* 골드/노랑 (기회, 강조점) */
  --color-danger-red: #D32F2F;   /* 빨강 (위험, 경고) */
  --color-success-green: #4CAF50; /* 녹색 (해결책, 긍정 변화) */

  /* 텍스트 및 배경 */
  --color-text-light: #E0E0E0;   /* 본문 텍스트 색상 */
  --color-background-dark: #12163d; /* 최하단 배경색 (딥 스페이스 블루) */
  --spacing-unit: 1rem;          /* 기본 간격 단위 */

  /* 가독성 및 타이포그래피 */
  --font-family-primary: 'Noto Sans KR', sans-serif;
}
```

## 🖼️ 모듈 1. Gap Visualization Module (정보 공백 시각화)

**목표:** 복잡한 개념을 Before(위험/손실)와 After(안전/이익)의 극명한 대비로 보여주어, 정보 습득의 긴급성을 자극합니다.
**형식:** SVG 기반 2-Column 비교 구조 (모바일 환경에서는 수직 스택).

### ✏️ 디자인 브리프 및 구현 스펙

1.  **구조:** `[Before: Problem/Loss]` | `[After: Solution/Gain]`
2.  **애니메이션 가이드:** Before 섹션은 흐릿하거나 깨지는(Glitch) 애니메이션을, After 섹션은 명확하게 채워지거나 성장하는(Grow) 애니메이션을 적용하여 심리적 대비를 극대화합니다.

| 요소 | 스펙 (CSS/SVG 속성) | 설명 및 사용 예시 |
| :--- | :--- | :--- |
| **컨테이너** | `display: flex; gap: 2rem; padding: 4rem 0;` | 모바일(<=768px): `flex-direction: column;` 적용 필수. |
| **위험 구역 (Before)** | 배경색: `--color-danger-red` 투명도 15%. 테두리: `2px solid var(--color-danger-red)`. 아이콘: 위험 삼각형 (`⚠️`). | **텍스트 강조:** '❌', '손실 가능성', '미흡한 대비' 등 부정적 키워드에 사용. |
| **해결 구역 (After)** | 배경색: `--color-success-green` 투명도 15%. 테두리: `2px solid var(--color-accent-gold)`. 아이콘: 체크마크 (`✅`). | **텍스트 강조:** '✔️', '확보된 권리', '최적화 방안' 등 긍정적 키워드에 사용. |
| **데이터 시각화** | SVG `rect`와 `path`를 사용하여, Before는 낮은 곡선/높은 변동성을, After는 안정적인 우상향 곡선을 그립니다. | **필수 요소:** 두 섹션 사이에 화살표(`→`) 아이콘을 배치하여 흐름과 전환(Transition)을 시각적으로 강조합니다. |
| **모바일 최적화** | 텍스트 크기: `min-width` 설정 및 반응형 타이포그래피 (`vw` 또는 `clamp()`) 적용. | Before/After 헤딩은 최대 3줄 초과 금지 원칙 준수. |

## 🟡 모듈 2. CTA Button Component (행동 유도 버튼)

**목표:** 콘텐츠의 마지막에 위치하여, 시청자의 불안감을 '해결할 수 있는 행동'으로 즉시 전환시키는 역할을 수행합니다.
**형식:** Props 기반, 고대비 Gradient 버튼 컴포넌트.

### ✏️ 디자인 브리프 및 구현 스펙

1.  **Props (속성):** `text`, `linkUrl`, `isPrimary` (기본/보조), `urgencyLevel` (긴급도).
2.  **CSS Variables:** 버튼의 모든 색상과 크기는 변수로 관리됩니다.

| 속성 | 스펙 (CSS) | 설명 및 사용 예시 |
| :--- | :--- | :--- |
| **기본 스타일** | `padding: 1rem 2rem; border-radius: 50px; cursor: pointer; text-transform: uppercase; transition: all 0.3s ease;` | 모바일 터치 영역을 고려하여 충분한 크기를 확보합니다. |
| **Primary (최종 목표)** | `background-image: linear-gradient(90deg, var(--color-danger-red), var(--color-accent-gold)); color: white; box-shadow: 0 6px 15px rgba(211, 47, 47, 0.5);` | **긴급성 강조:** 빨강과 골드를 조합하여 '지금 당장 클릭해야 한다'는 심리적 압박을 유도합니다. (가장 중요) |
| **Hover/Active** | `transform: translateY(-2px); box-shadow: 0 8px 20px rgba(211, 47, 47, 0.6);` | 클릭 가능한 '입체감'을 부여하여 반응성을 높입니다. |
| **Secondary (보조)** | `background-color: var(--color-primary-navy); border: 1px solid var(--color-accent-gold); color: var(--color-text-light);` | 전문 자료 다운로드, 블로그 참고 등 주 CTA 외의 보조 행동 유도에 사용합니다. |

## 📈 모듈 3. Credibility Graph (신뢰도 및 비교 그래프)

**목표:** 복잡한 통계 데이터(예: 연금 개정률 변화, 세액 공제 비율)를 직관적이고 전문가적인 방식으로 제시하여 콘텐츠의 신뢰도를 극대화합니다.
**형식:** SVG 기반 인터랙티브 차트 컴포넌트 (데이터 포인트 강조).

### ✏️ 디자인 브리프 및 구현 스펙

1.  **구조:** 하나의 그래프가 아닌, **비교 가능한 여러 개의 작은 모듈(Micro-Graphs)** 조합으로 구성됩니다.
2.  **핵심 원칙:** 데이터 레이블은 반드시 '절대값'과 '변화율 (%)'을 함께 표시하여 이해도를 높입니다.

| 요소 | 스펙 (SVG/CSS) | 설명 및 사용 예시 |
| :--- | :--- | :--- |
| **차트 타입 A (시간 흐름)** | 꺾은선 그래프 (`<path>`). Y축: 금액 단위, X축: 연도. | 과거 대비 현재의 변화를 보여줄 때 사용합니다. **강조점:** '가장 큰 하락 지점'에 `--color-danger-red` 마커 포인트를 지정하고 설명을 추가합니다. |
| **차트 타입 B (분포 비교)** | 도넛/파이 차트 (`<circle>` 조합). 비율 제시. | 복잡한 비율(예: 세금 vs 비과세)을 보여줄 때 사용하며, 전체 대비 '놓치고 있는 부분'의 면적에 `--color-accent-gold`를 할당하여 시각적으로 부각합니다. |
| **인터랙티브 요소** | SVG `cursor: pointer;`. 마우스 오버 시 해당 데이터 포인트가 크게 확대되며(Zoom effect), 툴팁으로 상세 수치가 표시되어야 합니다. | 전문성을 높이는 핵심 기능입니다. 사용자가 궁금증을 느끼는 순간 정보를 제공합니다. |
| **브랜드 적용** | 그래프의 배경 격자선은 연한 회색(`rgba(255, 255, 255, 0.1)`)을 사용하여 데이터 자체에 시선이 집중되게 합니다. |
