### 📁 **산출물: LP 마스터 인터랙티브 컴포넌트 브리프 V2.1**

#### 📌 **I. 시스템 개요 및 목적 (Design Principle)**
*   **목표:** 리드 데이터 수집의 신뢰도(Trust) 극대화 및 CTA 클릭률(CTR) 최적화.
*   **톤앤매너:** 전문가적이고 단호하며, 사용자의 행동을 명확하게 유도하는 '경고/안전' 톤 유지.
*   **핵심 전략:** 높은 시각적 대비(High Contrast)와 일관된 인터랙션 피드백 제공.

#### 🎨 **II. 컬러 팔레트 (Color Palette)**
| 용도 | 이름 | Hex Code | RGB Values | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary CTA** | Trust Blue | `#0A2463` | R:10, G:36, B:99 | 신뢰성 및 메인 액션 색상. 배경보다 전경 사용 권장. |
| **Secondary Accent** | Warning Gold | `#FFC72C` | R:255, G:199, B:44 | 기회/주의 포인트를 강조할 때만 제한적으로 사용 (핵심 수치 하이라이트). |
| **Success State** | Safety Green | `#38A169` | R:56, G:161, B:105 | 폼 제출 성공 시 피드백에 사용. |
| **Error/Danger** | Alarm Red | `#D52B3C` | R:213, G:43, B:60 | 필수 입력 누락 또는 유효성 검사 실패 시 사용. |
| **Text Primary** | Deep Navy | `#1A202C` | R:26, G:32, B:44 | 텍스트 본문 및 레이블에 사용 (최대 가독성). |
| **Background Base**| Clean White | `#FFFFFF` | R:255, G:255, B:255 | 대부분의 배경색. |

#### ✒️ **III. 타이포그래피 시스템 (Typography)**
*   **폰트 패밀리:** Pretendard 또는 Noto Sans KR (가독성이 높고 디지털 환경에 최적화된 산세리프 계열)
*   **주요 크기:** 본문(Body): 16px / 제목(H2): 30px / CTA 버튼: 18px

#### 🧱 **IV. 컴포넌트 마스터 에셋 세트 (Master Assets)**

---

##### **1️⃣ [CTA Button] - PDF 다운로드/제출 버튼**
*   **역할:** 사용자의 최종 행동을 유도하는 가장 중요한 요소. 시선이 강하게 머무르도록 디자인해야 함.
*   **기본 스타일 (Default State):**
    *   배경: `#0A2463` (Trust Blue)
    *   텍스트: `#FFFFFF` (White)
    *   패딩: Vertical 16px / Horizontal 48px
    *   폰트 크기: 18px, Bold
    *   모서리 곡률(Border Radius): 8px
    *   호버 효과 (Hover): 배경을 약간 밝은 블루 `#2C52A0`으로 변경하며, 그림자(Box-shadow)를 추가하여 입체감을 부여.
    *   클릭 시 (Active/Click): 배경을 어두운 네이비 `#071F46`로 눌리는 효과 연출.
*   **직관적 명칭:** "✅ 무료 가이드 다운로드 받기" 또는 "👉 사각지대 점검 시작하기"

##### **2️⃣ [Input Field] - 필수 정보 입력 폼 (Form Input)**
*   **역할:** 데이터를 입력하는 과정에서 심리적 장벽을 낮추고, '안전한 공간'이라는 느낌을 제공.
*   **기본 스타일 (Default State):**
    *   배경: `#FFFFFF`
    *   테두리(Border): 1px solid `#D1D5DB` (옅은 회색)
    *   패딩: Vertical 12px / Horizontal 16px
    *   폰트 크기: 16px, Regular
    *   모서리 곡률(Border Radius): 4px
*   **포커스 상태 (Focus State - ★필수★):**
    *   테두리 색상: `#0A2463` (Trust Blue)로 즉시 변경.
    *   테두리 두께: 2px (강조).
    *   사용자에게 "지금 여기에 집중하고 있습니다"라는 피드백을 주어 사용성을 높임.
*   **오류 상태 (Error State):**
    *   테두리 색상: `#D52B3C` (Alarm Red)로 즉시 변경.
    *   에러 메시지(Text): 빨간색 텍스트와 함께 필수 항목임을 명확히 고지.

##### **3️⃣ [Form Container] - 전체 폼 영역**
*   **역할:** 입력 필드들을 하나의 논리적이고 안전한 단위로 묶어주는 역할.
*   **디자인:** 주변 배경과 확실하게 분리되는 카드 형태(Card Layout)가 가장 효과적임.
    *   배경: `#F7FAFC` (아주 연한 회색/블루 계열).
    *   테두리: 1px solid `#E2E8F0`.
    *   패딩: 전체 영역에 충분한 여백을 주어 복잡하지 않고 '전문적인 느낌'이 들도록 설계.

## 💻 컴포넌트별 상세 사양 (Specifications)

### 🔵 1. CTA 버튼 (Button: Download / Submit)
*   **형태:** 직사각형 모서리 곡률(Border Radius): 8px
*   **[Default]**:
    *   배경: `#0A2463` (Trust Blue)
    *   텍스트: `#FFFFFF` (White)
    *   패딩: V16px / H48px
    *   폰트 크기: 18px, Semi-Bold
*   **[Hover]**:
    *   배경: `#2C52A0` (Trust Blue 계열 밝게 변경)
    *   효과: `box-shadow: 0 4px 6px rgba(10, 36, 99, 0.3);` 추가.
*   **[Focus/Active]**:
    *   배경: `#071F46` (더 어둡게)
    *   효과: 눌리는 느낌을 주는 미세한 색상 변화와 그림자 감소.

### 📝 2. 입력 필드 (Input Field)
*   **[Default]**:
    *   배경: `#FFFFFF`
    *   테두리: 1px solid `#D1D5DB` (옅은 회색)
    *   패딩: V12px / H16px
    *   폰트 크기: 16px, Regular
*   **[Focus]**:
    *   테두리 색상: `1px solid #0A2463` (Trust Blue)로 즉시 변경. (가장 중요!)
*   **[Error]**:
    *   테두리 색상: `1px solid #D52B3C` (Alarm Red).
    *   *Tip:* 필드 아래에 빨간색 텍스트의 오류 메시지(예: "이메일 형식이 올바르지 않습니다.")를 반드시 추가할 것.

### 📦 3. 폼 컨테이너 (Form Container)
*   **배경:** `#F7FAFC` (연한 회색). 주변 배경과 분리되어 집중도를 높입니다.
*   **구조:** `div` 태그로 전체를 감싸고, 내부 필드와 버튼 사이에 충분한 세로 여백(Spacing)을 확보하여 시각적 피로도를 낮춥니다.
