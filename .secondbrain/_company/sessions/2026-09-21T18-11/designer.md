## 🎯 목적 및 적용 범위
*   **목적:** 콘텐츠의 일관성(Consistency), 전문성(Authority), 시급성(Urgency)을 극대화하여 사용자 경험을 표준화하고 브랜드 인지도를 높인다.
*   **적용 대상:** 블로그 포스팅, 유튜브 썸네일/영상 내 그래픽, 인스타그램 리믹스 콘텐츠 전체.

## 🎨 1. 컬러 시스템 (Color Palette)
모든 색상은 웹 접근성(WCAG AA 이상)을 기준으로 정의하며, 명확한 역할에 따라 사용한다. 모든 Hex 코드는 개발자에게 전달되어야 할 변수 값이다.

| 이름 | 용도 | HEX Code | RGB | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (온현 메인)** | 핵심 강조, CTA 버튼 배경 | `#0A3D62` | (10, 61, 98) | 신뢰성, 깊이 있는 전문 지식 |
| **Secondary (포인트/하이라이트)** | 중요한 데이터 포인트, 링크 하이라이팅 | `#FFC72C` | (255, 199, 44) | 경고, 주목도, 금전적 가치 (Alert Gold) |
| **Background** | 기본 배경색 (웹/모바일 공통) | `#FFFFFF` | (255, 255, 255) | 고대비 확보를 위한 표준 흰색 |
| **Text-Dark** | 본문 및 제목 텍스트 | `#1A1A1A` | (26, 26, 26) | 가독성 최우선 (Black보다 부드러움) |
| **Danger/Alert** | 위험 요소, 손실(Gap Visualization) 시각화 | `#C0392B` | (192, 57, 43) | '놓치고 있는 위험'에 대한 감정적 자극 극대화 |

### ✨ CSS 변수 정의 예시
```css
:root {
  --color-primary: #0A3D62; /* 온현 메인 색상 */
  --color-secondary: #FFC72C; /* 경고/강조 골드 */
  --color-danger: #C0392B; /* 재정적 위험 */
  --color-text-dark: #1A1A1A; 
}
```

## 🔡 2. 타이포그래피 시스템 (Typography)
모바일 환경을 최우선으로 고려한 스케일링 규칙을 적용한다.

*   **메인 폰트:** Pretendard (또는 Noto Sans KR). 범용성, 가독성, 모바일 적합성이 높음.
*   **제목(H1-H3):** 볼드체(Bold)를 사용하되, 과도한 장식은 배제한다. 제목에 경고색(`Secondary`)을 포인트로 사용한다.
    *   **예시:** `font-size: 2rem; font-weight: 700; color: var(--color-primary);`
*   **본문 (Body):** 가독성을 위해 적절한 줄 간격(Line Height)이 필수이다.
    *   **권장 값:** `line-height: 1.6; font-size: 1rem;`

## 🖼️ 3. 아이콘 및 일러스트 시스템 (Iconography & Assets)
모든 아이콘은 SVG 포맷을 사용하며, 라이브러리 형태로 통합 관리한다. 이로써 개발 단계에서 '폰트'가 아닌 '벡터 에셋'으로 처리하여 스케일링 오류를 제거한다.

### 📁 필수 핵심 카테고리 (SVG Component Library)
1.  **위험/경고:** `⚠️ Warning`, `❌ Error`, `🔻 DownArrow` (Gap 시각화에 사용)
2.  **성공/확인:** `✅ Check`, `💡 Idea`, `📈 UpTrend` (혜택 발견, 해결책 제시 구간에 사용)
3.  **구분/흐름:** `➡️ ArrowRight`, `🔄 Cycle`, `🔗 Link` (Funnel 구조화 및 프로세스 설명에 사용)
4.  **사람/정책:** `👨‍👩‍👧‍👦 FamilyIcon`, `👤 ProfileIcon`, `📜 DocumentIcon` (타깃 청중 관련 콘텐츠에 사용)

## 📱 4. 모바일 친화적 컴포넌트 가이드라인 (The Component Library)
### A. 자막/캡션 스타일 (Video & Reel)
*   **배경:** 반투명 검은색 박스 (`rgba(0, 0, 0, 0.6)`)를 기본으로 사용하여 대비 효과를 극대화한다.
*   **텍스트:** 흰색(`FFFFFF`) 또는 경고 골드(`Secondary`)로 처리하여 주목도를 높인다.
*   **크기/위치:** 영상 중앙 하단에 고정 (하단 15% 영역). 최대 2줄을 초과하지 않도록 설계한다.

### B. Gap Visualization 그래프 (Infographic Standard)
*   **형식:** 반드시 **Before-After** 또는 **A vs B 비교 차트** 구조를 따른다.
*   **시각화 요소:** 손실되는 부분(Gap)은 `Danger/Alert` 컬러로 채우고, 획득하는 부분은 `Secondary` 또는 `Primary`로 강조한다.
*   **핵심 원칙:** **숫자 자체가 아니라 숫자가 의미하는 '손실의 크기'를 시각적 폭과 높이로 보여준다.** (시각적 충격 극대화)

### C. 전문 상담 CTA 버튼 (Call to Action)
*   모든 플랫폼에 통일성을 부여하기 위해 단일 컴포넌트로 지정한다.
*   **디자인:** `Primary` 컬러 배경 + 흰색 텍스트 + 모서리 라운딩(8px).
*   **문구:** "무료 전문 상담 받기" 또는 "나의 혜택 확인하기". (추상적이지 않고 명확한 행동 유도)
