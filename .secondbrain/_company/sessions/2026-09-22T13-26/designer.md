## 🎯 1. 시스템 목표 및 원칙
**목표:** 복잡한 금융/정책 데이터를 직관적으로 '위험'과 '손실 기회비용(Gap)'의 관점에서 전달하여, 청중에게 즉각적인 불안감(Pain Point)을 조성하고 해결책에 대한 니즈를 극대화합니다.
**톤앤매너:** 전문적(Professional), 신뢰성 기반(Trustworthy), 긴급함(Urgent).
**핵심 원칙:** 모든 데이터는 'Gap' (Expected vs Actual) 비교를 통해 표현되어야 하며, 배경의 어두운 톤이 높은 집중도를 유지하도록 설계합니다.

## 🎨 2. 비주얼 아이덴티티 가이드라인

### A. 컬러 팔레트 (Color Palette: Hex Code 기준)
| 용도 | 역할 및 의미 | 색상 코드 (Hex) | 사용 예시 |
| :--- | :--- | :--- | :--- |
| **Primary Background** | 전체 배경, 전문성 강조 | `#1A237E` (Deep Navy Blue) | 차트 배경, 섹션 배경 |
| **Secondary Text** | 본문 텍스트, 기본 정보 | `#F0F4FF` (Off-White/Cream) | 제목 및 주요 설명 텍스트 |
| **Accent Color (Gap)** | '손실된 Gap' 영역 강조 (가장 중요) | `#FF9800` (Warning Orange / Gold) | 차트의 음영 처리(Shading), CTA 버튼 배경 |
| **Expected Line** | 기대치/이상적인 흐름 | `#4CAF50` (Green - Stability) | 목표선, 예상 자금흐름 |
| **Actual Line** | 실제 현황/현재 상태 | `#FFCDD2` (Light Red/Pink) | 현재 수입/지출 선, Gap의 시작점 |
| **Danger Area Fill** | 위험 경고 영역 (Gap) | `rgba(255, 152, 0, 0.3)` (Orange Semi-Transparent) | 차트 음영 처리 (주요 시각적 요소) |

### B. 타이포그래피 가이드라인 (Typography Guidelines)
**폰트 선정:** Noto Sans KR 또는 Pretendard 계열 (가독성과 모던함을 겸비한 산세리프 폰트를 원칙으로 합니다.)

| 용도 | 권장 크기 (Desktop 기준) | 굵기(Weight) | 사용 목적 및 규칙 |
| :--- | :--- | :--- | :--- |
| **H1 - 메인 제목** | 48pt ~ 60pt | Bold / ExtraBold | 콘텐츠의 가장 충격적인 메시지 전달. 경고 아이콘과 함께 사용. |
| **H2 - 섹션 제목** | 30pt ~ 36pt | SemiBold | 주요 논점 구분. 질문형("~는 무엇인가요?")으로 작성 유도. |
| **Body Text (본문)** | 18pt ~ 24pt | Regular | 가독성 최우선. 문장은 짧게 끊어 정보 과부하 방지. |
| **Callout/Data Label** | 24pt ~ 30pt | SemiBold / Bold | 핵심 수치(숫자)를 강조할 때 사용. 배경 박스 처리 필수. |

## 📈 3. 핵심 컴포넌트: Gap Area Chart 표준 명세서 (Technical Spec)
이 차트는 모든 콘텐츠의 중심이자, '문제 제기'가 이루어지는 곳입니다.

### A. 시각화 구조 및 요소 배치
1.  **X축:** 시간 흐름 (연도 또는 월 단위).
2.  **Y축:** 금액(원) 혹은 비율(%) – 사용처에 따라 유동적 정의.
3.  **주요 선 1: Expected Line (기대치)**
    *   색상: `#4CAF50` (Green)
    *   의미: '이상적인 노후 자금 흐름' 또는 '법적 최대 수령액'. 시청자가 도달해야 할 목표.
4.  **주요 선 2: Actual Line (실제 현황)**
    *   색상: `#FFCDD2` (Light Red)
    *   의미: 현재 개인/가족이 실제로 확보했거나 수령하는 금액. 현실적인 위험성을 나타냄.
5.  **Gap Area:**
    *   구조: Expected Line과 Actual Line 사이의 음영 처리된 영역.
    *   색상: `rgba(255, 152, 0, 0.3)` (Warning Orange)
    *   표현 방식: 이 Gap이 곧 **'미인지된 재정적 손실 규모'**임을 강조합니다.

### B. 인터랙티브 요소 명세 (Interactive Elements Spec)
| 기능 | 기술 요구사항 (코다리 참고) | 목적 및 사용처 |
| :--- | :--- | :--- |
| **Tooltip/Hover** | 마우스 오버 시 해당 지점의 정확한 금액과 차이를 팝업 표시. (`data-point-id` 기반 연동 필수). | 데이터에 대한 신뢰도 확보 및 몰입감 증대. (롱폼, 웹) |
| **데이터 유효성 검증** | 모든 데이터를 JSON 스키마(`FinancialGapData v2.0`)와 비교하여 오류 발생 시, 차트를 중단시키지 않고 "데이터 미확인" 경고 메시지 표시 (Fallback Logic). | 안정적인 콘텐츠 배포 보장. (모든 플랫폼) |
| **애니메이션** | 선 그래프는 시작점에서 부드럽게(Smooth Easing) 그려지는 효과 적용. Gap Area는 마지막에 채워지며 충격감을 극대화. | 숏폼/영상에서 시선 집중 및 긴급성 부여. (레오 참고) |

## 📺 4. 플랫폼별 활용 가이드라인 (Consistency Rule)
| 콘텐츠 포맷 | 표현 방식의 중점 | 디자인 조정 포인트 |
| :--- | :--- | :--- |
| **유튜브 롱폼/숏폼** | **'경고 애니메이션'과 '데이터 충격'**. Gap Area가 채워지는 순간, 배경에 미세한 노이즈나 경고음 효과를 삽입하여 공포감을 극대화. (시각적 + 청각적 연출) |
| **블로그 포스팅** | **'권위 있는 분석 자료'**. SVG/PNG 형태로 고정된 이미지로 사용하되, 툴팁 기능을 설명하는 별도 문단 추가. 차트 주변에 '핵심 요약 박스(Callout Box)'를 배치하여 강조. |
| **인스타그램 릴스** | **'극도의 단순화 및 초점 이동'**. 전체 Gap 대신 가장 충격적인 *한 지점*의 비교만 보여줍니다 (예: 국민연금 vs 예상 생활비). 카운트다운 타이머나 빠른 전환 효과를 활용합니다. |
