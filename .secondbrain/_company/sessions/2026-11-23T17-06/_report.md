### 2. 웹 랜딩 페이지 Mockup 세트 (Desktop & Mobile)

#### A. Input UI 섹션: Gap Score 입력 및 전개
*   **목표:** 사용자에게 진입 장벽을 낮추면서도, '직접 측정해야 할 것 같은' 긴급성을 부여합니다.
*   **레이아웃:** 중앙 정렬 (Hero Section).
*   **UI 컴포넌트:**
    1.  **제목/헤드라인:** "당신의 건강은 얼마나 손실되고 있습니까? ⏰" (`Pretendard Bold`, Size: 36px, Color: White)
    2.  **설명 카피 (Sub-Headline):** "지금까지 미뤄온 시간만큼의 '잃어버린 가치'를 숫자로 확인하세요." (`Pretendard Regular`, Size: 18px, Color: #B0C4DE - 밝은 회색)
    3.  **Input Field:** (간단한 질문이나 데이터 입력 형태가 가장 좋음. 예: "최근 수면 시간(시간):")
        *   `Type`: Number Input. `Placeholder`: '예시: 5.5'
        *   `Focus State`: 배경색 `#1A2B50`, 테두리 색상 `Alarm Red`.

#### B. Time Projection Graph (핵심 애니메이션 스펙)
*   **목표:** 심리적 위기감(호기심 $\rightarrow$ 공포)을 시각화합니다. 그래프 자체를 하나의 '경고 장치'로 인식하게 만듭니다.
*   **컴포넌트명:** **Time Loss Projection Graph (TLPG)**
*   **그래프 구조:** X축: 시간 경과(월/년), Y축: 건강 점수 또는 손실률(%)
    *   **Baseline (기준선):** 안정적인 상태를 나타내는 은은한 `Accent Blue`의 꺾은선.
    *   **Projection Line (예측선):** 사용자가 현재 데이터로 입력했을 때 도달할 미래 위험점을 나타냅니다. 이 선이 **Alarm Red**으로 표시됩니다.
*   **🚨 필수 애니메이션 스펙: Time-Based Flashing Effect**
    1.  **Trigger:** 그래프가 특정 임계점(예: 25% 손실률)을 초과하는 구간에 도달했을 때 발동.
    2.  **Mechanism:** 해당 구간의 배경 영역 및 예측선 자체가 **3초 주기로 깜빡임 (Flash)** 효과를 반복합니다.
        *   *State A:* 완전히 빨간색 (`Alarm Red`)으로 짙게 채워짐 (High Alert).
        *   *State B:* 어두운 Navy Background가 순간적으로 노출됨 (Breathing Effect).
    3.  **UX 카피 연동:** 깜빡이는 동안, 그래프 아래에 "🚨 **위험 임계점 초과! 현재 방식으로는 2년 후 심각한 손실이 예상됩니다.**"와 같은 경고 문구가 굵은 고딕체로 강하게 노출되어야 합니다.

#### C. CTA 섹션: 진단 결과 $\rightarrow$ 유료 리포트 구매
*   **목표:** 위기감을 최고조로 끌어올린 후, **전문가 개입 및 책임감 부여**라는 심리적 가치로 결제 전환을 유도합니다.
*   **레이아웃:** Deep Navy 배경의 고대비 섹션 (Contrast Zone).
*   **콘텐츠 흐름:**
    1.  **진단 결과 요약 (Pain Point):** "당신이 놓치고 있는 3가지 핵심 손실 영역." (핵심 데이터 3가지가 카드 형태로 간결하게 나열됨)
        *   `Card Title`: 장기요양 사각지대 위험도: **85%** (빨간색으로 강조)
    2.  **Gap/Solution 제시:** "이 수치는 당신의 책임 영역을 보여줄 뿐입니다." (정보 제공) $\rightarrow$ "정확한 진단과 해결책은 전문가의 분석이 필요합니다." (문제 인식 및 공포 유발)
    3.  **CTA 버튼 (Final Conversion):**
        *   `Primary Button`: **[전문가 심층 리포트 받기 (유료)]**
        *   *스펙:* 배경색 `Alarm Red`, 호버 시 미세한 깜빡임 애니메이션 적용. 크기는 모바일/데스크톱 모두 최대 주목도를 확보하도록 설정.
        *   `Secondary Button`: [무료 진단 보고서 다운로드 (정보성)]
        *   *스펙:* 배경색 투명, 테두리 `Accent Blue`.

| **릴스 / 쇼츠** | 9:16 | 빠른 문제 제기, 트래픽 유도 (최초 접점). | **[Alarm Red 타이틀]** + 핵심 수치(숫자) 강조 + 화면 상단/하단에 고정된 **진단 도구 링크 CTA**. (가장 자극적인 단일 데이터 포인트만 사용) |
