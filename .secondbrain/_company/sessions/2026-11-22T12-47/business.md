### 📈 핵심 KPI 정의 및 Data Spec 설계 (CEO 지시 이행)

저희가 추구해야 할 '최소 실행 가능 KPI(MVKPI)'는 단순 리드 수(Lead Count)가 아니라, **'고관여 질문자 전환율(Qualified Inquiry Conversion Rate, QICR)'**과 **'평균 잠재 고객 가치(Average Lead Value, ALV)'**입니다.

**1. 최소 실행 가능 KPI (MVKPI)**
| 지표 | 정의 | 측정 목표 | 성공 기준 수치화 (가설) |
| :--- | :--- | :--- | :--- |
| **QICR (핵심)** | 리드(Lead ID 생성자) 중, '전문 상담 요청'이라는 구체적인 의도를 가진 사람의 비율. (최종 CTA 클릭률보다 높은 고품질 지표) | 콘텐츠가 단순 관심 유발을 넘어, *문제 해결에 대한 재정적 니즈*를 자극했는가? | 목표: 5% 이상 유지 $\rightarrow$ (현재 기준 대비 최소 10% 증가 필요) |
| **ALV** | 리드 ID당 예상되는 최대 상담 금액 범위. 이는 콘텐츠/CTA 설계 시 가격 설정을 결정하는 기초 데이터임. | 유입된 잠재 고객의 문제 심각도 및 가용 자금력을 추정했는가? | 목표: 최소 50만원 이상 (최소한의 투자액 확보) |
| **Defect ID 점수** | 리드가 어떤 유형의 '시스템 오류'에 가장 높은 관심을 보였는지 측정하는 내부 점수. (A, B, C 중점) | 잠재 고객을 세분화하고, 후속 콘텐츠/판매 전략(Upsell)을 결정할 근거를 확보했는가? | 필수: A > B > C 순서로 점수가 기록되어야 함. |

**2. 리드 생성 데이터 스펙 (Data Spec for Lead ID)**
리드가 생성될 때마다 다음의 구조화된 데이터를 DB에 기록해야 합니다. 이 필드는 단순 정보 수집을 넘어, **'잠재적 재정 손실 규모 예측 및 후속 맞춤 전략 설계'**를 위한 핵심 인풋입니다.

| 필드명 | 데이터 타입 | 설명 (수치/범주) | 사용 목적 (비즈니스 활용) |
| :--- | :--- | :--- | :--- |
| `Lead_ID` | Unique String | 시스템 고유 식별자 | 추적 및 로깅 |
| `Acquisition_Source` | Enum (UTM 기반) | 유입 채널 (YouTube, Instagram, Naver 등) | KPI: 효율적인 콘텐츠 배포처 파악 |
| `Content_Topic` | String | 리드가 관심을 보인 구체적 Defect ID 주제 (예: LDL 콜레스테롤, 퇴직금 투자 오류) | 콘텐츠 캘린더 방향성 결정 및 소재 반복 활용 방지 |
| **`Defect_ID_Score`** | Float (0.1~5.0) | 리드의 문제 인지 깊이와 심각도를 점수화. (예: '인지 저하'에 높은 점수) | **가장 중요.** 상담 시 우선순위 설정 및 긴급성 강조 근거 마련. |
| `Financial_Impact_Range` | String/Enum | 예상되는 재정적 피해 규모 범위. (①경미~②중간③심각) | ALV 측정의 핵심 지표. 고점(③) 리드에게 최우선 영업 자원 투입. |
| `Consult_CTA_Click` | Boolean | 상담 CTA 버튼을 클릭했는지 여부 (진성도 판단). | QICR 계산 및 성공/실패 Funnel 검증. |

### 🎯 다음 단일 작업 결정: 수익화 모델 최적화 시뮬레이션

**👉 실행 계획:**
1.  설정된 MVKPI와 Data Spec을 바탕으로, 리드 ID의 세분화된 가치(①경미/②중간/③심각)에 따른 **3단계 가격 구조 (Tiered Pricing)**를 설계합니다.
