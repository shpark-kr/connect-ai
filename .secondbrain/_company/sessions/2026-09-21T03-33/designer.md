## 📜 [프로젝트명: 온현] 공식 출처 안내 박스 (Citation Box) 디자인 시스템 브리프

### 💡 1. 핵심 컨셉 및 목표
*   **컨셉:** '배경을 지지하는 신뢰의 아카이브(The Supporting Archive of Trust)'
*   **목표:** 공적 데이터를 시각적으로 압도감 있게 제시하되, 정보 자체가 메인이 되도록 디자인한다. (정보 > 디자인)
*   **톤앤매너:** 전문성, 권위, 차분한 경고.
*   **활용 원칙:** 콘텐츠의 *가장 중요한 사실(핵심 통계)*이 제시된 직후에 배치하여 독자의 신뢰도를 즉각적으로 끌어올린다.

### 🎨 2. 컬러 및 타이포그래피 가이드라인 (Palette & Type)
| 요소 | 색상 코드 (HEX) | 용도 및 설명 |
| :--- | :--- | :--- |
| **메인 배경** | `#FFFFFF` / `#F5F7FA` | 기본 텍스트 영역. 깔끔한 대비 유지. |
| **강조색/헤더** | `#1A237E` (Dark Navy) | 섹션 제목, 구분선, 박스 외곽선, 중요 데이터 강조. 전문성 부여. |
| **권위/하이라이트** | `#FFC107` (Muted Gold) | 핵심 수치(Key Figure), CTA 버튼의 보조 색상, 경고 표시 아이콘. 시선을 집중시키는 포인트. |
| **보조 텍스트** | `#607D8B` (Slate Gray) | 출처 이름, 날짜, 저작권 정보 등 부차적인 안내 문구. 가독성 확보. |
| **타이포** | Noto Sans KR / Pretendard | 시스템 전체 통일성을 위해 사용한다. 제목은 굵게(Bold), 본문은 보통(Regular)으로 구분하여 권위를 부여한다. |

### 🧱 3. 모듈화된 컴포넌트 정의 (Modular Components)
API 자동 삽입을 염두에 두고, 데이터의 성격별로 세 가지 필수 모듈을 분리합니다.

#### A. [Module Type: `citation_text`] - 일반 출처 명시 (텍스트 기반 자료)
*   **용도:** 학술 논문, 법률 근거, 뉴스 기사 등 텍스트 정보의 공신력을 확보할 때 사용.
*   **디자인 특징:** 깔끔한 인용 블록(Blockquote) 형태를 유지하되, 경계가 명확해야 함.
*   **구조 (CSS/HTML):**
    ```html
    <div class="citation-box citation_text">
        <!-- 좌측: 출처 아이콘 -->
        <span class="citation-icon">📚</span> 
        <!-- 중앙: 핵심 문구 및 간략 설명 (굵은 글씨 강조) -->
        <p class="citation-content">"핵심 내용을 인용한 공적 근거가 있습니다."</p>
        <!-- 우측 하단: 상세 출처 정보 -->
        <div class="citation-detail">
            <span class="source-name">[출처명]</span> | 
            <span class="date">[발행 연도/월]</span> | 
            <a href="[URL]" class="read-more-link">자세히 보기</a>
        </div>
    </div>
    ```

#### B. [Module Type: `citation_data`] - 데이터 기반 출처 명시 (차트/통계 자료) **(가장 중요)**
*   **용도:** 그래프, 통계 수치(예: '비급여 지출액'), 비교 데이터를 근거로 제시할 때 사용. 시각적 충격과 권위를 동시에 전달해야 함.
*   **디자인 특징:** 데이터의 출처가 *데이터 자체의 일부*처럼 보이도록 디자인한다. Gold 톤을 활용하여 "신뢰도 높은 수치"임을 강조.
*   **구조 (CSS/HTML):**
    ```html
    <div class="citation-box citation_data">
        <!-- 메인 헤더: 데이터 근거 출처임을 명확히 안내 -->
        <h4 class="data-source-header">📈 자료 출처: [통계청/복지로] (YYYY년 기준)</h4>
        <!-- 핵심 시각화 영역을 감싸는 배경 박스 (옅은 회색 또는 다크 네이비의 10% 투명도) -->
        <div class="data-visual-container">
            <!-- 여기에 코다리가 생성하는 SVG 차트가 삽입됨. -->
            [SVG Chart Placeholder]
        </div>
        <!-- 하단: 데이터 원본 접근 링크 (강한 CTA 성격) -->
        <p class="source-attribution">✅ **원문 확인**: <a href="[API_LINK]" target="_blank" style="color:#FFC107;">공식 사이트에서 실시간 데이터 조회</a></p>
    </div>
    ```

#### C. [Module Type: `citation_disclaimer`] - 법적 고지/Disclaimer (최하단 공통 모듈)
*   **용도:** 모든 콘텐츠의 맨 하단에 배치하여, 정보가 절대적인 진실이 아님을 명시함으로써 오히려 신뢰도를 높이는 역할(겸손한 권위).
*   **디자인 특징:** 가장 작고 미니멀하게 디자인하며, Slate Gray 톤을 사용하여 메인 콘텐츠와 분리한다.
*   **구조 (CSS/HTML):**
    ```html
    <div class="citation-box citation_disclaimer">
        <p class="disclaimer-text">※ 본 자료는 공적 정보를 기반으로 재구성된 참고용 정보이며, 최종 결정은 반드시 해당 기관의 공식 가이드라인을 통해 확인하시기 바랍니다. (최종 업데이트: 2026년 MM월)</p>
    </div>
    ```

### 🛠️ 4. 개발자 구현 상세 브리프 (For Codari)

1.  **CSS Pseudo-Elements 필수:** 모든 모듈은 `box-shadow`와 `:before`/`:after`를 활용하여, 단순히 박스로 감싸는 것이 아니라 *깊이감*을 가진 카드 형태처럼 보이게 설계합니다.
2.  **데이터 레이블 우선순위:** `citation_data` 모듈의 경우, SVG 차트가 삽입되는 위치 주변에 **"기준 데이터: A"**, **"비교 데이터: B (Gap)"** 등의 텍스트 라벨을 반드시 추가하여 시각적 연결성을 확보해야 합니다.
3.  **API 구조 연동:** API 호출 시, 콘텐츠 타입(`text`, `data`, `disclaimer`)과 함께 출처의 메타데이터(Source Name, URL, Date)를 JSON으로 전송받아 적절한 모듈에 매핑하는 로직이 필수입니다.
