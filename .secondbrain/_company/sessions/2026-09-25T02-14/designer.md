## 📊 온현 표준화 시각 자료 세트 (Visual System Set)

### 🖼️ 템플릿 1: 충격적 통계 비교 그래프 모듈 (The Loss Comparator Graph)
**[목표]**: 복잡한 공공 데이터를 'A 그룹(현재/오해)'과 'B 그룹(진실/손실액)'로 명확하게 대비시키며, 시청자에게 정량화된 재정적 충격파를 전달합니다. (가장 중요한 에셋)
**[스타일]**: 다크 모드 배경의 미니멀리즘, 3D 느낌의 데이터 깊이감 부여.

| 항목 | 세부 디자인 스펙 | 기술 명세/코드 예시 | 비고 및 사용법 |
| :--- | :--- | :--- | :--- |
| **배경** | 무광택 다크 네이비 계열 (#1A233B). 좌우에 미세한 그리드 패턴(Grid Pattern)을 넣어 데이터 신뢰도를 높임. | Background: `#1A233B` <br> Grid Overlay: `opacity: 0.05; stroke-dasharray: 5px;` | 전체 모듈 배경으로 사용. |
| **비교 그래프** | 막대형 차트(Bar Chart)가 가장 효과적입니다. 손실액을 나타내는 막대는 '위험한' 느낌의 색상으로 강조합니다. | **A 그룹 (오해/현재)**: 은은한 청록색 (#4DD0E1). <br> **B 그룹 (손실액/경고)**: 경고를 상징하는 강렬한 오렌지-레드 계열 (#FF7043). | 막대 높이 차이를 극대화하여 재정적 손실을 시각적으로 폭발시키는 것이 핵심. 그래프 위에 '⚠️ 예상 손실액' 텍스트 레이블 필수 삽입. |
| **데이터 강조** | 가장 중요한 수치(Loss Amount)는 글래스모피즘 효과를 적용한 투명한 박스 안에 배치하여 주목도를 최상으로 높입니다. | `box-shadow: 0 8px 32px 0 rgba(31, 38, 15, 0.37);` (글래스모피즘) <br> Text Color: `#FFCDD2` (골드 빛 하이라이트) | 그래프의 결론이자 핵심 주장 위치에 배치합니다. 애니메이션 시 이 박스가 가장 먼저 나타나야 합니다. |

### 🔗 템플릿 2: 전문가 진단 Funnel CTA UI 컴포넌트 세트
**[목표]**: 콘텐츠 소비가 끝난 직후, 시청자가 '이 문제를 혼자 해결할 수 없다'는 결론에 도달하게 하고, 다음 행동(클릭)으로 유도하는 최종 장치입니다.
**[스타일]**: 명확한 정보 계층 구조와 즉각적인 클릭 욕구를 자극하는 고대비 디자인.

| 항목 | 세부 디자인 스펙 | 기술 명세/코드 예시 | 비고 및 사용법 |
| :--- | :--- | :--- | :--- |
| **메인 배경** | 연한 골드-베이지 계열의 그라데이션 (#FFF8E1 → #FFEB3B)을 사용하여 '희망'과 '해결책'이라는 긍정적 감정을 부여합니다. (다크 모드 콘텐츠와 대비됨) | Gradient: `linear-gradient(to bottom, #FFF8E1, #FFE082)` <br> 배경 패턴: 미세한 육각형 격자무늬 (`opacity: 0.1`)를 넣어 전문적인 느낌 유지. | 영상/블로그의 마지막 15% 영역에 배치합니다. |
| **핵심 메시지 블록** | "당신의 상황은 전문가 진단이 필요합니다."와 같은 권위적 문구를 중앙 상단에 배치합니다. 폰트는 세리프 계열을 사용하여 전통적인 신뢰도를 강조합니다. | Headline Font: `serif` (예: Noto Serif KR) <br> Color: `#37474F` (진한 청회색) | 이 블록은 콘텐츠 전체의 결론이 되어야 합니다. |
| **CTA 버튼** | '무료 진단 받기' 또는 '상담 신청하기'와 같은 명확한 Call to Action을 담습니다. 가장 눈에 띄는 색상을 사용합니다. | Background: `#D32F2F` (강렬하고 신뢰감 있는 빨간색) <br> Text Color: `white;` <br> Effect: 커서 오버 시 살짝 밝아지는 `:hover` 효과 필수. | **이 버튼은 반드시 앵커 링크(Funnel Link)**로 연결되어야 합니다. 가장 크고, 중앙에 배치합니다. (모바일 최적화 고려) |

### ✨ 템플릿 3: 핵심 개념 아이콘 세트 (The Core Concept Iconography)
**[목표]**: 연금, 의료, 법률 등 복잡한 개념을 하나의 통일된 비주얼 언어로 즉각적으로 이해시킵니다. (모션 그래픽 최적화).
**[스타일]**: 단색(Monotone), 라인 아트 스타일 (Line Art SVG). 두께가 일정하고 간결해야 합니다.

| 개념 카테고리 | 아이콘 명칭 | 설명 및 시각화 요소 | 사용 목적 |
| :--- | :--- | :--- | :--- |
| **💰 재정/연금** | 연금 수령 (Pension) | 돈이 쌓여있는 저축 통장 모양에 화살표가 위로 올라가는 모션. | 국민연금, 은퇴 자산 등 '돈'과 관련된 개념 설명 시 사용. |
| **🏥 의료/복지** | 건강 진단 (Health Checkup) | 심전도 그래프(EKG) 라인과 하트 모양이 결합된 형태. 또는 방패 모양 안에 십자가가 들어감. | 장기요양, 복지 지원 등 '건강' 관련 데이터를 다룰 때 사용. |
| **📜 법률/제도** | 문서 및 검토 (Document & Audit) | 두꺼운 책이나 서류철 위에 커다란 체크 마크(✓)가 찍히는 형태. | 법적 근거, 공공기관 제도, 자격 조건 등 '규정' 관련 내용을 설명할 때 사용. |
| **🔄 비교/변화** | 시간의 흐름 (Time Flow) | 왼쪽에서 오른쪽으로 화살표와 함께 시간이 흐르는 듯한 곡선 형태. | Before/After 비교나 시기별 변화를 보여줄 때 사용합니다. |

본 가이드는 모든 영상(롱폼/숏폼)과 블로그 콘텐츠에 걸쳐 통일된 '전문가적 신뢰도'와 '재정적 경고감'을 동시에 부여하는 것을 목표로 합니다. 디자인은 복잡한 데이터를 시각적으로 단순화하고, Funnel CTA를 최대한 자연스럽게 유도하도록 설계합니다.

## 2️⃣ Funnel CTA UI 컴포넌트 세트

*   **핵심 스펙**: 골드-베이지 그라데이션 배경, 세리프체 헤드라인. 핵심 버튼은 고대비 빨간색 `#D32F2F` 사용.
*   **기술 파일**: `visual_assets/cta_template_v1.html` (재사용 가능한 HTML 템플릿)

## 3️⃣ Core Concept Iconography Set

*   **핵심 스펙**: 라인 아트 SVG 스타일, 단색(White/Gold Accent). 아이콘은 `💰`, `🏥`, `📜` 카테고리별로 3가지 변형 버전 제공.
