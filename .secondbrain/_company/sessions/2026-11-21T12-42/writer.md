## 🚨 MiniFunnel 유도형 숏폼 카피 세트 (총 3가지)
**(영상 길이: 20~45초 권장 / 톤앤매너: 공학적, 경고 메시지)**

### 🧬 세트 1: 에너지 시스템 오류 (미토콘드리아/ATP 저하)
**[주요 타깃]** 만성 피로를 느끼는 직장인, 활력 저하가 고민인 40대.
**[Defect ID 콘셉트]** 세포 단위의 전력 공급 불안정 (Power Grid Failure).

| 구성 요소 | 내용 (스크립트/캡션) | 비고 (시각적 연출 가이드) |
| :--- | :--- | :--- |
| **① 위기감 Hook (3초 이내)** | "혹시, 에너지가 바닥나는 게 '노화' 탓이라고 생각하시나요? 그건 시스템 오류입니다." | 화면에 빨간 경고등(`[ERROR: ATP Level Critical]`)과 함께 급격히 떨어지는 그래프를 오버레이. 강한 전자음/경고음을 사용. |
| **② 과학적 근거 본문 카피** | 우리의 피로는 단순히 잠이 부족해서 오는 게 아닙니다. 세포의 발전소인 미토콘드리아가 ATP(에너지)를 효율적으로 생산하지 못하고 있다는 명확한 시스템 결함, 즉 '미토코지오스' 패턴이 포착된 것입니다. 나잇살보다 더 무서운 건, 에너지 근본 회로의 과부하입니다. | 현미경 이미지나 복잡한 에너지 전송 과정을 다이어그램으로 보여주며 권위성을 높임. 전문 용어(ATP, 미토콘드리아)를 자막 처리하여 신뢰도 확보. |
| **③ 긴급 CTA 문구** | 막연히 영양제를 드시지 마십시오. 당신의 세포가 보내는 **'에너지 시스템 오류 코드(Defect ID)'**를 진단해야 합니다. 지금, 무료 테스트 후 전문 리포트를 확인하세요. (→ [진단 보고서 페이지 링크]) | 화면 중앙에 'Diagnostic Report' 버튼을 크고 빨간색으로 배치하고, 타이머 카운트다운 효과를 주어 긴급성 강조. |

### 💪 세트 2: 근육 합성 시스템 마비 (Sarcopenia/근손실)
**[주요 타깃]** 운동은 하지만 효과가 미미하다고 느끼는 중장년층, 관절 건강이 염려되는 사용자.
**[Defect ID 콘셉트]** 신호 전달 체계의 오작동 (Signal Transmission Failure).

| 구성 요소 | 내용 (스크립트/캡션) | 비고 (시각적 연출 가이드) |
| :--- | :--- | :--- |
| **① 위기감 Hook (3초 이내)** | "단순히 근육이 빠진 게 아닙니다. 몸의 '근육 합성 스위치'가 꺼지고 있습니다." | 거울을 보는 듯한 장면에서, 사용자의 근력계 수치가 정상 범위보다 낮은 그래프를 보여주며 충격 유발. |
| **② 과학적 근거 본문 카피** | 40대 이후 급감하는 것은 단순히 운동 부족 때문이 아닙니다. 우리 몸은 근육 합성을 위한 핵심 신호(mTOR 등)에 오류가 발생해, 마치 시스템 명령 자체가 먹통이 된 것과 같습니다. 이 '근합성 신호 마비'를 방치하면 만성적인 활동 능력 저하로 이어집니다. | 인체 내부의 복잡한 단백질 합성 경로 다이어그램을 제시하고, 특정 단계에 'DEFECT' 태그를 붙여 오류처럼 보이게 함. |
| **③ 긴급 CTA 문구** | 지금 본인의 근육 시스템이 어떤 코드에서 에러가 났는지 정확히 아십니까? 막연한 운동 계획은 위험합니다. 전문적인 **근합성 Defect ID 진단 보고서**로 진짜 원인을 찾아내세요! (→ [진단 보고서 페이지 링크]) | '시스템 복구 필요'와 같은 문구를 크게 배치하고, 진단 리포트가 마치 해킹된 시스템의 비밀 파일처럼 보이게 연출. |

### 🛡️ 세트 3: 만성 염증 및 대사 불균형 (Silent System Failure)
**[주요 타깃]** 수많은 영양제와 증상만으로 혼란을 느끼는 일반 중장년층, 전반적인 컨디션 관리가 필요한 사용자.
**[Defect ID 콘셉트]** 내부 환경의 만성적 독소 축적 (Internal Pollution/Inflammation).

| 구성 요소 | 내용 (스크립트/캡션) | 비고 (시각적 연출 가이드) |
| :--- | :--- | :--- |
| **① 위기감 Hook (3초 이내)** | "몸이 아프다고 느끼는 근본적인 이유가 '염증' 때문이라는 걸 알고 계십니까? 이건 몸의 경고 신호입니다." | 어둡고 붉은색 톤으로 배경을 설정하고, 내부 장기에 마치 녹슨 듯한 금속 질감의 오류(Rust/Corrosion)를 입힌 시각 자료 사용. |
| **② 과학적 근거 본문 카피** | 우리가 흔히 아는 피로와 관절 통증은 사실 몸속에서 진행되는 만성 염증 반응이 원인일 때가 많습니다. 이 '만성 저등급 염증'은 시스템 전체의 밸런스를 무너뜨리는 가장 교활한 Defect ID입니다. 혈액 검사 수치만으로는 알 수 없는, 장기적이고 복합적인 오류를 잡아내야 합니다. | 면역계와 염증 반응을 보여주는 과학 다이어그램을 사용하며, 'C-Reactive Protein' 같은 전문 용어를 언급하여 권위를 확보. |
| **③ 긴급 CTA 문구** | 당신의 몸속에 숨겨진 '만성 시스템 오류 코드(Defect ID)'를 발견할 시간입니다. 종합적인 밸런스 진단이 필요합니다. 지금 바로 **전신 Defect ID 보고서**로 위험도를 체크하세요! (→ [진단 보고서 페이지 링크]) | '종합 시스템 스캔 시작' 버튼을 만들고, 클릭하면 복잡하고 많은 항목의 체크리스트가 나오는 느낌으로 연출하여 정보의 방대함을 강조. |
