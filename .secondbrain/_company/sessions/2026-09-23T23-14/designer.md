### 1. 시스템 플로우 및 인터랙션 순서도 (UX Sequence Diagram)

사용자가 진단 위젯에 접근하여 결과를 확인하기까지의 모든 단계별 동작 정의입니다.

| Step | 상태 (State) | 사용자 액션 | 시스템 반응 (Visual Feedback) | 개발 필수 요소 |
| :---: | :---: | :---: | :---: | :---: |
| **1** | **초기 진입 (Initial)** | 위젯 페이지 로드 | 1. 경고 헤더(`앰버 골드`): "당신의 재정적 사각지대를 확인하세요." 2. 핵심 Pain Point 요약 카드(3개) 제시. 3. 입력 필드 활성화 대기. | **애니메이션:** 데이터가 '떠오르는' 느낌의 Fade-in 효과 (0.5s). |
| **2** | **데이터 로딩 (Loading)** | N/A | 1. 전체 화면을 덮는 스켈레톤 UI(Skeleton Screen) 표시. 2. 스켈레톤 애니메이션은 콘텐츠 영역 위주로, '지연 시간'에 대한 불안감을 줄이도록 설계. | **기술:** 지수 백오프(Exponential Backoff) 로직 작동 중임을 시각적으로 감추고 부드러운 UI만 제공해야 함. (최대 3초). |
| **3** | **입력 및 유효성 검사 (Input/Validation)** | 사용자가 값을 입력하거나 버튼 클릭. | A. 값이 누락된 경우: 해당 필드 주변에 `빨간색` 경계선과 함께 "필수 항목입니다." 메시지 표시. B. 형식이 잘못된 경우: 구체적인 오류(예: '연도'는 4자리 숫자여야 합니다.)와 애니메이션 강조. | **UX:** 사용자 입력 즉시 피드백 (On-change validation) 필수. |
| **4** | **진단 처리 중 (Processing)** | 버튼 클릭 후, 데이터 전송 직전. | 로딩 스켈레톤으로 전환되거나, 또는 '분석 중...' 팝업과 함께 *작은 시계 아이콘* 애니메이션만 표시하여 대기 시간을 인지시킴. | **UX:** 긴 처리 시간(>3초) 예상 시, 사용자에게 "정확한 분석을 위해 잠시만 기다려주세요." 메시지를 명확히 제공해야 함. |
| **5** | **결과 제시 (Success/Result)** | API 호출 성공 및 데이터 로드 완료. | 1. 가장 심각한 문제점(Worst Case Gap)이 *앰버 골드*로 강조되어 최상단에 표시됨. 2. '진단 결과 요약' 섹션 활성화. 3. **Funnel CTA 버튼**(`스카이 민트`): "나의 상세 진단 보고서 다운로드"를 가장 크게 배치. | **애니메이션:** 결과가 펼쳐지는 듯한(Reveal) 효과와 함께, 'Gap 금액/수치'에 초점을 맞추는 시각적 강조 필요. |
| **6** | **시스템 오류 (Error)** | API 호출 실패 또는 네트워크 문제 발생. | **[Critical]** `빨간색` 배경의 경고 모달 팝업 표시. 사용자에게 구체적인 원인(예: 서버 연결 불가)과 해결책('잠시 후 다시 시도')을 제시하며, 기술적 오류 메시지는 절대 노출하지 않아야 함. | **기술:** 재시도 버튼(`Retry`) 필수 배치. 백그라운드에서 지수 백오프 로직이 작동하고 있음을 내부적으로 기록해야 함. |

### 2. 개발자를 위한 UI/UX 컴포넌트 체크리스트 (Component Library)

개발자가 반드시 구현해야 하는 5가지 핵심 상태별 디자인 사양입니다. 모든 컴포넌트는 모바일-퍼스트(Mobile-First), 터치 영역 최소 48px을 준수합니다.

#### A. [State: Loading] 스켈레톤 UI 명세
*   **목표:** 로딩 시간을 지루함이 아닌 '진행 중인 전문 분석'으로 인식하게 함.
*   **디자인:** 실제 콘텐츠와 유사한 형태(카드, 텍스트 블록)를 유지하되, 색상은 배경과 분리되는 회색 계열(`#E0E0E0`)을 사용합니다.
*   **애니메이션:** 부드러운 좌우/상하로 이동하는 'Shimmer' 효과를 적용하여 정적인 느낌을 제거합니다.

#### B. [State: Error] 에러 모달 (Critical) 명세
*   **트리거:** API 호출 실패, 네트워크 연결 끊김 등 시스템 오류 발생 시.
*   **구조:** 전체 화면을 덮는 오버레이 모달(Overlay Modal).
    1.  **아이콘:** 심각도를 나타내는 `빨간색` 삼각형 경고 아이콘.
    2.  **제목 (H2):** "🚨 분석에 실패했습니다." (강한 위협감 조성)
    3.  **본문:** "현재 서버 연결 상태를 확인해주세요. 잠시 후 다시 시도하시면 정확한 진단 결과를 받아보실 수 있습니다." (쉬운 설명과 안심 유도)
    4.  **CTA 버튼 1:** **[다시 시도]** (`#74D9D5` - 스카이 민트): 클릭 시 지수 백오프 로직을 재개하고 API를 호출합니다.
    5.  **CTA 버튼 2 (Optional):** [고객센터 문의]

#### C. [State: Empty] 데이터 없음 상태 명세
*   **트리거:** 사용자가 특정 조건에 맞는 데이터를 입력하지 않았거나, 위젯이 활성화되었으나 진단할 근거 데이터가 없을 때.
*   **디자인:** 정보의 부재를 '위험 신호'로 전환해야 합니다. 단순한 텍스트는 금물.
    1.  **아이콘:** 물음표 모양과 함께 `앰버 골드`색으로 강조된 경고 아이콘.
    2.  **제목 (H2):** "⚠️ 진단할 데이터가 충분하지 않습니다."
    3.  **본문:** "더 정확하고 깊이 있는 재정 분석을 위해, [A 항목]과 [B 항목]에 대한 최소한의 정보를 추가해 주세요." (사용자 행동 유도)

#### D. [State: Success] 결과 강조 및 CTA Funnel 명세
*   **목표:** 사용자의 불안감을 최대치로 끌어올린 후, 반드시 다운로드/문의(CTA) 버튼을 누르게 함.
*   **시각적 계층 구조 (Visual Hierarchy):**
    1.  **(최우선)** **핵심 Gap 수치**: 가장 위험한 공백 금액/수치를 `초대형 폰트`와 배경색(`앰버 골드`)으로 처리합니다. (예: "🚨 예상 손실액: 최소 N억 원")
    2.  **중요 정보:** 진단 근거가 되는 핵심 포인트 3가지 (카드 형태).
    3.  **(최종)** **CTA 버튼**: 페이지 하단을 가로지르는 Sticky Footer 형태로 배치하며, 크기 및 색상(`스카이 민트`)을 최대로 강조합니다.
