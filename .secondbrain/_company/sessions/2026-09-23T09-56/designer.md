# 🎨 Gap Contrast Widget 디자인 시스템 모듈 (V1.0)

## 📌 개요 및 목표
본 모듈은 공적 지원 금액(A)과 산출된 재정적 격차(Gap, B)를 비교하는 Mini-Assessment 페이지의 핵심 컴포넌트입니다. **목표는 '불안감'을 유발하고, 이 불안감을 해소하기 위한 서비스 이용(CTA 클릭)으로 전환시키는 것입니다.** 모든 디자인 요소는 전문성과 경고성을 동시에 지녀야 합니다.

## 🌈 1. 컬러 팔레트 정의 (Color Palette Definition)
모든 색상 코드는 **웹 접근성 AA 레벨 이상**을 충족하도록 설계되었습니다.

| 역할 | 이름 (Concept) | HEX 코드 | 사용처 및 주의사항 |
| :--- | :--- | :--- | :--- |
| **Primary** | 온현 네이비 (신뢰) | `#0A1931` | 배경, 헤더, 텍스트 기본색. 전문성 확보. |
| **Secondary** | 골드 포인트 (기회/강조) | `#FFC72C` | 성공 메시지, CTA 버튼의 비활성화 상태 강조. |
| **Neutral-A** | 안전 지원금 (공적 자금 A) | `#10B981` | 공적지원액(Input A). 안정감과 희망을 주는 녹색 계열. |
| **Critical-R** | 재정적 Gap (위협/손실 B) | `#EF4444` | **Gap 금액 자체.** 가장 강한 경고 효과를 주어야 함. 무조건 눈에 띄게, '위험'을 상징합니다. |
| **Background** | 메인 배경 | `#F9FAFB` | 콘텐츠 영역의 기본 배경색. |
| **Text-Primary** | 본문 텍스트 | `#1F2937` | 가독성을 최우선으로 하는 진한 회색 계열. |

### 🎨 경고 컬러 상세 (Critical Red)
*   **HEX:** `#EF4444`
*   **RGB:** (239, 68, 68)
*   **용도:** Gap 금액의 숫자 및 바 그래프의 '손실 부분'에만 사용.
*   **사용 지침:** 이 색상은 다른 곳에서는 절대 사용하지 않으며, 시각적 대비(Contrast)를 극대화하여 **패닉 버튼 효과**를 유발하는 것이 목적입니다.

## 📐 2. 아이콘 및 비주얼 에셋 가이드라인 (Icons & Visual Assets)
개발자가 즉시 사용할 수 있는 컴포넌트별 상태 아이콘 세트를 정의합니다.

| Icon Set | 이름/상태 | 설명 | 사용 예시 (Context) | 크기 권장값 |
| :--- | :--- | :--- | :--- | :--- |
| ⚠️ | **경고 삼각형** | Gap 계산 전, 사용자가 입력을 망설일 때. | "Gap 금액이 발생할 수 있습니다." 안내문 옆. | 24px |
| ✅ | **완료 체크** | 공적 지원금(A)의 적정성 확인 완료 시. | A 값 표시 근처에 배치하여 신뢰도 확보. | 20px |
| 🚨 | **위험 경고 (Critical)** | Gap 금액이 최종 산출되어 화면에 나타날 때. | Gap 금액 숫자 바로 옆 또는 하단 바 그래프 시작점. | 32px (애니메이션 필수) |
| 🔄 | **로딩 스피너** | API 호출 및 계산 진행 중. | 로딩 상태에서 사용자 이탈 방지. | 표준 Material Design Spinner |

## ✨ 3. 애니메이션 키프레임 가이드라인 (Animation Keyframes & Timing)
Gap Contrast Widget의 전환율은 타이밍에 달려 있습니다. 다음 세 가지 핵심 단계의 애니메이션을 반드시 적용해야 합니다.

### A. [Transition: Loading → Calculation] - 기대감 고조
*   **상태:** 사용자가 '계산하기' 버튼 클릭 직후, 데이터 로딩 중.
*   **애니메이션:** 전체 위젯이 부드럽게 페이드 인(Fade-In) 하면서, 계산 결과가 나타날 위치에 미세한 **진동 효과 (Subtle Bounce)**를 줍니다.
*   **타이밍:** 시작 시점부터 0.3초 동안 진행.

### B. [Key Moment: Gap Reveal] - 충격 극대화 (가장 중요)
*   **상태:** 계산 결과(Gap 금액 B)가 API 응답을 받아 화면에 나타나는 순간.
*   **애니메이션:**
    1.  숫자가 0부터 최종 값까지 **빠르게 카운트업 (Count-Up Animation)** 해야 합니다. (예: $0 \rightarrow \$5,234,567$)
    2.  카운트업이 완료되는 순간, 해당 숫자 박스 전체가 `Critical-R` 배경과 함께 **강한 '팝' 효과(Pop/Scale Up & Down)**를 주며 시각적 충격을 줍니다.
*   **타이밍:** 카운트 시작: 0.5초 / 종료 및 Pop 완료: 1.2초

### C. [Transition: Comparison Emphasis] - 대비 강조
*   **상태:** Gap 금액(B)과 공적 지원금(A)의 수치가 나란히 비교될 때.
*   **애니메이션:** 두 값의 영역을 나누는 **경계선(Divider Line)**이 왼쪽(공적지원액 A)에서 오른쪽(Gap B)으로 부드럽게 슬라이딩 되며 나타나야 합니다. 이 슬라이딩 과정 자체가 '손실 구간'임을 인지시켜야 합니다.
*   **타이밍:** 0.8초에 걸쳐 진행하며, 슬라이드가 끝나는 지점이 가장 시각적으로 강해야 함.
