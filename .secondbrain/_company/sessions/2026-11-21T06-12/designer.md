## 🎯 1. 프로젝트 목표 및 컨셉 정의
**페이지 목적:** 사용자에게 '자가진단(Diagnosis)'을 통해 자신의 문제가 단순한 증상이 아닌, 전문적인 관리가 필요한 '시스템 오류(System Failure)'임을 인지시키고, MiniFunnel의 진단 보고서를 통한 솔루션 구매를 유도한다.
**핵심 컨셉:** **'권위적 위기감 조성 (Authoritative Crisis Generation)'**
**톤앤매너:** 정부 공식 프로토콜 또는 전문 연구소의 '최종 경고/진단 리포트' 느낌을 극대화.
**주요 컬러 시스템:**
*   **Deep Navy (#0A1931):** 기본 배경색 및 권위적 텍스트 (신뢰, 전문성).
*   **Crisis Red (#C72C3E):** 경고 메시지, 위험 지표, 중요 CTA 버튼 배경 (위기감, 긴급함).
*   **Electric Blue/Gold Accent (#0096FF / #FFD700):** 강조 데이터 포인트, 패치 완료 상태, 성공적인 복구 프로토콜 제시 시 사용 (해결책, 희망).

## 🔄 2. 사용자 경험 플로우 정의 (State Machine)
이 페이지는 단순한 '읽기'가 아닌, 세 단계의 **감정적/정보적 상태 전이(Emotional/Informational State Transition)**를 거쳐야 합니다.

| Step | 명칭 | 목적 | 감성 변화 (UX Goal) | 핵심 UI 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **S1** | **진단 및 위기 경고 (Diagnosis & Alert)** | 사용자의 문제(Pain Point)를 공학적 오류 코드(Defect ID)로 정의하여 충격과 불안감을 극대화한다. | *궁금증 → 불안감/공포* | 시스템 알림창, Defect Code 블록, 원인 그래프 |
| **S2** | **필요성 증명 (Necessity Proof)** | 자가진단만으로는 부족하며, '전문적인 개입'이 필수적임을 객관적 데이터와 공학적 근거로 설득한다. (AOV 최적화 포인트) | *불안감 → 위기 인정/절박함* | 결손 분석 보고서(Missing Data Report), 패치 필요성 시각화, 전문가 코멘트 박스 |
| **S3** | **해결책 제시 및 행동 요청 (Solution & Action)** | 우리의 상품/솔루션이 유일한 '복구 프로토콜'임을 확신시키고 즉각적인 액션을 요청한다. | *절박함 → 안도감/행동 의지* | MiniFunnel 핵심 CTA(버튼), 복구 로드맵, 보증 시스템 표시 |

## 🧩 3. 컴포넌트 상세 스펙 및 인터랙션 가이드 (v4.0)

### A. [S1] Defect ID 코드 블록 (Diagnosis Start)
*   **UI:** 페이지 상단에 위치하며, 마치 OS의 커널 레벨 오류 메시지처럼 디자인한다. 배경은 Deep Navy, 텍스트는 모노스페이스 폰트(예: Consolas).
*   **핵심 요소:** `[SYSTEM ALERT]`, `Defect ID: E-C403`, `ERROR CODE MESSAGE`.
*   **인터랙션 (Animation):** 페이지 로드 시, 코드가 마치 타이핑되는 것처럼 **점진적 텍스트 애니메이션(Typing Effect)**을 적용하여 긴장감을 조성한다. 경고 메시지 주변은 미세하게 깜빡이는 **글로우 효과(Flicker Glow)**를 준다.

### B. [S2] 결손 분석 보고서 (The Pivot Point)
*   **UI:** '당신의 현재 데이터는 99%의 효율을 보장하지 못합니다.' 같은 강력한 문구로 시작한다. 좌측에 Defect ID를 기반으로 한 *비교 그래프(Before/After)*를 배치하고, 우측에 그 결손을 분석하는 **'전문가 진단 코멘트'** 섹션을 둔다.
*   **핵심 요소:**
    1.  **Missing Data Visualization (SVG):** 현재 부족한 데이터 영역을 마치 깨진 패치(Patch)처럼 빨간색으로 하이라이트 처리한다.
    2.  **Required Patch Component (Interactive):** 사용자가 '더 깊은 진단 보고서 열기'를 클릭하면, 숨겨져 있던 **MiniFunnel의 핵심 가치를 담은 인터랙티브 요약 그래프(3D 파지)**가 슬라이드 인 되며 나타난다.
*   **인터랙션 (Animation):** 사용자가 'Missing Data'에 시선을 집중하는 순간, 해당 영역이 미세하게 확대되면서 **경고음 톤의 진동 효과(Subtle Vibration/Shake)**를 주어 경각심을 높인다.

### C. [S3] MiniFunnel CTA 컴포넌트 (Action Block)
*   **UI:** 페이지 최하단에 배치되며, 가장 권위적이고 강력한 디자인으로 구성되어야 한다. 배경은 Deep Navy 바탕의 크라이시스 레드 경계선 처리(Aura).
*   **핵심 요소:**
    1.  **'복구 프로토콜 적용' 배지:** 우리가 제공하는 것이 단순 상품이 아닌, 시스템을 정상화시키는 '공식 패치'임을 명시한다. (Gold/Electric Blue 사용)
    2.  **CTA 버튼 (`[SYSTEM PATCH APPLY]`):** 가장 눈에 띄는 요소.
*   **인터랙션 (Animation & Microcopy):**
    *   버튼 마우스 오버 시, 배경색이 미세하게 **Pulse(맥동)**하며 '지금 바로 복구해야 합니다'라는 긴급성을 부여한다.
    *   클릭 전: "진단 완료. 시스템 패치 적용을 시작합니다." 메시지가 짧게 노출된다.

## ✨ 4. 종합 애니메이션 및 UX 스펙 요약 (Developer Ready)

1.  **스크롤 기반 위기감 고조:** 페이지를 아래로 스크롤 할 때마다, 배경의 Deep Navy 색상에 미세한 **'디지털 노이즈(Digital Noise)'** 오버레이가 증가하는 애니메이션을 적용하여 '지금 이 정보는 실시간으로 업데이트되는 중요한 경고 보고서'라는 느낌을 유지한다.
2.  **코드 블록 강조:** 모든 Defect ID와 공학적 용어는 폰트 크기보다 **빛나는 네온 효과(Neon Glow)**를 주어 전문성과 중요도를 극대화한다.
3.  **패널 전이:** 각 단계(S1 $\rightarrow$ S2 $\rightarrow$ S3)가 전환될 때, 단순히 사라졌다 나타나지 않고, 마치 운영체제에서 **'다음 모듈 로딩 중...'** 같은 Transition 효과를 사용해야 한다.
