🎨 Designer: 작업 시작합니다.

CEO 지시사항에 따라, '공학적 위기감(Error Code)' 콘셉트를 극대화한 '긴급성 강조 CTA 오버레이' 디자인 브리프 3종을 작성했습니다. 이 오버레이는 단순히 버튼이 아니라, **시스템의 최종 경고 메시지**처럼 느껴져야 하며, 영상 시청 흐름을 끊지 않으면서도 강렬하게 행동(진단 페이지 유입)을 유발하는 것이 목표입니다.

모든 디자인은 공통적인 구조를 가지며, A/B 테스트는 메인 컬러와 폰트의 '톤'만 변경하여 진행할 수 있도록 설계되었습니다.

### 🚨 CTA 오버레이 디자인 브리프: Critical Failure Sequence (3종)

#### I. [Core Component] 시스템 경고 배너 (System Alert Banner)
*   **목표:** 영상/이미지의 하단 15~20% 영역에 고정적으로 배치되어 시각적 긴장감을 조성합니다.
*   **구조:** 3개의 수평 요소로 구성됩니다. [시스템 코드] - [긴급 메시지] - [액션 유도].

| 항목 | 상세 디자인 가이드라인 |
| :--- | :--- |
| **배경 (Video)** | 어두운 반투명 블랙 (`#0A0A0F`) 또는 배경 위에 얇은 스캔 라인(Scan Line) 효과 오버레이. |
| **폰트** | Monospace 계열의 기술적 느낌이 나는 폰트 사용 필수 (예: Space Mono, Roboto Mono). 대문자 위주로 작성하여 기계적인 느낌 극대화. |
| **공통 요소** | 모든 오버레이에 Defect ID(`E-622`)와 `[STATUS: CRITICAL]` 등의 시스템 코드를 배치하여 전문성과 긴급성을 부여합니다. |

#### II. 🔴 [A/B 테스트 Ver. 1] Critical Failure (Deep Crimson Red)
*   **톤앤매너:** 가장 심각한 오류, 즉시 중단 및 점검 필요. (STOP / Danger)
*   **컬러 팔레트:**
    *   메인 배경: `#0A0A0F` (딥 네이비/블랙)
    *   경고색: **Deep Crimson Red (`#B21829`)**
    *   텍스트 강조: 밝은 골드 또는 화이트 (`#FFFFFF`, `#FFD700`)

| 요소 | 디자인 상세 스펙 및 애니메이션 (Video 기준) | Static Image 적용 가이드라인 |
| :--- | :--- | :--- |
| **배너 배경** | 크림슨 레드로 이루어진 얇은 플래시 효과(Pulse)를 주기적으로 발생. 배너 좌측 끝에 미세한 노이즈/글리치(Glitch) 애니메이션 적용. | 단순 컬러 블록으로 처리하되, 경계선 주변에 디지털 글리치 패턴을 추가하여 '깨진' 느낌 유지. |
| **코드 영역** | `[STATUS: CRITICAL]` - 크림슨 레드로 깜빡이는 텍스트 효과(Blinking Cursor)를 사용하며, 전파되는 듯한 진동 애니메이션 적용. | 폰트 사이즈 키우고, 주변에 사각형 경계선을 넣어 시스템 메시지 박스처럼 보이게 합니다. |
| **메시지 본문** | "당신의 [신체/인지] 시스템은 현재 비정상 작동 중입니다." - 크림슨 레드로 강조하며, 텍스트가 타이핑되는 듯한 애니메이션(Typewriter Effect)을 적용합니다. | 가장 큰 글씨로 배치하고, 그 아래에 작은 자극 문구('즉시 진단 필요')를 넣습니다. |
| **CTA 버튼** | `[E-622 정밀 진단 프로토콜 실행]` - 크림슨 레드로 채워진 3D 입체감의 버튼 형태. (마우스 오버 시 미세한 흔들림 애니메이션). | 일반적인 버튼 모양 대신, '데이터 패킷을 전송'하는 듯한 직사각형 구조로 변경하고, 테두리를 강조합니다. |

#### III. 🟠 [A/B 테스트 Ver. 2] High Alert (Amber Warning)
*   **톤앤매너:** 주의 필요, 점검 및 개선 권장. (CAUTION / Cautionary)
*   **컬러 팔레트:**
    *   메인 배경: `#0A0A0F`
    *   경고색: **Warning Amber (`#FFC300`)**
    *   텍스트 강조: 딥 네이비 또는 블랙 (`#1A1A2E`, `#000000`)

| 요소 | 디자인 상세 스펙 및 애니메이션 (Video 기준) | Static Image 적용 가이드라인 |
| :--- | :--- | :--- |
| **배너 배경** | 앰버 색상의 깜빡이는 점멸 효과(Flicker/Strobe Light)를 주기적으로 발생. 글리치 애니메이션은 크림슨보다 약하게, '불규칙적인 데이터 오류' 느낌으로 처리. | 단순 컬러 블록 사용. 경고 삼각 기호 (⚠️)와 함께 배치하여 주의의 의미를 명확히 합니다. |
| **코드 영역** | `[STATUS: WARNING]` - 앰버 색상으로 점멸 효과 적용. 크림슨에 비해 진동 애니메이션을 줄여 '불안정'함보다는 '주의'에 초점을 맞춥니다. | 경고 사인과 함께 배치하며, 코드 주변에 데이터 파형(Waveform) 이미지를 넣습니다. |
| **메시지 본문** | "당신의 [신체/인지] 시스템은 현재 최적화가 필요합니다." - 앰버 색상으로 강조하고, 텍스트 애니메이션을 부드러운 '데이터 로딩' 효과로 변경하여 정보 제공의 느낌을 더합니다. | 권고 문구처럼 작성하며, 문제점을 지적하기보다 개선할 수 있다는 뉘앙스를 풍깁니다. |
| **CTA 버튼** | `[E-622 최적화 진단 받아보기]` - 앰버 색상으로 채워진 직사각형 형태. (마우스 오버 시 '전송 준비 완료' 같은 효과). | '데이터 로딩 바(Progress Bar)' 형태를 CTA 버튼처럼 사용하여, 사용자가 다음 단계로 나아갈 여지를 시각적으로 만듭니다. |

#### IV. 🔵 [A/B 테스트 Ver. 3] System Overload (Electric Blue Alert)
*   **톤앤매너:** 시스템 과부하, 데이터 처리 오류. (MALFUNCTION / Technical Failure)
*   **컬러 팔레트:**
    *   메인 배경: `#0A0A0F`
    *   경고색: **Electric Blue (`#33CCFF`)**
    *   텍스트 강조: 화이트 또는 밝은 시안 계열 (`#E0FFFF`)

| 요소 | 디자인 상세 스펙 및 애니메이션 (Video 기준) | Static Image 적용 가이드라인 |
| :--- | :--- | :--- |
| **배너 배경** | 블루 색상의 격자 패턴(Grid Pattern)이 미세하게 깜빡이며 '디지털 아티팩트' 느낌을 강조. 글리치 애니메이션은 가장 기술적이고 기하학적인 형태로 구현. | 파란색의 하이테크한 회로도(Circuit Board) 배경 위에 텍스트를 배치합니다. |
| **코드 영역** | `[ERROR: E-622]` - 시안 색상으로 깜빡이는 네온사인 같은 효과 적용. 마치 컴퓨터 터미널에서 오류가 출력되는 듯한 느낌을 극대화합니다. | 코드 자체를 가장 강조하며, 주변에 괄호나 대괄호를 사용하여 데이터의 일부처럼 보이게 합니다. |
| **메시지 본문** | "시스템 과부하 감지: 핵심 모듈 성능 저하 발생." - 시안색으로 강조하고, 마치 그래프가 오버로드 되는 듯한 '파형(Waveform)' 애니메이션을 배경에 깔아줍니다. | 시스템 로그 파일처럼 보이도록 텍스트를 배치하고, 시간과 코드를 함께 기록하는 형식을 취합니다. |
| **CTA 버튼** | `[SYSTEM DIAGNOSIS INITIATE]` - 시안색의 네온사인 느낌으로 빛나는 버튼. (마우스 오버 시 전력이 흐르는 듯한 전기 효과). | 'Execute Command' 또는 'Enter Protocol' 같은 명령어 창 스타일로 디자인하여, 사용자가 시스템을 직접 조작하는 기분을 느끼게 합니다. |
