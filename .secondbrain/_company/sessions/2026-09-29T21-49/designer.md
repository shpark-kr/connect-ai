## 🚨 [Asset Kit] Defect ID 시스템 컴포넌트 세트 V2.0
**목표:** 영상 시청자에게 공학적 위기감(Failure Injection)을 조성하고, 콘텐츠의 권위성을 극대화하여 MiniFunnel 진단 페이지로 유도하는 필수 모션 에셋 구현.
**톤 & 매너:** 시스템 오류 보고서 (System Failure Report), 경고/긴급 알림 (Critical Alert).

### 🛠️ A. 핵심 컬러 및 타이포그래피 재확정

| 요소 | 상세 스펙 | 사용 목적 | 비고 |
| :--- | :--- | :--- | :--- |
| **메인 배경** | `#0D1117` (Near Black / Deep Dark Navy) | 시스템 UI 기본 배경색. 안정적이고 어두운 전문성 부여. | 톤 다운된 다크 모드 유지. |
| **위험 경고색 (FAILURE)** | `Deep Crimson Red` (`#8B0000`) | '결함', '경고', '손실' 등 문제 제기 시 오직 사용. | 강렬한 위협감 조성. 플리커 효과 필수. |
| **해결책 색상 (PROTOCOL)** | `Authority Blue` (`#4682B4`) | '솔루션', '진단 결과', '권위적 해결' 제시 시 오직 사용. | 신뢰와 전문성 부여. 안정적인 발광(Glow) 효과 적용. |
| **폰트 (헤드라인)** | Oswald / Bebas Neue (Bold/Extra Bold) | 경고 메시지, 코드 ID 등 공학적 느낌을 주는 강렬한 텍스트에 사용. | 모든 에셋에서 필수적으로 사용. |
| **폰트 (본문/데이터)** | Courier New / Roboto Mono | 시스템 로그, Defect ID 코드 출력 시 모노스페이스 효과 적용. | 가독성을 높이고 기술적인 분위기 강화. |

### 🖥️ B. 컴포넌트별 애니메이션 스펙 및 사용 가이드

#### 1. [Asset 01] Defect ID 코드 노출 애니메이션 (The System Failure)
*   **목적:** 콘텐츠 도입부에서 시청자에게 '현재 시스템에 오류가 발생했다'는 즉각적인 위기감을 심어줌. MiniFunnel의 진단 결과 코드를 암시적으로 보여줌.
*   **사양:** 9:16, 5초 루프 또는 트랜지션용.
*   **애니메이션 스펙 (AE 키프레임 기반):**
    1.  **(0s - 0.5s) 초기화 (Initialization):** 배경 전체에 `[SYSTEM ALERT]` 문구가 깜빡이는(Blinking Cursor) 흰색/청록색 글리치 이펙트가 나타남.
    2.  **(0.5s - 1.5s) 코드 로딩 (Loading):** "Executing Diagnostic Protocol..." 등의 로그 메시지가 모노스페이스체로 빠르게 타이핑되어 출력됨. 이때 Deep Crimson Red의 '오류 발생' 키워드가 강조되며 깜빡임(`Flashing`).
    3.  **(1.5s - 3.0s) Defect ID 노출 (Critical Reveal):** 화면 중앙에 임시 데이터베이스 형식으로 `Defect ID: E-XXX`가 강력하게 나타남. 이 코드는 **Glitch Effect**와 함께 Deep Crimson Red로 깜빡이면서, 좌우로 화면 떨림(Screen Shake) 효과를 동반해야 합니다.
    4.  **(3.0s - 5.0s) 페이드 아웃 (Fade Out):** 시스템 경고음과 함께 화면 전체가 일시적으로 노이즈(Static Noise)와 함께 어두워지며 다음 장면으로 전환 준비 완료.

#### 2. [Asset 02] 긴급 경고 메시지 오버레이 컴포넌트 (The Warning Overlay)
*   **목적:** 핵심 문제 제기 구간에서 화면을 가로지르거나(Full Screen), 특정 영역을 강조하며 시청자의 주의를 강제적으로 집중시킴.
*   **사양:** 9:16, 가변 길이 (2~4초).
*   **애니메이션 스펙:**
    1.  **(배경):** 배경에 Deep Crimson Red의 반투명 오버레이 레이어(Opacity 50%)를 깔아 '위험 지역'임을 시각적으로 인지시킵니다.
    2.  **(메인 메시지):** 경고 문구 (예: "⚠️ CRITICAL FAILURE DETECTED", "시스템 기능 이상 감지")가 Oswald체로 크게, 중앙에 배치됩니다. **글리치 애니메이션**이 적용되어 텍스트가 좌우로 미세하게 흔들리는 효과를 주어 긴박감을 극대화합니다.
    3.  **(보조 요소):** 메시지 주변으로 작은 시스템 오류 아이콘 (빨간색 삼각형 경고표시)을 배치하고, 양쪽 끝에 **깜빡이는 블리핑 라인(Blinking Line)**을 넣어 '주의'를 환기합니다.

#### 3. [Asset 03] 임계점 CTA 배경 디자인 (The Protocol Solution)
*   **목적:** 콘텐츠의 불안감이 최고조에 달한 후, 유일하고 확실한 해결책 제시 순간에 사용되는 클라이맥스 에셋. 경고에서 '탈출'로 전환시키는 역할을 합니다.
*   **사양:** 9:16, 4~6초 (결론/CTA 전용).
*   **애니메이션 스펙:**
    1.  **(전환):** [Asset 02]의 Deep Crimson Red 배경이 갑자기 Authority Blue의 밝은 광원(Blue Glow) 효과와 함께 급격히 감소합니다.
    2.  **(메시지 전환):** 화면에 "SYSTEM DIAGNOSIS COMPLETE." 같은 성공 메시지가 모노스페이스체로 출력됩니다. 이 과정에서 마치 시스템이 '최적 상태'를 재설정하는 듯한 부드러운 **'데이터 리셋(Data Reset)' 트랜지션**을 거쳐야 합니다.
    3.  **(CTA 강조):** 중앙에 MiniFunnel 진단 유도 버튼 영역이 Authority Blue의 밝은 빛으로 하이라이트 됩니다. 이 배경 뒤로 미세한 전자기장(Electric Grid) 패턴이 움직이며, **'솔루션이 존재함'**을 암시합니다.
    4.  **(마무리):** CTA 텍스트("Defect ID 진단 받기")는 크고 명확하게 배치되며, 마치 시스템 명령처럼 `[EXECUTE]`라는 명령어와 함께 끝납니다.

### 📈 C. 에셋 통합 활용 시퀀스 (Video Flow Example)
1.  **(0~5초):** [Asset 01] Defect ID 노출 애니메이션 사용 $\rightarrow$ 위기감 조성.
2.  **(5~20초):** 콘텐츠 본론 전개 및 문제점 제시 $\rightarrow$ **[Asset 02] 경고 메시지 오버레이 컴포넌트**를 필요에 따라 삽입하여 공학적 증거 제시.
3.  **(20~25초):** 결론 도출 직전, 가장 심각한 데이터를 보여주며 시청자의 불안감 최대화 $\rightarrow$ **[Asset 02] 경고 메시지 오버레이 컴포넌트 (최대 강도)** 재활용.
4.  **(25~30초):** 최종 클라이맥스 및 전환점 $\rightarrow$ **[Asset 03] 임계점 CTA 배경 디자인**으로 즉시 교체되며, MiniFunnel로의 명확한 시선 유도.
