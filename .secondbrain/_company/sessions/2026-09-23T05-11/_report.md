## 🎯 프로젝트 개요 및 목표
*   **산출물 목적:** 사용자가 공적 지원 시스템 대비 놓치고 있는 '재정적 Gap 금액'을 자각하고, Mini-Assessment 진입을 유도하는 고전환율 인터랙티브 컴포넌트 완성.
*   **타겟 환경:** Mobile First (모바일 전용 PWA/웹뷰). 반응형 디자인은 고려하지 않으며, 단일 스크롤(Single Page Scroll) 구조를 유지합니다.
*   **핵심 KPI:** Gap 금액 자각 → 위협감 극대화 → CTA 클릭률 5% 이상 달성.

## ✨ 브랜드 및 심리적 가이드라인 (Tone & Emotion)
1.  **톤앤매너:** '전문적인 경고' (Authoritative Warning). 친절함보다는 신뢰도와 긴급성을 최우선합니다.
2.  **색상 팔레트:**
    *   **Primary Background:** `#0A1931` (Deep Navy - 신뢰, 전문성)
    *   **Secondary Accent:** `#FFD700` (Gold - 중요 정보 강조, 프리미엄 솔루션)
    *   **Warning/Gap:** `#CC0000` (Critical Red - 위협감, 손실 금액 표시 시 사용. 절대 배경색으로 사용 금지.)
    *   **Success/Safe Zone:** `#1E90FF` (Medium Blue - 안정적인 공적 지원 정보 제시 시 제한적으로 사용)
3.  **레이아웃:** 모든 콘텐츠는 중앙 정렬된 단일 컬럼(Single Column Flow)을 유지하여 스크롤 흐름을 끊지 않습니다.

## 💡 UX 플로우 및 인터랙션 로직 (The Core Logic)
사용자는 총 3단계의 질문(요양, 주거/교통, 의료)에 답하며 Gap 금액이 점진적으로 누적되는 경험을 합니다.

### 1. 초기 진입 단계 (Pre-Gap): 공포감 유발 및 기대치 설정
*   **시각 요소:** 큰 헤드라인과 함께 '혹시 놓치고 있는 부분이 있나요?'와 같은 질문형 문구로 시작합니다.
*   **상호작용:** 첫 3개 질문은 Gap 금액 계산에 직접 참여하지 않으며, 공적 지원 제도의 존재를 상기시키는 역할만 합니다 (Warm-up).

### 2. 핵심 진단 단계 (Gap Calculation Loop): 위협감 극대화
*   **원리:** 사용자가 각 섹션의 질문(Q)을 선택할 때마다 `[추가 Gap 금액] = [선택된 항목의 비용] - [공적 지원 최대 보장액]` 공식을 거쳐, 이 값이 누적되어 메인 Gap Display에 즉시 반영됩니다.
*   **상호작용:**
    1.  사용자 질문 클릭/라디오 버튼 선택 (예: '월 30만원 추가 비용 발생 가능')
    2.  프론트엔드(PWA)가 해당 값을 감지하고, API 호출 없이 클라이언트 측에서 `totalGapAmount` 변수를 업데이트합니다.
    3.  **핵심:** 화면 상단/하단의 메인 Gap Display 컴포넌트(`<GapDisplayModule>`)의 텍스트와 색상(Critical Red)이 즉시 변화해야 합니다.

### 3. 최종 전환 단계 (Conversion): 해결책 제시 및 CTA
*   **발동 조건:** 모든 섹션 완료 시, 최종 누적된 `totalGapAmount`가 화면 중앙에 가장 크고 강렬한 '충격 요법'으로 표시됩니다.
*   **메시지:** "당신이 놓친 Gap 금액은 OOO원입니다. 이 돈을 방치하면 1년 뒤 OO 문제가 발생할 수 있습니다." (FOMO 극대화)

## 🛠️ 컴포넌트별 상세 사양서 (Kodari Ready Components)

### 1. `<QuestionCard>` (질문 카드 컴포넌트)
*   **구조:** 질문 헤드라인(H2), 본문 설명(P), 그리고 옵션 버튼 그룹(`OptionGroup`).
*   **옵션 버튼 (`<SelectButton>`):**
    *   버튼 텍스트: '비용 항목' (예: "월 교통비 추가 부담")
    *   데이터 속성 (`data-gap-value`): 이 버튼이 선택되었을 때 계산되어야 할 Gap 금액의 숫자 값.
    *   상태 관리: 활성화(Selected) 시 `Deep Navy/Gold` 테두리, 비활성화(Deselected) 시 투명한 배경 처리.

### 2. `<GapDisplayModule>` (핵심 Gap 표시 모듈 - **가장 중요**)
*   **위치:** 페이지 상단 고정 영역 (Sticky Header).
*   **표시 값:** `Total Potential Loss: <span id="current_gap">0원</span>`
*   **인터랙션:** 모든 질문 선택에 반응하여 실시간으로 업데이트되어야 합니다.
*   **스타일 변화 로직:**
    *   `totalGapAmount`가 0원일 때: 글자색 `#FFD700`(골드).
    *   `totalGapAmount`가 최소 임계값(예: 100만원)을 넘을 때: **글자색 `#CC0000` (Critical Red)**으로 변경 및 애니메이션 효과(깜빡임 또는 진동 효과)를 적용하여 사용자 주의 집중.

### 3. `<SectionSummaryBox>` (섹션 요약 박스)
*   **목적:** 각 섹션이 끝날 때마다 사용자가 지금까지 '무엇을 놓치고 있는지' 재확인시켜 공포감을 유지합니다.
*   **내용:** "✅ [요양시설] 점검 완료: 현재까지 추정 Gap 금액 ₩X,XXX,XXX"
*   **디자인:** 배경색 `#1A2B45` (짙은 네이비)에 골드 경계를 넣어 중요도를 높입니다.

## 🖼️ 데이터 기반 시각화 에셋 요구사항 (Visual Asset Briefs)
개발 단계가 완료된 후, 이 체크리스트의 결과를 요약하여 보여줄 고해상도 이미지/인포그래픽을 다음 목적에 맞게 제작해야 합니다.

1.  **[결과 배너] Gap Amount 시각화:** 누적된 `totalGapAmount`를 가장 크고 직관적인 차트로 보여줍니다. (예: 3D 그래프 형태의 '손실액' 바 그래프).
2.  **[경로 안내] Funnel Flow Chart:** 체크리스트 진단 → Gap 자각(충격) → Mini-Assessment 진입(해결책 탐색) 과정을 화살표와 함께 시각화한 플로우 차트가 필요합니다. (전환율 극대화를 위한 설계).
