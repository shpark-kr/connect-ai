### 🖼️ 3가지 데이터 시각화 패턴 (Design System V1.0 - Blog용)

#### 💡 Pattern 1: Gap 비교형 막대 그래프 (The "Missing Money" Chart)
*   **목적:** 현재 인식하는 자금 규모(A)와 실제 필요한 최소한의 안전 자금 규모(B) 사이의 **'결손액(Gap)'**을 직관적으로 보여주어 충격 효과를 극대화합니다. 블로그 도입부에서 사용되어야 합니다.
*   **데이터 유형:** 2개 항목 간의 정량적 비교 (예: 현재 퇴직금 vs. 30년 평균 생활비).
*   **기술 스펙:** SVG Bar Chart Component, Interactive Hover Effect 필수.
*   **사이즈:** 가로 폭 1200px / 높이 450px (Web Container 표준)

| 요소 | 상세 디자인 지시 | Hex Code | 비고 |
| :--- | :--- | :--- | :--- |
| **배경색** | 순백색 배경에 은은한 그림자 효과 적용. | `#FFFFFF` | - |
| **주요 막대 (A)** | 현재 자산 규모 (긍정적 인식). 채도가 높은 노란색으로 표현하여 '착각'의 느낌을 줌. | `#FFC300` | `Current Status` |
| **필수 막대 (B)** | 필요한 최소 안전 자금 규모 (팩트). 더 강렬하고 경고적인 색상 사용. | `#CC0000` | `Required Gap` |
| **Gap 영역** | B와 A 사이의 차이(결손액)를 **가장 어두운 경고색**으로 칠해 시각적 공포 유발. | `#FF7B00` (Warning Orange) | 이 색상이 '놓치고 있는 돈'을 상징해야 함. |
| **텍스트/축 레이블** | 명료하고 큰 고딕체 사용. Gap 영역과 연관된 키워드를 볼드 처리. | `#333333` | 가독성 최우선. |

***

#### 💡 Pattern 2: 시간 경과형 파묻는 라인 차트 (The "Consumption Spiral")
*   **목적:** 시간이 흐름에 따라 자산이 점진적으로, 그리고 *필연적으로* 고갈되는 과정을 그래프로 보여줍니다. 단순한 숫자가 아닌 '시간의 위협'을 느끼게 합니다. 블로그 중반부, 위험 경고 파트에서 사용됩니다.
*   **데이터 유형:** 연도별/기간별 자산 추이 예측 (Exponential Decay Curve).
*   **기술 스펙:** SVG Line Chart Component. 애니메이션 효과(시간 순서대로 라인이 그려지는) 필수.
*   **사이즈:** 가로 폭 1200px / 높이 550px

| 요소 | 상세 디자인 지시 | Hex Code | 비고 |
| :--- | :--- | :--- | :--- |
| **배경색** | 흰색 배경에 그래프 아래쪽에 은은한 회색 그라데이션을 넣어 '깊이감' 표현. | `#F5F5F5` | - |
| **라인 1 (이상적)** | 자산의 이상적인 유지 경로(기준선). 부드러운 연한 노란색 점선. | `#FFD700` | `Ideal Path` |
| **라인 2 (예상 실패)** | 현재 습관을 유지했을 때 예상되는 급격한 하락 곡선. 경고의 느낌이 강하게 드는 주황-빨강 계열. | `#CC6600` | 라인의 기울기가 곧 '위험성'입니다. |
| **결손 영역** | 두 라인 사이의 거리가 벌어지는 구간을 굵은 음영 처리로 강조하여, Gap이 커지는 물리적 공간처럼 보이게 함. | `#FF7B00` | 시각적으로 가장 넓고 어둡게 처리해야 합니다. |
| **핵심 요소** | 자산 고갈 지점(X축의 특정 연도)에 큰 원형 마커를 배치하고, 팝업 형태로 '위험 경보' 문구 삽입. | - | 인터랙티브 필수. |

#### 💡 Pattern 3: 체크리스트/Funnel Infographic (The "Must-Do Action")
*   **목적:** 독자에게 불안감을 극대화한 후, 최종적으로 '해결책(Solution)'을 제시하며 신뢰를 구축합니다. 단순 나열이 아닌, *반드시 점검해야 할 체크리스트 구조*로 설계합니다. 블로그 후반부, 행동 촉구 CTA 직전에 사용됩니다.
*   **데이터 유형:** 복잡한 정책/혜택 목록 (List of potential benefits).
*   **기술 스펙:** SVG Step-by-Step Funnel / Checklist Component. 체크박스(Checkbox) 형태의 인터랙션 필수.
*   **사이즈:** 가로 폭 1200px / 높이 650px

| 요소 | 상세 디자인 지시 | Hex Code | 비고 |
| :--- | :--- | :--- | :--- |
| **배경색** | 흰색 배경. 전체적으로 '깨끗하고 명확한' 느낌을 강조하여 안도감을 주되, 중요 항목만 노랑으로 포커싱. | `#FFFFFF` | - |
| **헤드라인 강조** | "당신이 놓치고 있는 5가지 재정 점검 항목"과 같은 문구를 가장 크게 처리하고, 배경에 미묘한 골드 패턴을 넣음. | `#FFC300` | `Focus Area Highlight` |
| **체크박스/아이콘** | 각 항목 앞에 체크가 필요한 느낌의 커다란 원형 아이콘(Circle Icon) 배치. 아직 점검하지 않았음을 나타내는 빈 노랑 테두리 사용. | `#DDEEFF` (옅은 파랑) | 신뢰와 안정감을 상징하는 보조색을 사용하여 '해결'의 이미지를 구축. |
| **핵심 항목 강조** | 가장 중요한 혜택(예: 연금 사각지대)에는 별도의 박스를 만들고, 그 배경에 은은한 노란 빛 효과를 주어 시선 집중 유도. | `#FFD700` | `Callout Box Effect` |
| **전체 구조** | 위에서 아래로 자연스럽게 흐르며 '점검 → 확인 → 행동'의 논리적 순서를 따르도록 레이아웃 설계. | - |
