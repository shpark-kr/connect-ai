#### **2️⃣ 개발자를 위한 원천 데이터 구조화 가이드 (API & DB Specification)**

이 섹션은 코다리에게 전달되는 가장 중요한 부분입니다. 각 지표를 구현하기 위해 필요한 최소한의 필드와 데이터를 명확히 정의합니다.

**A. [지표 1] 장기요양보험 미적용 사각지대 규모 (LTC Gap)**
*   **데이터 수집 주기:** 분기별 (최소 월 단위 업데이트 권장)
*   **핵심 API 포인트:** 지자체별/등급별 지원금 상한선 데이터, 비급여 항목 목록 및 평균 비용.
*   **필수 필드 구조 (JSON Schema 예시):**

```json
{
  "data_id": "LTC_GAP_[YYYYMMDD]",
  "지표명": "장기요양보험 사각지대 분석",
  "기준일자": "2024-12-31",
  "분석지역": ["서울시", "경기도"], // 지자체 단위 분리 저장 필수
  "지원등급_코드": ["1~5등급 구분"], 
  "비급여_항목": [
    {
      "item_name": "전문 간병인 서비스 (시간당)",
      "평균_시장가액(원)": 20000, // 기준값: 시장 평균 가격
      "공단_지원금(원)": 15000,   // 지원 가능 최대 금액
      "Gap_Amount(원)": "계산필드 (시장가 - 지원금)",
      "근거법규": "지자체 복지 서비스 가이드라인 제X조"
    }
  ],
  "최신정책변화요약": "2025년 기준, OO 지자체에서 간병비 바우처 지급 확대 예정." 
}
```

**B. [지표 2] 소득 공백 및 연금 누락분 위험 분석 (Pension Gap)**
*   **데이터 수집 주기:** 반기별 (국민연금공단 통계 발표 시점)
*   **핵심 API 포인트:** 퇴직 전/후 예상 소득 흐름 비교, 공제율 변화에 따른 예상 손실액 산출 로직.
*   **필수 필드 구조 (JSON Schema 예시):**

```json
{
  "data_id": "PENSION_GAP_[YYYYMMDD]",
  "지표명": "퇴직 후 소득 공백 위험 분석 모델",
  "대상직군": ["공무원 퇴직자", "일반 기업 퇴직자", "프리랜서/자영업자"], 
  "분석기간_년수": 10, // 계산 기준 기간
  "가정변수": {
    "퇴직연령대": [55-60],
    "현재소득수준": ["월 평균 400만원"]
  },
  "시뮬레이션_결과": [
    {
      "공적연금예상액(원)": 1200000, // 공단 데이터 기반 예측치
      "개인자산운용필요액(원)": 800000, // 목표 생활비 대비 부족분 (진짜 Pain Point)
      "Gap_Amount(원)": "계산필드",
      "위험지표": ["소득 감소율 위험"]
    }
  ]
}
```

**C. [지표 3] 비급여 의료 리스크 증가율 추이 (Non-Covered Risk)**
*   **데이터 수집 주기:** 연간 또는 반기별 (심평원 통계 기반)
*   **핵심 API 포인트:** 특정 만성질환(당뇨, 고혈압 등) 환자의 비급여 항목 Top 5 리스트 및 비용 변화 추이.
*   **필수 필드 구조 (JSON Schema 예시):**

```json
{
  "data_id": "NHIS_RISK_[YYYYMMDD]",
  "지표명": "만성질환자 비급여 의료비 증가 경고",
  "대상질환군": ["당뇨병", "고혈압"], 
  "분석기간": ["2018년 ~ 2023년"],
  "의료항목_트렌드": [
    {
      "item_name": "특정 검사 패키지 (예: 혈당 측정)",
      "최초관찰연도": 2018,
      "평균비용(원)": {
        "2018": 5000,
        "2023": 15000 // 급격한 증가율 강조 필요
      },
      "증가율_CAGR_%": "계산필드 (연평균 증가율)",
      "주의문구": "이 항목은 필수 검사로 오인되어 지출되는 경우가 많습니다." 
    }
  ]
}
```
