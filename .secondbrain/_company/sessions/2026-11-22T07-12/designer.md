# 🚨 [Final Specification] Defect ID 오버레이 에셋 디자인 사양서 (Video Ready)

## 📐 1. 기본 시스템 및 가이드라인
*   **플랫폼:** Instagram Reels / Short-form Video (9:16 비율, Full Screen Overlay).
*   **목표:** 전문적인 의료 보고서를 보는 듯한 '권위적 긴급성(Authoritative Urgency)' 부여.
*   **색상 팔레트:**
    *   `#0A182F` (Deep Navy - 배경/기본 텍스트)
    *   `#E32636` (Critical Red - 경고, 결함 지표, 위험 강조)
    *   `#FFC72C` (Warning Gold - 중요 포인트, Callout 박스)
    *   `#FFFFFF` (White - 주요 텍스트)
*   **폰트:** 고딕 계열의 산세리프(Sans-serif). 전문성을 위해 명확하고 간결한 느낌이 필수입니다. (예: Pretendard Bold/SemiBold 활용 권장)

## ⚙️ 2. 핵심 컴포넌트별 디자인 사양 (Animation Focus)

### A. Critical Alert UI (가장 중요, 위험 경고 바)
*   **역할:** 시청자에게 '지금 이 정보는 심각한 경고'임을 즉시 주지시킨다. 콘텐츠의 클라이맥스(Hook 직후 또는 Defect ID 제시 순간)에 사용.
*   **위치:** 화면 상단 (Top Center, 5% 높이).
*   **디자인 요소:**
    1.  **배경:** 반투명 블랙/딥 네이비 배경 (`rgba(10, 24, 47, 0.8)`).
    2.  **테두리:** Critical Red 플래싱 라인 (애니메이션 필수).
    3.  **아이콘:** 경고 삼각형 아이콘 (`⚠️`)을 좌측에 배치하고 Gold로 강조.
*   **✅ 애니메이션 가이드 (Critical Flashing):**
    *   **(0.0s - 0.2s):** 배경이 어둠 속에서 빠르게 나타나며(Fade In) 화면 상단 전체를 채움.
    *   **(0.2s - 1.5s):** Critical Red 테두리가 **점멸 효과(Pulsating Glow)**를 주면서 지속적으로 깜빡임 (Cycle: On-Off, 주파수 0.3초).
    *   **(1.5s - 2.0s):** 경고 문구가 최대 크기로 나타났다가 부드럽게 축소되며 사라짐(Fade Out), 다음 화면 전환을 예고함.

### B. Defect Metric Display (데이터 지표 시각화)
*   **역할:** 추상적인 개념(예: '혈당 스파이크')을 구체적이고 충격적인 수치로 변환하여 전문성을 확보한다.
*   **위치:** 화면 중앙 또는 우측 하단 (정보의 밀도가 높아야 하는 곳).
*   **디자인 요소:**
    1.  **레이블:** `[Defect ID-01]` 같은 고유 코드를 Gold로 배치하여 보고서 느낌 강화.
    2.  **수치:** 측정값은 항상 **볼드체(Bold)**와 Critical Red 색상을 사용한다. (예: 180 mg/dL $\rightarrow$ \#E32636)
    3.  **그래프 형태:** 단순한 숫자가 아닌, **'Before / After' 비교형 차트**를 짧게 보여줘야 함. (예: 이전 수치(Navy) vs 현재 리스크 수치(Red)).
*   **✅ 애니메이션 가이드 (Metric Reveal):**
    *   **(0.0s - 0.5s):** 데이터 값이 0부터 시작하여 **빠르게 카운트업(Counter Up)**되는 효과를 준다. (숫자가 '도달하는' 느낌).
    *   **(0.5s - 1.5s):** 그래프가 마치 스캔되듯 수평선(`Scanning Line`)을 따라 그려지며(Drawing Animation), 최종 값이 정착한다. 이 과정에서 배경에 미세한 디지털 노이즈/글리치 효과를 추가하여 SF적 긴장감을 높인다.

### C. MiniFunnel CTA Graphic (행동 유도)
*   **역할:** 영상의 결론이자, 시청자가 다음 행동을 취해야 하는 명확한 지점을 제공한다.
*   **위치:** 화면 하단 1/4 영역에 고정 배치.
*   **디자인 요소:**
    1.  **배경:** 배경과 대비되는 밝은 색상 (예: 미세하게 광원 효과를 준 연한 골드 배경).
    2.  **CTA 버튼:** 가장 눈에 띄는 **Critical Red 플랫 디자인 버튼**. (텍스트만 넣지 말고, 실제 클릭 가능한 버튼 모양으로 만듦).
    3.  **유도 문구:** "자세히 알아보기" 대신 **"[Defect ID] 자가 진단 키트 받기"**와 같이 구체적인 행동과 혜택을 결합한 문구를 사용해야 함.
*   **✅ 애니메이션 가이드 (Action Prompt):**
    *   **(최종 3초 전):** CTA 버튼이 마치 **'전기가 흐르듯(Electric Arc)'** 짧게 번쩍이며 포커스를 받는다.
    *   **(지속):** 화면에 배치된 MiniFunnel 링크/프로필 아이콘 방향으로 **미세한 애니메이션 화살표가 톡톡 치는 듯(Tapping)** 움직여 시선을 유도한다.

## 💡 3. 추가 오버레이 요소 (Contextual Enhancements)
*   **[Focus Box]:** 특정 단어나 개념을 언급할 때, 해당 단어 주위에 **Gold 테두리의 박스**를 짧게 생성하여 강조 (마치 연구원이 포스트잇으로 표시하듯).
*   **[Glitch Effect]:** 중요한 정보가 지나가거나 메시지가 전환될 때, 영상 전체에 찰나의 디지털 글리치(Distortion) 효과를 적용하여 '시스템 오류' 컨셉을 일관성 있게 유지한다.
