# 📐 Mini-App 진단 도구 (Diagnostic Panel) Handoff Specification v1.0

## I. 목표 및 구조 개요
*   **목표:** 사용자가 자신의 건강 위험도를 즉각적으로 인지하고, 이 불안감을 해소하기 위해 'Mini-App'으로 전환하도록 유도하는 것이 최우선 목적입니다.
*   **레이아웃 시스템:** 12-Column Flexbox Grid (모바일 가로폭 기준). 모든 섹션은 `max-width: 640px`를 기준으로 설계합니다.
*   **데이터 흐름:** Mock Data Set $\rightarrow$ 스코어 계산 로직(JS) $\rightarrow$ 위험도 측정 바 업데이트 $\rightarrow$ CTA 활성화/강화.

## II. 핵심 컴포넌트 상세 명세 (Components Specification)

### 1. [Risk Bar] 위험도 측정 바 (SVG 기반 인터랙티브 요소)
이 컴포넌트는 진단 점수(0~100점)를 가장 즉각적이고 공포감을 유발하는 방식으로 시각화하는 핵심 요소입니다.

| 속성 | 정의 | 기술 요구 사항 | 비고 |
| :--- | :--- | :--- | :--- |
| **구조** | SVG Path (`<path>`) 기반의 채우기(Fill) 방식 사용. | `viewBox="0 0 1200 100"` 등 고정된 좌표계를 사용하여 크기 변화에 대응합니다. | 크기 변수 대신 비율로 제어해야 함. |
| **데이터 입력** | `score` (number, 0 ~ 100) | JS에서 계산된 점수를 받습니다. | Score가 낮을수록 채워진 길이를 늘립니다. |
| **색상 매핑 로직 (Color Logic)** | **[Primary]** 위험도에 따른 배경 및 전경 색상 변화를 강제합니다. | 1. `0-30`: `#4CAF50` (🟢 녹색, 안전) <br> 2. `31-60`: `#FFC107` (🟡 노란색, 주의) <br> 3. `61-100`: `#F44336` (🔴 빨간색, 위험) | 배경 색상(Background Color)도 점수 구간별로 변경해야 합니다. |
| **애니메이션 로직 (Animation)** | **'Pulse Effect'** 적용 필수. | `score >= 61`일 경우: CSS Keyframe Animation을 사용하여 박자가 있는 깜빡임 효과(`opacity` 변화와 함께 미세한 크기 진동)를 강제합니다. <br> *Delay:* 점수 계산 완료 후 500ms 뒤에 시작됩니다. | 시각적 경고의 최고 우선순위 요소입니다. |

**💡 개발 지침 (Pseudo-Code Example):**
```javascript
function updateRiskBar(score) {
    let color = getColorByScore(score); // 로직 함수 호출
    document.getElementById('risk-svg-path').style.fill = color;
    document.getElementById('risk-bar-container').classList.add('pulse', score >= 61 ? '' : 'none');
}
```

### 2. [Diagnostic Header] 헤더 및 결과 요약 박스
진단 결과를 한눈에 보여주며, 사용자의 공포감을 극대화하는 영역입니다.

*   **구조:** 좌측 4칸 / 우측 8칸 레이아웃 유지 (혹은 모바일에서 상하 분리).
*   **핵심 요소:** 점수(Score)와 위험도 레벨(Level: 예. '만성 염증 고위험군')을 대형 타이포그래피로 배치합니다.
*   **CTA 유입 연계:** 이 섹션의 가장 하단에 CTA 버튼 그룹이 붙어 있어, 사용자가 결과를 확인하자마자 다음 액션을 취하도록 시선 흐름(Funnel)을 설계해야 합니다.

## III. A/B 테스트용 CTA Button 영역 3가지 변형 (Technical Variation Specification)
CTA는 단순한 '클릭'이 아니라, **심리적 전환**이 일어나야 합니다. 개발팀은 아래의 세 가지 버전 중 가장 효율적인 반응(CTR)을 보이는 버전을 실시간으로 A/B 테스트할 수 있도록 구조화해야 합니다.

| 버전 | 목표 심리 상태 (Emotion) | 카피 전략 (Tone & Copy) | 레이아웃 및 스타일 가이드 |
| :--- | :--- | :--- | :--- |
| **V1: 공포 자극형** (Fear/Urgency) | "이대로 가면 안 된다" (위기감) | **[헤드라인]:** 경고. 지금 당장 점검하지 않으면 늦습니다. <br> **[서브 카피]:** 전문의가 말하는 당신의 '대사 기능' 위험 신호입니다. | **배경:** 강렬한 빨간색/어두운 배경 (Risk Bar와 통일성).<br>**버튼:** 가장 크고, 깜빡이는 애니메이션 효과(Pulse)를 적용하여 시선 고정 유도. <br>**CTA 텍스트:** "위험 자산 방어 시작하기" |
| **V2: 신뢰/해결책 제시형** (Trust/Authority) | "전문적인 도움을 받고 싶다" (안심, 기대) | **[헤드라인]:** 객관적 데이터로 나의 건강 수준을 진단하세요. <br> **[서브 카피]:** 온현의 [Mini-App]은 10년 이상의 임상 데이터를 기반으로 합니다. | **배경:** 브랜드 메인 컬러 (다크 네이비 계열)를 유지하며, 신뢰감을 주는 질감 처리.<br>**버튼:** 골드 포인트 색상을 사용하여 권위와 전문성을 강조. 애니메이션 없이 깔끔하고 명확한 버튼 형태. <br>**CTA 텍스트:** "전문 진단 리포트 받기" |
| **V3: 낮은 장벽 유도형** (Low Barrier/Curiosity) | "가볍게 궁금증을 해소해 보고 싶다" (탐색 욕구) | **[헤드라인]:** 단 5분만 투자하세요. 내 몸이 보내는 신호가 무엇인지 알아봅시다. <br> **[서브 카피]:** 간단한 질문으로 만성 염증 및 근력 저하 리스크를 점검할 수 있습니다. | **배경:** 대비가 적은 미디엄 그레이 톤을 사용하여 부담감을 줄임.<br>**버튼:** 가장 부드러운 곡선의 형태와 크기. <br>**CTA 텍스트:** "간단 진단 시작하기" (혹은 '자세히 알아보기') |

## IV. 기술 명세서 요약 체크리스트 (Developer Checklist)
개발팀이 구현 시 반드시 점검해야 할 필수 항목입니다.

1.  [ ] **반응형 그리드:** 320px ~ 640px까지의 모바일 환경에서 레이아웃이 깨지지 않는지 확인합니다.
2.  [ ] **상태 기반 로직:** 스코어(Score) 값 변화에 따라 Risk Bar의 색상, 애니메이션, 그리고 CTA 버튼 그룹 전체의 디자인 변형(V1 $\leftrightarrow$ V2 등)이 즉시 동기화되는지 검증해야 합니다.
3.  [ ] **성능 최적화:** SVG와 애니메이션 사용으로 인한 번들 사이즈 증가나 로딩 지연이 발생하지 않도록 CSS/JS 최적화를 진행합니다.
