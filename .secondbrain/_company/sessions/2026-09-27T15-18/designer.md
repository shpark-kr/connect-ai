## 📋 개요 및 목적
본 가이드는 ADLS 점수 계산 로직(`calculate_adls_score`)의 **정량적 결과(Score)**를 바탕으로, 사용자에게 가장 효과적으로 *'위험 인지'*와 *'해결 필요성'*을 전달하는 인터페이스 시나리오 흐름 및 애니메이션 타이밍을 정의합니다.

**핵심 원칙:**
1.  **Deep Crimson Red 활용:** 위험도가 높아질수록 이 색상의 사용 비중과 강도를 높여 긴급성과 권위를 확보합니다.
2.  **점수 기반 스토리텔링:** 점수를 단순한 숫자로 제시하지 않고, '미래 자산 감소 리스크'라는 감정적 맥락으로 재해석하여 공포와 해결 의지를 자극합니다.
3.  **직관적인 피드백:** 화면 전환 시 애니메이션 타이밍을 명시하여 개발팀의 구현 편의성을 극대화합니다.

| 위험도 등급 | 점수 범위 (Score Range) | Deep Crimson Red 사용 정도 | 핵심 메시지 / 톤앤매너 | CTA 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **🟢 안정권** (Low Risk) | Score $\ge$ 75점 | 최소화 (Deep Crimson Red를 '경고' 목적 외 사용 금지) | "현재는 양호하나, 점진적 관리가 필요합니다. 습관을 유지하는 것이 중요합니다." (안심감 + 관리 독려) | 콘텐츠 소비 유도 / 장기 관심사 등록 |
| **🟡 주의 단계** (Medium Risk) | 40점 $\le$ Score $<$ 75점 | 중간 (배경 하이라이트, 경고 아이콘 활용) | "몇 가지 생활 습관 개선이 필요합니다. 지금 점검하면 손실을 막을 수 있습니다." (호기심 + 기회 제시) | Mini-App 재진단 유도 / 핵심 콘텐츠 열람 |
| **🔴 위험 단계** (High Risk) | Score $<$ 40점 | 극대화 (전면 배경, 메인 카운터, CTA 버튼 등 필수 요소에 사용) | "경고. 현재 신체 건강 자산의 손실 속도가 심각합니다. 즉각적인 전문 점검이 필요합니다." (긴급성 + 공포 유발) | **Mini-App 진단 도구 결제/가입 Funnel로 즉시 이동** |

## 🎬 2단계: UI/UX 시나리오 흐름 및 애니메이션 가이드라인 (Flow & Animation)

### A. 초기 진단 화면 $\rightarrow$ 결과 리포트 전환 (The Reveal Moment)
*   **목표:** 사용자가 자신의 점수를 발견하는 순간, 심리적 충격을 극대화하여 다음 단계로의 이탈을 방지합니다.
*   **액션:** 데이터 로딩 완료 직후.
*   **애니메이션 지시:**
    1.  `Score Card`: 초기에는 0점 또는 '계산 중...' 텍스트로 표시됩니다.
    2.  **[Animation Timing]**: 점수가 계산되는 동안 **Deep Crimson Red의 미세한 글리치(Glitch) 효과**를 배경에 반복 노출합니다 (Duration: 1초).
    3.  최종 점수 도달 시: 점수 숫자가 **'카운트업 애니메이션'**으로 빠르게 증가하며 최종 값(`Score`)을 확정적으로 보여줍니다. (Transition Time: 0.7s, Easing: `cubic-bezier(0.25, 1, 0.5, 1)`)
    4.  점수 아래의 위험도 바(Risk Bar): 점수가 도달하는 동시에, 해당 색상으로 **'차오르는 듯한 (Fill Up)' 애니메이션**이 적용됩니다.

### B. 결과 리포트 화면 $\rightarrow$ CTA 유도 단계 (The Action Trigger)
*   **목표:** 사용자가 자신의 위험도를 인지했으면, 해결책을 제시하여 다음 Funnel로 안내합니다.
*   **시나리오 분기점:**
    1.  **(🔴 High Risk):** 점수와 함께 **'경고! 즉각적인 행동이 필요합니다.'**라는 헤드라인이 전체 화면에 팝업처럼 나타납니다. (Transition: `ease-in-out`, Duration: 0.5s). 가장 큰 CTA 버튼(예: '전문가 상담 예약하기')이 Deep Crimson Red로 강조되며, **화면 하단에서 위로 강하게 상승하는 듯한 애니메이션**을 적용합니다.
    2.  **(🟡 Medium Risk):** "관리가 필요한 영역"이라는 문구와 함께, 세부적인 생활 습관 개선 가이드가 팝업됩니다. 이 때, 해결책 제시 섹션에 **'더 깊이 알아보기 (Mini-App Funnel)'** 버튼을 배치하고, 해당 버튼만 은은하게 깜빡이는(Pulse) 효과를 적용합니다.
    3.  **(🟢 Low Risk):** "꾸준한 관리가 중요합니다."라는 메시지를 전달하며, '유지 습관 리포트' 등의 콘텐츠 다운로드로 유도합니다.

## 📑 3단계: 개발자 필수 기술 명세 (Developer Tech Spec Checklist)

### 1. 컴포넌트별 CSS/JS 로직 요구사항
| 요소 | 상태 | 시각적 지시 | 애니메이션 및 트랜지션 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **위험도 바 (Risk Bar)** | Low / Medium / High | Deep Crimson Red 계열의 강약 조절. 점수 도달에 따라 색상 채움. | `transition: all 0.8s cubic-bezier(0, 1, 0, 1)`를 사용하여 부드럽게 채워지도록 구현. | SVG Path 데이터 활용 권장. |
| **핵심 CTA 버튼** | 기본 / Hover / Active | Deep Crimson Red (`#B30000`) 기반. 크기는 반응형으로 일정 유지. | `transform: translateY(5px); box-shadow: 0 10px 20px rgba(179, 0, 0, 0.4);` (Hover 시). | 클릭 직전 Micro-Interaction 필수. |
| **경고 메시지 박스** | 활성화 시 | 배경에 Deep Crimson Red를 활용한 반투명 오버레이 적용. | `opacity: 0` $\rightarrow$ `opacity: 1` (Duration: 0.4s, Easing: `ease-out`). | 공포감 극대화를 위해 매우 빠르고 강하게 등장해야 함. |

### 2. 마이크로카피 가이드라인 (Tone & Message)
*   **위험 메시지 헤드라인:** "당신의 건강 자산이 감소하고 있습니다." 또는 "현재 점검 결과, 즉각적인 리스크가 발견되었습니다." (직접적이고 단정적인 어조 유지).
*   **대안 제시 톤:** '문제'만 던지지 않고 반드시 **'해결을 위한 로드맵'**을 함께 제시합니다. (예: "하지만 이대로 방치할 필요는 없습니다. [솔루션]을 통해 시간을 되돌릴 수 있습니다.")
