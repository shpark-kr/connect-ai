# 📋 작업 브리프

**원 명령:** md 파일이 아닌 html 파일로 만들어줘

## 요약
이전 작업에서 생성된 모든 콘텐츠(특히 시리즈 블로그 글)의 파일 형식을 Markdown(.md)이 아닌 웹에 바로 적용 가능한 완전한 HTML 구조로 재작업해야 합니다. 원본 텍스트의 내용과 논리적 흐름은 유지하되, 개발자가 즉시 사용 가능한 코드 형태로 변환하는 것이 목표입니다.

## 분배
- **✍️ Writer**: 이전에 작성된 모든 시리즈 블로그 초안 원고(HTML 구조화 전의 텍스트 기반 콘텐츠)를 검토하고, 각 섹션별로 HTML 변환에 적합한 마크다운이나 플레이스홀더가 아닌 순수이고 완벽하게 구획화된 텍스트 흐름으로 정리하여 개발팀에 전달하십시오.
- **💻 코다리**: Writer가 제공한 모든 콘텐츠 원고를 받아, 마크다운 문법이 아닌 Semantic HTML5 태그 구조(예: , , ,  등)를 사용하여 완벽하게 변환하십시오. 단순 텍스트 변환을 넘어, 블로그 플랫폼에 업로드했을 때 오류가 발생하지 않도록 스타일링 가이드라인까지 고려한 코드 단위로 최종 파일을 생성해야 합니다.
