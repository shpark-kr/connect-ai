## 📘 노후 자금 Gap 체크리스트 디자인 시스템 브리프 V1.0
**(Target: Web Interactive & PDF Lead Magnet)**

### 1. 브랜드 시각 요소 (Visual Identity System)

| 항목 | 사양/설명 | Hex Code | 용도 및 의의 |
| :--- | :--- | :--- | :--- |
| **메인 배경색** | 신뢰와 깊이를 주는 어두운 네이비 계열 | `#1E2A47` | 전체적인 전문성 확보. 밤하늘, 안정된 지식 전달 느낌. (다크 모드 기반) |
| **보조 배경색** | 가독성을 높이는 옅은 회색/블랙 그레이 | `#2D3C5B` | 카드 및 컴포넌트 구분용. 메인 배경과 충분한 대비를 이룸. |
| **메인 타이포그래피** | 전문성, 안정감 (Serif) | N/A | 제목, 주요 헤드라인에 사용. 신뢰감을 극대화하는 폰트(예: Times New Roman 대체 계열). |
| **데이터 강조색 (The Gap)** | 경고, 위험, 주목 (High Contrast Orange) | `#FF7B00` | **Gap Area** 자체를 표현하는 핵심 색상. '주의해야 할 손실'에 대한 즉각적 인지 유발. |
| **긍정/현황색 (Status Quo)** | 공신력, 안정성 (Soft Blue) | `#4A90E2` | 현재 제도나 확보된 자산을 나타내는 색상. 차분하고 신뢰할 수 있는 느낌 부여. |
| **CTA 버튼 배경** | 행동 유도 (Action/Gold Accent) | `#F5C318` | '다운로드', '점검 시작' 등 사용자의 다음 액션을 유도하는 부분에 사용. |

### 2. 타이포그래피 가이드라인 (Typography Guideline)

*   **폰트 패밀리:** Noto Sans KR 또는 Pretendard 계열 (Sans-serif 기반의 고가독성 폰트 선호).
*   **헤드라인 (H1/H2):** 32px ~ 48px, Bold, `#FFFFFF` 또는 `#F5C318` (Gap 강조 시)
*   **본문 텍스트:** 16px, Regular, `#EAEAEA` (어두운 배경 위에서 눈의 피로도가 적은 밝은 그레이 사용)
*   **데이터 레이블/캡션:** 14px, Medium, `#A0B3D2` (보조적인 정보임을 명시하여 가독성 유지)

### 3. 핵심 컴포넌트 설계 (SVG & Component Specification)

#### A. Gap Area Chart SVG 스펙
이 차트는 웹/PDF 양쪽에 사용되는 가장 중요한 시각화 요소입니다.

*   **역할:** 현재 제도 수준(A)과 실질적 필요 비용(B) 사이의 간격(Gap)을 면적으로 표현합니다.
*   **기술 명세 (SVG):**
    *   `<svg width="100%" height="250px" viewBox="0 0 800 250">` 구조 사용 권장.
    *   **데이터 바(A) 경로:** `path d="M [x1, y1] L [x2, y2]..." style="fill: #4A90E2;"` (Soft Blue)
    *   **Gap 영역(B-A) 경로:** `path d="M [x1, y1] L [x2, y2]..." style="fill: #FF7B00; opacity: 0.8;"` (**The Gap Orange**)
    *   **Tooltip/Hover Logic (Web Only):** 마우스 오버 시 해당 간격의 **절대 금액(원)**과 **퍼센트 손실률 (%)**을 계산하여 툴팁으로 표시해야 함.

#### B. 데이터 포인트 카드 (Data Point Card) 스펙
각 Pain Point(국민연금, 장기요양 등)를 담는 표준화된 정보 단위입니다.

*   **구조:** `[Gap 주제 제목]` → `[Pain Point 요약]` → `[시뮬레이션 결과/위험 데이터]`
*   **디자인 요소:**
    1.  **제목 영역 (H3):** `#FFFFFF` 배경, 24px.
    2.  **요약 박스 (Callout Box):** `border-left: 5px solid #FF7B00;` 를 사용하여 시각적 경고를 부여합니다.
    3.  **핵심 데이터 표시:** 숫자 단위는 항상 **'원(KRW)'**을 명확히 표기하고, 만 원/억 원 단위를 자동으로 변환하여 읽기 쉽게 처리해야 합니다.

### 4. 인터랙션 로직 스펙 (Interaction Logic Specification)
*(Web Only - 코다리 구현 필수)*

| 단계 | 액션 (Trigger) | 시스템 응답 (Action) | 결과 시각화 | 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 진입** | 사용자 스크롤 또는 섹션 로딩 완료 | 배경에 미세한 애니메이션(Fade-in) 적용. 5개의 Gap 포인트 카드가 순차적으로 등장 (Staggered Reveal). | 전체적인 어두운 무드와 긴장감 조성. | 집중도 향상 및 몰입 유도. |
| **2. 탐색** | 사용자가 특정 'Gap 주제' 카드(예: 장기요양) 클릭/호버 | 해당 섹션의 `Gap Area Chart`가 중앙에 확대되어 나타나며, 차트 하단에 관련 텍스트 설명을 확장(Accordion)하여 표시함. | Gap Chart 활성화 및 상세 설명 패널 오픈. | 정보 깊이 제공 및 문제 인식 심화. |
| **3. 진단 (최종)** | 모든 Gap 포인트 검토 완료 후 'Gap 체크리스트 다운로드' 버튼 클릭 | 폼 유효성 검사(Email, Phone Number)를 수행하고, 성공 시 리드 마그넷 페이지로 이동하며 백엔드에 데이터 전송. | **CTA 버튼**이 Glow 효과와 함께 애니메이션 실행. | Funnel 완성 및 리드 확보 (Conversion). |

### 5. PDF 리드 마그넷 변환 전략 (Static Adaptation)
*(Web 인터랙션을 정적 매체로 옮기는 방법)*

1.  **상호작용 → 질문/확인:** 웹의 '클릭' 액션은 PDF에서 **[O] / [X] 체크박스 형식**으로 변경됩니다. "현재 나의 상황을 점검해 보세요."
2.  **차트 데이터 → 비교 표:** 인터랙티브 차트는 고정된 `Gap Area Chart` 이미지를 사용하되, 하단에 '위험성 자가 진단 테이블'을 배치하여 사용자 스스로 Gap 금액을 계산하도록 유도합니다.
3.  **텍스트 강조:** 모든 핵심 경고문(Pain Point) 앞에는 🚨 **[필수 확인]** 태그를 붙여 시각적 위급함을 인쇄물에서도 유지합니다.
