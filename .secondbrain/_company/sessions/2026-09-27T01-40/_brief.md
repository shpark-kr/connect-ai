# 📋 작업 브리프

**원 명령:** 블로그 html 파일을 주제당 시리즈로 작성해서 파일을 지금 바로 생성해줘.

## 요약
블로그 콘텐츠 제작은 단순한 글쓰기를 넘어, '권위(Authority)'를 구축하고 독자가 체계적으로 정보를 습득하게 만드는 구조화된 과정이 필요합니다. 따라서 연구 단계부터 시작하여 전문적인 콘텐츠 작성, 그리고 이를 고대비의 학습 흐름을 유도하는 HTML 디자인 시스템 적용까지 전 과정을 수행해야 합니다.

## 분배
- **🔍 Researcher**: 현재 기획된 5가지 핵심 주제(만성 염증/인슐린 민감성, 근력/관절 보호 등)별로 '법적 근거가 필수적인' 최신 공공 데이터와 학술 자료를 최종 검토하여, 각 시리즈의 전반적인 논리 흐름과 주장에 대한 반박 불가능한 근거(Citation List) 매트릭스를 완성하십시오. 특히 각 주제 간 연결고리를 찾을 수 있는 상위 레벨의 통합 지식 지도(Knowledge Map Data Set)를 준비해야 합니다.
- **✍️ Writer**: researcher가 제공한 공신력 높은 근거 자료와 5단계 필수 구조(문제 인식 → 해결책 제시 → 다음 콘텐츠 예고) 가이드라인을 철저히 준수하여, 주제별 시리즈 블로그 글 초안 묶음(Draft Set)을 작성하십시오. 모든 주장은 [공적 기관/법 조항]을 반드시 인용하고, 독자의 학습 흐름이 끊기지 않도록 문단을 구조화하며, 각 글의 최종 목표 CTA('리스크 검진 체크리스트 다운로드')가 명확하게 강조되도록 카피라이팅 해주십시오.
- **🎨 Designer**: Writer가 작성한 시리즈별 콘텐츠 초안을 기반으로, 독자의 학습 흐름과 정보의 위계를 시각적으로 극대화하는 고대비 HTML/CSS 컴포넌트 세트를 디자인하십시오. 단순히 텍스트를 배치하는 것이 아니라, ① '시리즈 연재 가이드(Series Navigation)' 섹션과 ② '단계별 프로세스 시각화(Step-by-Step Visualizer)' 모듈을 포함하여, 코다리가 바로 웹페이지에 통합할 수 있는 구조적이고 전문적인 HTML 코드 블록 형태로 브리프를 완성해 주십시오.
