## 📊 Gap Area Chart Design Specification (V2.0)

### 1. 🎯 목적 및 목표
*   **목표:** 시청자가 현재의 돌봄 비용 구조에 대한 '무지(Ignorance)'가 곧 재정적 손실이라는 인식을 갖게 하는 것.
*   **핵심 기능:** 두 개의 독립적인 면적 그래프를 사용하여, **[A] 보험/기대 비용 (Covered Cost)** 대비 **[B] 실제 필요 비용 (Required Cost)**의 격차(The Gap)를 시각적으로 최대화합니다.
*   **활용처:** 롱폼 영상 스크립트의 클라이맥스 지점, 블로그 포스팅의 핵심 데이터 요약 섹션.

### 2. 🎨 비주얼 시스템 및 토큰 정의 (Color & Type)

| 요소 | 역할/의미 | Hex 코드 | 사용 환경 |
| :--- | :--- | :--- | :--- |
| **Background** | 신뢰감, 전문성 유지 | `#1A2333` (Dark Navy Blue) | Web / Video (어두운 배경 필수) |
| **Primary Color** | 안정적인 기준선 (보험 커버 범위) | `#4CAF50` (Safe Green - 낮은 채도) | Line Chart (Expected Cost) |
| **Secondary Color** | 위험/필요 비용 (The Gap 추적) | `#FF6B6B` (Warning Red - 고채도) | Filled Area Chart (Required Cost) |
| **Gap Highlight** | 핵심 격차 (주의 집중 유도) | `#FFA726` (Amber Orange - 강조색) | Gradient Fill / Shading (The Gap 자체에 적용) |
| **Text/Label** | 가독성 확보 | `#FFFFFF` 또는 `#E0E0E0` | 모든 텍스트 및 축 레이블 |
| **Typography** | 본문/헤딩 | Noto Sans KR Bold (가장 큰 크기) | 웹, 인쇄물, 영상 자막 공통 적용 |

### 3. 🖼️ 컴포넌트 스펙: Gap Area Chart 구조

#### A. 차트 구성 레이어
1.  **Area Layer (Required Cost):** Y축의 상한선. 실제 필요 비용을 나타내며, **`#FF6B6B`** 색상의 채워진 면적 그래프로 표현합니다. 이 부분이 시청자에게 '위협'으로 다가와야 합니다.
2.  **Line Layer (Expected Cost):** Y축의 기준선. 보험/기대 비용을 나타내며, **`#4CAF50`** 색상의 굵은 라인 그래프로 표현합니다.
3.  **Gap Shading Area:** 두 레이어 사이의 면적(Area) 자체를 포착하여, 전체 차트 배경 위에 **반투명 `#FFA726`** 그라데이션 오버레이로 덧씌웁니다. 이 부분이 핵심 시각화 요소입니다.

#### B. 축 레이블링 규칙 (Axis Labeling Rules)
*   **X-Axis (시간 경과/돌봄 단계):** 시간적 흐름이나 돌봄의 단계를 나타내는 범주형(Categorical) 라벨을 사용합니다. (예: '입원 초기' → '재활 과정 1년차' → '가정 생활 전환')
*   **Y-Axis (비용/금액):** 반드시 **"단위: 만 원 (KRW)"**을 명시하며, 눈금 간격(Interval)은 청중이 직관적으로 이해할 수 있도록 큰 단위(예: 100만 원 또는 200만 원)로 설정합니다.
*   **데이터 포인트 강조:** 그래프 상에 **수직 점선(`dashed line`)**을 활용하여, Gap 값이 가장 크게 벌어지는 특정 시점 (Critical Point)에 포커스를 맞춥니다.

### 4. 💻 구현 가이드: SVG 및 미디어별 적용 방안

#### A. 웹/블로그 환경 (SVG 컴포넌트 스펙)
*   **컴포넌트명:** `GapAreaChart-v2.0`
*   **기술 요구사항:** 반응형(Responsive) 디자인 필수. 모바일 뷰에서는 Y축 레이블의 간격을 좁히고, X축 라벨을 회전시켜 가독성을 확보해야 합니다.
*   **SVG 속성:** 복잡한 데이터 처리는 JavaScript 라이브러리 (예: D3.js)에 의존하며, SVG 자체는 구조적 컴포넌트 역할을 수행합니다.
    *   `<svg role="img" aria-labelledby="...">` 태그를 사용하여 접근성을 확보해야 합니다.
    *   **데이터 바인딩:** `[Gap Data Set]`을 JSON 배열 형태로 입력받아 렌더링합니다.

#### B. 영상 환경 (Video/FFmpeg Spec)
*   **목표:** 애니메이션 효과(Animation)를 통해 데이터가 '발견'되는 느낌을 주어야 합니다.
*   **애니메이션 시퀀스:**
    1.  **[Step 1: 초기 로딩]**: 배경과 Y축 레이블만 먼저 나타납니다. (신뢰감 조성).
    2.  **[Step 2: 기대 비용 라인 등장]**: `Primary Color`의 Line Layer가 왼쪽부터 부드럽게 그려지며(Draw-in), 기준선을 설정합니다.
    3.  **[Step 3: 실제 필요 영역 폭발]**: `Secondary Color`의 Area Layer와 Gap Shading이 **강렬하게 확대/등장(Pop-up)**하며, 충격 효과를 극대화합니다. 이 순간에 나레이션의 톤을 가장 낮게 설정해야 합니다.
    4.  **[Step 4: 결론 도출]**: 모든 요소가 제자리를 잡고 정지하며, Gap 부분이 `Amber Orange`로 하이라이트 되며 핵심 메시지를 자막으로 강조합니다.
