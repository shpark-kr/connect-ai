## 🤖 Part 2. API 호출 시퀀스 및 발행 플로우 (Sequence Flow Diagram)

콘텐츠가 **'완성'**되는 것보다, 여러 플랫폼에 **'오류 없이 순차적으로 배포'**하는 것이 중요합니다. 아래는 가장 안정적이고 트래픽을 극대화할 수 있는 권장 API 호출 시퀀스입니다.

### 🔗 발행 전 필수 선행 조건 (Prerequisites)
1.  **[디자인] Warning 에셋 최종 확정:** 모든 콘텐츠에 사용될 충격 경고 모듈형 자산(이미지, 그래프)이 개발팀에게 전달되어야 합니다.
2.  **[법률/검토] 면책 고지서 통합 (Disclaimer):** 모든 플랫폼 발행 전, '본 내용은 법적 상담을 대체할 수 없음'이라는 문구가 강제적으로 포함되어야 합니다.

### ⚙️ 단계별 API 호출 시퀀스 (API Sequence Flow)
| 순서 | 채널 / 목표 | 실행 에이전트 | 핵심 작업 내용 | 필수 체크포인트 |
| :--- | :--- | :--- | :--- | :--- |
| **STEP 1** | **블로그/웹사이트 (SEO)** | 코다리(개발) | 완성된 원고를 HTML로 변환 → 워드프레스 발행 API 호출. (가장 안정적인 트래픽 유입원 확보) | `01_블로그_콘텐츠` 폴더 저장 확인, 애드센스/광고 삽입 테스트. |
| **STEP 2** | **유튜브 (롱폼)** | 레오(YouTube) | 스크립트 기반으로 영상 자동 렌더링 API 호출 → YouTube Studio 업로드 API 호출. | 설명란 Funnel CTA 링크 정상 작동 여부 확인, 태그 최적화 검증. |
| **STEP 3** | **인스타그램/쇼츠 (단기 트래픽)** | Instagram 에이전트 | Shot List 기반으로 쇼츠/릴스 영상 자동 렌더링 → 플랫폼 API 호출 (크로스 포스팅). | 첫 3초 후킹 문구와 시각 자료의 일치성 확인, CTA 질문형 구조 유지. |
| **STEP 4** | **재검증 및 최적화** | 영숙/CEO | 모든 채널별 실시간 유입 데이터 분석 → 다음 콘텐츠 기획에 반영 (피드백 루프). | 트래픽이 가장 많이 발생한 Funnel CTA 경로 재점검. |

## ✅ Part 3. 최종 발행 체크리스트 (Checklist)

모든 콘텐츠가 발행되기 전, 반드시 이 리스트를 통해 **'사각지대 위험 요소'**를 점검해야 합니다.

### 🚩 [기술적 안정성]
*   [ ] **E2E 파이프라인 테스트 완료:** 개발팀의 마스터 테스트 스위트(Master Test Switch)가 작동하여 모든 API 호출 경로에 오류가 없는지 확인.
*   [ ] **Funnel CTA 연결 검증:** 모든 콘텐츠 (블로그 설명란, 유튜브 설명란, 숏폼 캡션)에서 리드 마그넷 다운로드 페이지로의 링크가 정상적으로 동작하는지 클릭 테스트 완료.
*   [ ] **다중 포맷 호환성 확인:** 영상 자막(노랑/흰색 대비), 블로그 이미지 비율 등이 모든 기기(모바일, 데스크톱)에서 깨지지 않는지 최종 점검.

### ⚠️ [콘텐츠 전문성 및 법적 준수]
*   [ ] **최신 공공 데이터 출처 명시:** 콘텐츠 내 모든 통계와 주장은 반드시 '국민연금 공식 자료', '복지부 정책' 등의 출처 URL과 조항을 포함했는지 확인. (가장 중요!)
*   [ ] **경고/위기 메시지 일관성:** 전체 시리즈의 톤앤매너(Tone & Manner)를 '재정적 손실 회피 경고'로 통일하고, 헤드라인이 위기감을 극대화하는 구조인지 확인.
*   [ ] **면책 고지서 삽입:** 콘텐츠 시작과 끝에 전문적인 Disclaimer 문구가 명확하게 노출되는지 확인.
