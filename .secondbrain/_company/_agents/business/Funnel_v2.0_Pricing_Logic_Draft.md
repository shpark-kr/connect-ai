# 📈 Mini-App Funnel v2.0 - 가격 책정 및 전환 논리 흐름도 (가설)<br><br>## 🎯 목표: 기술 안정화 후 적용할 '최종 수익 모델'의 청사진<br><br>**1. 프로모션 구조 확정:**<br>*   **핵심 상품:** 7일 무료 체험 진단 및 관리 서비스.<br>*   **Free Tier (진단):** 초기 데이터 입력 $\rightarrow$ 전문 용어 기반 위험 경고(Deep Crimson Red) 제시 $\rightarrow$ **'맞춤 솔루션 부족분 확인'** 유도. (수익화 포인트: 심리적 위기감 조성)<br>*   **Paid Tier (구독 전환):** 7일 후 자동 결제 옵션을 기본으로 설정하되, 사용자가 직접 구독을 '활성화'하는 명시적인 버튼(Action Teal)을 통해 자발적 동의를 유도. <br><br>**2. 수익화 논리 플로우 다이어그램 (Flow Logic):**<br>1. **진입:** 사용자 데이터 입력 $\rightarrow$ 2. **위기 고조:** 전문 지표 기반 진단 결과 제시 ('이 상태는 위험함' 강조) $\rightarrow$ 3. **솔루션 부족 감지:** 현재 Funnel에서 제공하는 해결책만으로는 '최적의 개선 목표치'에 도달할 수 없음을 과학적으로 증명 (예: "HOMA-IR 지표가 이 정도 낮으면, 최소 X% 이상의 보충이 필요합니다."). $\rightarrow$ 4. **CTA 유도:** 부족분을 채우기 위한 유료 컨설팅/솔루션 패키지(월 구독) 제시 및 체험 시작 버튼 노출.<br><br>**3. 핵심 KPI 설계 (측정 기준):**<br>*   **Primary KPI:** Free $\rightarrow$ Paid 전환율 (Conversion Rate). <br>*   **Secondary KPI:** 평균 사용자 세션당 체류 시간 (Deep Crimson Red 경고 구간에서의 이탈 방지).
